# 560 和为 K 的子数组

- 难度：中等
- 标签：数组、**哈希表**、前缀和
- 力扣链接：https://leetcode.cn/problems/subarray-sum-equals-k/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/subarray-sum-equals-k/solution/he-wei-kde-zi-shu-zu-by-leetcode-solution/)的「前缀和 + 哈希表优化」。正文主解是 **前缀和 + `unordered_map` 统计出现次数**；「枚举」解法见文末「复盘」。

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

**示例 1：**

```
输入：nums = [1,1,1], k = 2
输出：2
```

**示例 2：**

```
输入：nums = [1,2,3], k = 3
输出：2
```

**数据范围：**

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 思路

> 本题参考力扣官方「前缀和 + 哈希表优化」做法。

### 关键观察

记前缀和 `pre[i] = nums[0] + ... + nums[i]`，则区间 `[j..i]` 的和为：

```
pre[i] - pre[j-1]
```

于是「`[j..i]` 和为 `k`」等价于：

```
pre[j-1] == pre[i] - k
```

固定右端点 `i` 时，只要数一数**在 `i` 之前**有多少个前缀和等于 `pre[i] - k`，就能得到以 `i` 结尾、和为 `k` 的子数组个数。

### 为什么不用滑动窗口

数据范围里 `nums[i]` **可以为负**。窗口和不再随左右端点单调变化，无法靠“和太大就缩左端”这类单调性来维护，所以滑动窗口不适用。

### 暴力想法（会慢）

枚举每个右端点 `i`，再往左累加，统计和是否等于 `k`。时间 O(n²)，`n = 2 * 10^4` 时偏紧甚至超时风险大。

### 前缀和 + 哈希表

边从左往右扫，边用哈希表 `mp` 记录「某个前缀和出现了几次」：

1. 维护当前前缀和 `pre`（不必单独开 `pre` 数组）。
2. 查 `mp[pre - k]`：有多少个历史前缀和等于 `pre - k`，答案就加多少。
3. 再把当前 `pre` 的出现次数 +1。

初始化：`mp[0] = 1`，表示「空前缀」的和为 0 出现过一次。这样当 `pre` 本身就等于 `k`（子数组从下标 0 开始）时也能被正确统计到。

示意（`nums = [1,1,1], k = 2`）：

```
i=0: pre=1,  找 1-2=-1 → 0 个；mp: {0:1, 1:1}
i=1: pre=2,  找 2-2=0  → 1 个（空前缀）；mp: {0:1, 1:1, 2:1}
i=2: pre=3,  找 3-2=1  → 1 个；答案共 2
```

## 代码

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        // unordered_map<int, int>：C++ STL 无序哈希表。
        //   - 模板参数：key 是 int（前缀和），value 是 int（该前缀和出现次数）。
        //   - 底层哈希，查找 / 插入均摊 O(1)；最坏退化到 O(n)，但一般可当 O(1) 用。
        //   - 与 map 的区别：map 按 key 有序，查找 O(log n)；本题不需要有序，用 unordered_map 更合适。
        unordered_map<int, int> mp;

        // mp[0] = 1：空前缀（一个数都不选）的和为 0，约定出现过 1 次。
        //   - operator[]：若 key 不存在会先插入默认值（int 默认 0），再返回引用；这里直接赋 1。
        //   - 作用：当某个前缀和 pre 恰好等于 k 时，pre - k == 0，能命中这条记录，
        //     表示「从下标 0 一直取到当前」这一段也算一个合法子数组。
        mp[0] = 1;

        int count = 0;  // 答案：和为 k 的子数组个数
        int pre = 0;    // 当前前缀和，对应官方题解里的 pre[i]

        // 范围 for：auto& x 表示「对 nums 里每个元素的引用」，避免拷贝（int 拷贝便宜，写法上保持习惯）。
        for (auto& x : nums) {
            pre += x;  // 递推：pre[i] = pre[i-1] + nums[i]

            // find(key)：返回迭代器；找不到则返回 mp.end()。
            //   - 比直接用 mp[pre - k] 更安全：operator[] 在 key 不存在时会插入 {key, 0}，
            //     污染哈希表（把「从未出现过」也记成出现过 0 次，虽然数值上碰巧常没事，但语义脏）。
            //   - 这里先判断存在，再累加出现次数。
            if (mp.find(pre - k) != mp.end()) {
                count += mp[pre - k];
            }

            // mp[pre]++：当前前缀和再多出现一次。
            //   - 必须先查再更新：保证查到的都是「当前位置之前」的前缀和，
            //     不会把「以当前下标结尾」自己算进「更早的前缀」里。
            //   - 若 pre 首次出现，[] 会插入 0，再 ++ 变成 1。
            mp[pre]++;
        }
        return count;
    }
};
```

## 复杂度

- 时间：O(n)，其中 n 为数组长度。遍历一遍，哈希表查询 / 更新均摊 O(1)。
- 空间：O(n)。最坏情况下每个前缀和都不同，哈希表最多存 n + 1 个键（含初始的 0）。

## 复盘

### 可迁移套路

- **区间和 ↔ 前缀和差**：`sum(j..i) = pre[i] - pre[j-1]`。
- **「有多少个历史值满足 xxx」** → 哈希表存出现次数，边扫边查边更新（和「两数之和」同一味道）。
- 初始化 `mp[0] = 1` 是前缀和题里的常见细节。
- 有负数时，别惯性上滑动窗口。

### 解法二：枚举（官方方法一）

固定右端点，再往左累加，O(1) 维护区间和，总时间 O(n²)、空间 O(1)。思路直观，但不如哈希优化。

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int count = 0;
        for (int start = 0; start < (int)nums.size(); ++start) {
            int sum = 0;
            // 从 start 往左扩，边扩边加，避免再开一层求和循环
            for (int end = start; end >= 0; --end) {
                sum += nums[end];
                if (sum == k) {
                    ++count;
                }
            }
        }
        return count;
    }
};
```
