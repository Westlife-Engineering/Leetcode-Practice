> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/search-a-2d-matrix-ii/solutions/488838/sou-suo-er-wei-ju-zhen-ii-by-leetcode-so-9hcx/)的三种做法。正文主解是 **方法三：Z 字形查找（从右上角出发，每步排除一行或一列）**，与「矩阵」目录主题最对应也最巧妙；「直接查找」「逐行二分」见文末「复盘」作对比。

## 题目描述

编写一个高效的算法来搜索 *m* x *n* 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

**示例 1：**

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true
```

**示例 2：**

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
输出：false
```

**数据范围：**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= n, m <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- `-10^9 <= target <= 10^9`

## 思路

> 本题参考力扣官方「Z 字形查找」做法。关键性质：**每行从左到右升序、每列从上到下升序**（注意整张矩阵**不是**全局升序，比如 `matrix[0][n-1]` 可能大于 `matrix[m-1][0]`）。

### 暴力想法（会超时/官方方法一）

最直接：双层循环把 `matrix` 每个元素扫一遍，遇到等于 `target` 就返回 `true`。能做对，但时间是 O(mn)，没用上「行列都升序」的性质。

### 为什么不能从左上角出发？

直觉上「从左上角 `(0,0)` 出发找 `target`」很自然，但左上角是整个矩阵的**最小值**：

- 往右走（列 `+1`），值变大；
- 往下走（行 `+1`），值也变大。

如果当前值 `< target`，**你根本不知道该往右还是往下**——两个方向都可能找到 `target`，无法唯一决策。所以左上角是个「两个方向都增」的死角，做不出 O(m+n)。

同理，右下角 `(m-1, n-1)` 是整个矩阵的**最大值**，往左、往上都变小，也无法决策。

### 为什么右上角可以？

看右上角 `(0, n-1)`：它是**第一行的最大值**，同时是**最后一列的最小值**。它的两个邻接方向「一增一减」：

- **往左走**（列 `-1`），值**变小**（同一行从右到左递减）；
- **往下走**（行 `+1`），值**变大**（同一列从上到下递增）。

于是每次比较 `matrix[x][y]` 和 `target`，都能**唯一确定**走哪边：

- `matrix[x][y] == target` → 找到，返回 `true`。
- `matrix[x][y] > target` → 当前值偏大。因为第 `y` 列从上到下递增，**当前行往下都更大**，第 `y` 列整体排除，`y--`（往左走）。
- `matrix[x][y] < target` → 当前值偏小。因为第 `x` 行从左到右递增，**当前列往左都更小**，第 `x` 行整体排除，`x++`（往下走）。

每一步要么排除一整列、要么排除一整行，绝无回头路（`x` 只增、`y` 只减），所以总共最多走 `m + n` 步。

> 左下角 `(m-1, 0)` 同理可行（往右变增、往上变减），与右上角对称，任选其一。本笔记跟官方一样从右上角出发。

### 手动推导示例 1

`matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]`，`target = 5`：

```
起始 (x=0, y=4): matrix[0][4]=15 > 5  → 第 4 列整体 > 5，排除，y-- → y=3
(x=0, y=3): matrix[0][3]=11 > 5       → 第 3 列整体 > 5，排除，y-- → y=2
(x=0, y=2): matrix[0][2]=7  > 5       → 第 2 列整体 > 5，排除，y-- → y=1
(x=0, y=1): matrix[0][1]=4  < 5       → 第 0 行整体 < 5，排除，x++ → x=1
(x=1, y=1): matrix[1][1]=5  == 5      → 命中，返回 true ✓
```

走了 4 步就找到了，比扫一遍 25 个元素快得多。

## 代码

```cpp
class Solution {
public:
    // searchMatrix：在「行升序、列升序」的二维矩阵里找 target。
    //   参数 matrix：vector<vector<int>>&，m 行 n 列的二维矩阵（引用，不拷贝）。
    //   参数 target：int，要查找的目标值。
    //   返回值：bool，矩阵中是否存在 target。
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        // matrix.size()：外层 vector 元素个数 = 行数 m。
        //   题目保证 m >= 1，所以下面 matrix[0].size()（取第 0 行长度 = 列数 n）安全。
        int m = (int)matrix.size();
        int n = (int)matrix[0].size();

        // 起始位置定在右上角 (x=0, y=n-1)：
        //   x 是当前行，初始第 0 行；y 是当前列，初始最后一列。
        //   右上角是「第一行最大值 + 最后一列最小值」，往左变小、往下变大，方向唯一可决策。
        int x = 0, y = n - 1;

        // 循环条件：x 没越过最后一行（x < m）且 y 没越过第 0 列（y >= 0）。
        //   一旦越界说明已把所有可能的行/列排除完，target 不存在。
        while (x < m && y >= 0) {
            if (matrix[x][y] == target) {
                // 命中目标值，直接返回。
                return true;
            }
            if (matrix[x][y] > target) {
                // 当前值偏大：第 y 列从上到下递增，当前行往下都更大，
                // 所以整个第 y 列都不可能是 target → 排除第 y 列，y--（向左走）。
                --y;
            } else {
                // matrix[x][y] < target：当前值偏小。
                // 第 x 行从左到右递增，当前列往左都更小，
                // 所以整个第 x 行都不可能是 target → 排除第 x 行，x++（向下走）。
                ++x;
            }
        }
        // 走到边界还没命中，说明 target 不在矩阵中。
        return false;
    }
};
```

## 复杂度

- **时间**：O(m + n)
  - 每一步要么 `y--`（最多减 `n` 次，从 `n-1` 到 `-1`），要么 `x++`（最多增 `m` 次，从 `0` 到 `m`）。
  - 两个方向都不回头，所以 while 循环最多执行 `m + n` 次。比暴力的 O(mn) 和逐行二分的 O(m log n) 在渐进意义上更优（与 m、n 同阶）。
- **空间**：O(1)
  - 只用了 `m` / `n` / `x` / `y` 四个变量，没有开额外数组。

## 疑惑 / 卡点

（随做题提问持续更新）

### Q1：为什么从左上角 `(0,0)` 出发不行，从右上角 `(0,n-1)` 就行？

左上角是整张矩阵的**最小值**，往右和往下值都**变大**。当 `matrix[0][0] < target` 时，你无法判断 `target` 到底在右边还是下边——两个方向都得试，就退化成搜索了。

右上角则不同：往左**变小**、往下**变大**，是一个「单调分叉点」。比较一次就能确定唯一方向：偏大就往小的一侧（左）走，偏小就往大的一侧（下）走。**能唯一决策是 O(m+n) 搜索的前提**。

### Q2：为什么必须选右上角或左下角，选右下角行不行？

不行。右上角 `(0, n-1)` 和左下角 `(m-1, 0)` 的共同点是：**两个邻接方向一个增、一个减**。这种「十字交叉点」才能让每次比较唯一确定走哪边。

而左上角 `(0,0)`（双增）和右下角 `(m-1, n-1)`（双减）的两个方向都同向变化，无法决策。所以四个角里**只有右上、左下两个角能当起点**。

### Q3：最多走多少步？会不会反复来回走？

最多 `m + n` 步，**绝不会反复来回**。因为 `x` 只会 `++`（单调递增，从 0 到 m），`y` 只会 `--`（单调递减，从 n-1 到 -1），两个变量各自最多变化 m 次、n 次，加起来 `m + n` 就是上界。这也是为什么时间是 O(m+n) 而不是 O(m·n)。

### Q4：这个矩阵能用二分查找吗？

可以逐行二分（官方方法二）：对每一行用 `lower_bound` 二分找 `target`，每行 O(log n)，共 m 行，总时间 O(m log n)。当 m 较小、n 较大时它可能比 O(m+n) 略快；但 Z 字查找的 O(m+n) 是**与 m、n 同阶的最稳保证**，且只写一层循环、不用调 STL，是力扣官方推荐的「方法三」。注意整张矩阵**不是**全局升序的（`matrix[0][n-1]` 可能大于 `matrix[1][0]`），所以不能像「74. 搜索二维矩阵」那样把矩阵拍扁成一维做单次二分。

## 复盘

### 可迁移套路

- **「在有序结构里找唯一决策点」**：当数据有某种单调性时，找一个**两方向变化相反**的「十字点」当起点（本题是右上角/左下角），就能把搜索从「多向探索」降成「单向折半排除」。和二分查找的思想同源，只是作用在二维结构上。
- **「每步排除一行/一列」**：凡是「行有序、列有序」的矩阵查找，先想 Z 字形搜索，而不是暴力或逐行二分。
- **判断起点的口诀**：四个角里挑「左减右增/上减下增不一致」的那个——也就是右上角或左下角。

### 解法二：逐行二分查找（官方方法二）

对每一行调用 `lower_bound`（STL 二分下界），若命中等于 `target` 的元素就返回 `true`。时间 O(m log n)，空间 O(1)。当 m 远小于 n 时可能比 Z 字查找快，但渐进意义不如 O(m+n) 稳。

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        for (const auto& row: matrix) {
            // lower_bound(first, last, val)：在已升序区间 [first,last) 里二分找
            //   第一个「不小于 val」的元素，返回指向它的迭代器（<algorithm>，力扣默认可用）。
            //   - 若所有元素都 < val，返回 last（即 row.end()）。
            //   - 复杂度 O(log n)，比手写二分更不易写错。
            //   - 注意：lower_bound 找的是「>= val」，要再判 *it == target 才算真正命中。
            auto it = lower_bound(row.begin(), row.end(), target);
            if (it != row.end() && *it == target) {
                return true;
            }
        }
        return false;
    }
};
```

- **时间**：O(m log n)
- **空间**：O(1)

### 解法三：直接查找（官方方法一）

双层循环扫遍矩阵，时间 O(mn)，空间 O(1)。仅作下限对比，实际提交会偏慢（题面要求「高效算法」时不可取）。

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        // const auto& row：以 const 引用遍历每一行，避免拷贝整行（行内 int 数值不大时差异有限，但写 const& 是好习惯）。
        for (const auto& row: matrix) {
            for (int element: row) {
                if (element == target) {
                    return true;
                }
            }
        }
        return false;
    }
};
```

- **时间**：O(mn)
- **空间**：O(1)
