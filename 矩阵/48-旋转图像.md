# 48 旋转图像

- 难度：中等
- 标签：数组、数学、**矩阵**
- 力扣链接：https://leetcode.cn/problems/rotate-image/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/rotate-image/solution/xuan-zhuan-tu-xiang-by-leetcode-solution-vu3m/)的三种做法。正文主解是 **方法三：用翻转代替旋转（水平轴翻转 + 主对角线翻转）**；「辅助数组」「四元组原地交换」见文末「复盘」。

## 题目描述

给定一个 *n* × *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**示例 1：**

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**数据范围：**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 思路

> 本题参考力扣官方「用翻转代替旋转」做法。

### 关键观察

先写出顺时针 90° 的坐标映射（行列从 0 起算）：

```
matrix[row][col]  →  matrix[col][n - row - 1]
```

直接按这个公式往原矩阵里写会覆盖还没搬完的值，所以题目强调「原地」时需要换思路。

官方方法三的巧妙点：把这次旋转拆成两次**翻转**，每次都是成对交换，天然不丢数据。

### 步骤一：水平轴翻转（上下翻转）

枚举上半部分，与下半部分交换同一列：

```
matrix[row][col]  ↔  matrix[n - row - 1][col]
```

示意（示例二）：

```
 5  1  9 11                 15 14 12 16
 2  4  8 10    水平翻转 →    13  3  6  7
13  3  6  7                  2  4  8 10
15 14 12 16                  5  1  9 11
```

注意：这里是「沿水平中轴上下对折」，不是每一行左右翻转。

### 步骤二：主对角线翻转（转置）

枚举对角线严格左侧（或右侧），与对称位置交换：

```
matrix[row][col]  ↔  matrix[col][row]
```

继续上面的矩阵：

```
15 14 12 16                 15 13  2  5
13  3  6  7   主对角线翻转 →  14  3  4  1
 2  4  8 10                 12  6  8  9
 5  1  9 11                 16  7 10 11
```

正好就是答案。

### 为什么等价于顺时针 90°

两步联立：

```
(row, col)
  --水平轴翻转-->  (n-row-1, col)
  --主对角线翻转--> (col, n-row-1)
```

与关键映射 `matrix_new[col][n-row-1] = matrix[row][col]` 一致。

（等价写法还有「先转置再左右翻转每一行」，顺序不同但结果相同；正文跟官方方法三一致。）

## 代码

```cpp
class Solution {
public:
    // void 返回：原地修改 matrix，不另开返回矩阵。
    // vector<vector<int>>&：二维动态数组的引用；外层是行，内层是列。
    //   传引用避免拷贝整张矩阵；直接改调用方传入的那份。
    void rotate(vector<vector<int>>& matrix) {
        // size()：vector 元素个数；对二维矩阵即行数 n（本题保证方阵）。
        int n = (int)matrix.size();

        // 1) 水平轴翻转：第 i 行与第 n-1-i 行整行对调（逐列交换）。
        //    i 只扫到 n/2 - 1，避免交换两次又变回去。
        for (int i = 0; i < n / 2; ++i) {
            for (int j = 0; j < n; ++j) {
                // swap(a, b)：交换两个对象的值（头文件 <algorithm>，力扣环境已可用）。
                //   对 int 就是用临时变量互赋；写 swap 比手写 temp 更短、不易写错。
                swap(matrix[i][j], matrix[n - i - 1][j]);
            }
        }

        // 2) 主对角线翻转（转置）：只枚举 j < i（对角线左下），与 (j,i) 交换一次即可。
        //    若 j 从 0 扫到 n-1，会把同一对交换两次，等于没转置。
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
    }
};
```

## 复杂度

- 时间：O(n²)。两次翻转各自大约扫半个矩阵，合计仍是 O(n²)。
- 空间：O(1)。只做原地交换，不用辅助矩阵。

## 复盘

### 可迁移套路

- **旋转 ↔ 翻转组合**：顺时针 90° ≈ 水平轴翻转 + 主对角线翻转（或 转置 + 左右翻转）
- **原地矩阵变换**：先写出 `(i,j) → 目标`，再拆成可成对交换的几步，避免覆盖
- 易错点：水平翻转是**上下**对折；主对角线翻转时 `j` 必须只扫半边，否则会交换两次

### 解法二：使用辅助数组（官方方法一）

映射 `matrix_new[j][n-i-1] = matrix[i][j]`，先写到新矩阵再拷回。思路最直观，但额外空间 O(n²)，不完全符合「不要使用另一个矩阵」的题意（官方仍作为入门讲）。

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = (int)matrix.size();
        // auto matrix_new = matrix：对 vector 是值拷贝，得到一份独立的二维数组副本。
        //   （若写成指针/引用赋值则是共享同一份，这里必须是拷贝。）
        auto matrix_new = matrix;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                matrix_new[j][n - i - 1] = matrix[i][j];
            }
        }
        // matrix = matrix_new：再把结果值拷贝回原引用指向的对象。
        matrix = matrix_new;
    }
};
```

- 时间：O(n²)
- 空间：O(n²)

### 解法三：四元组原地旋转（官方方法二）

四个位置构成环：

```
(i, j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i) → (i, j)
```

用一个 `temp` 沿环交换。枚举范围：`i ∈ [0, n/2)`，`j ∈ [0, (n+1)/2)`，保证不重不漏（奇数阶中心点不动）。

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = (int)matrix.size();
        for (int i = 0; i < n / 2; ++i) {
            for (int j = 0; j < (n + 1) / 2; ++j) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[n - j - 1][i];
                matrix[n - j - 1][i] = matrix[n - i - 1][n - j - 1];
                matrix[n - i - 1][n - j - 1] = matrix[j][n - i - 1];
                matrix[j][n - i - 1] = temp;
            }
        }
    }
};
```

- 时间：O(n²)
- 空间：O(1)
