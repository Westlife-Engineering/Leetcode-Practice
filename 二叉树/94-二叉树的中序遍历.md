## 题目描述

给定一个二叉树的根节点 `root` ，返回 **它的中序遍历** 。

**示例 1：**

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [1]
输出：[1]
```

**提示：**

- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：** 递归算法很简单，你可以通过迭代算法完成吗？

## 思路

> 本题主要参考力扣官方题解「方法二：迭代」。

### 什么是「中序遍历」

二叉树的遍历有前序、中序、后序三种，区别只在于**根节点什么时候被访问**：

- **中序遍历**：对任意一棵（子）树，按 **左子树 → 根 → 右子树** 的顺序访问。
- （前序是 `根 → 左 → 右`，后序是 `左 → 右 → 根`，本题不涉及。）

因为「访问左子树」「访问右子树」时**用同样的中序规则**继续往下拆，所以整个过程天然是递归的——这正是「进阶」里说的「递归算法很简单」的由来：直接 DFS，先递归左、再访问根、最后递归右，几行就写完。

### 为什么还要学「迭代法」？

递归虽然好写，但它是**系统调用栈在帮你压栈**。一旦树退化成一条链（每个节点只有右孩子），递归深度就是 n，可能栈溢出，而且你完全看不到、也控制不了压栈过程。

题目「进阶」明确要求：**你能否用迭代算法完成？** 换句话说，要我们**手动把递归背后那个隐式的栈模拟出来**。一旦会了这个套路，前序、中序、后序的迭代写法都能照搬，是二叉树遍历的通用基本功。

### 迭代法的核心：一直往左压栈，到头弹出访问，再转向右

中序要求「左 → 根 → 右」。对当前节点来说，它的左子树里所有更靠左的节点都该排在它前面。所以算法是：

1. **一直往左走，边走边压栈**：从当前节点 `curr` 出发，只要它非空，就把它压进栈，然后 `curr = curr->left`，继续往左。这一步是在「排队」——把这条左链上所有节点按「从根到最左」的顺序存起来，**栈顶永远是最左（最该先被访问）的那个**。
2. **到头了就弹出并访问**：当 `curr` 走到 `nullptr`（左到头了），说明栈顶节点已经没有更左的节点挡着了，该轮到它。弹出栈顶，把它的值加入答案。
3. **转向右子树**：被访问的节点处理完后，中序要求接着访问它的**右子树**，所以让 `curr = 栈顶节点->right`，回到第 1 步对右子树重复同样的事。
4. **什么时候全部结束？** 当 `curr` 是空 **且** 栈也空了，说明没有正在走的左链、栈里也没有积压的节点，遍历完成。

### 手动推导 `root = [1,null,2,3]`（中序应为 `[1,3,2]`）

先看清这棵树长什么样：`[1,null,2,3]` 表示节点 1 的左孩子是 `null`、右孩子是 2；节点 2 的左孩子是 3、右孩子是 `null`。

```
    1
     \
      2
     /
    3
```

按上面的算法跑一遍（`stk` 栈底在左、栈顶在右；`curr` 是「当前指针」）：

```
初始  curr=1, stk=[]            res=[]
─────────────────────────────────────────────────
外层(curr=1≠空)：
  一路向左压栈：push(1), curr=1->left=nullptr     stk=[1]
  到头了，弹出：curr=stk.top()=1, pop            stk=[]
  访问 1：    res=[1]
  转向右：    curr=1->right=2
─────────────────────────────────────────────────
外层(curr=2≠空)：
  一路向左压栈：push(2), curr=2->left=3          stk=[2]
                push(3), curr=3->left=nullptr    stk=[2,3]   (栈顶是 3)
  到头了，弹出：curr=stk.top()=3, pop            stk=[2]
  访问 3：    res=[1,3]
  转向右：    curr=3->right=nullptr
─────────────────────────────────────────────────
外层(curr=nullptr, 但 stk 非空[2] → 继续)：
  curr 是空，内层「向左压栈」循环直接不进     stk=[2]
  到头了，弹出：curr=stk.top()=2, pop            stk=[]
  访问 2：    res=[1,3,2]
  转向右：    curr=2->right=nullptr
─────────────────────────────────────────────────
外层(curr=nullptr 且 stk 空) → 退出循环

最终 res = [1,3,2]  ✓
```

**最关键的一步**是第三段：此时 `curr` 已经是 `nullptr`，但**栈里还压着节点 2**没处理，所以外层循环**必须**靠 `!stk.empty()` 这个条件继续，把 2 弹出来访问。这就是为什么外层循环条件要写**两个**（`curr != nullptr || !stk.empty()`），缺一不可。

## 代码

```cpp
/**
 * Definition for a binary tree node.
 * 力扣预置的节点结构，提交时无需自己写，了解一下字段即可：
 *   - val：节点存的值
 *   - left / right：指向左右孩子的指针，没有对应孩子时为 nullptr
 *   - 三个构造函数分别支持：无参（val=0,孩子皆空）、只给值、值+左右孩子
 */
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        // vector<int>：动态数组，这里用来按访问顺序收集节点值。
        //   - push_back(x)：在末尾追加元素，均摊 O(1)。
        //   - 遍历结束后整体返回，力扣会按 res 的内容评判输出。
        vector<int> res;

        // stack<TreeNode*>：STL 栈，元素是「指向树节点的指针」。
        //   - 只能在栈顶操作：push 压入、pop 弹出（无返回值）、top 看栈顶、empty 判空。
        //   - push / pop / top 都是 O(1)。
        //   - 语义：保存「一路向左时路过、但还没到访问时机」的节点，栈顶 = 当前最该先访问的节点。
        //   - 注意存的是指针不是对象本身，避免拷贝整棵树。
        stack<TreeNode*> stk;

        // curr：当前正在处理的指针，从 root 开始。
        //   - 它的取值只有两种来源：要么是「某个节点的左/右孩子」（一路向左时不断 = ->left），
        //     要么是「刚从栈顶弹出来的节点」（到头时 stk.top()）。
        TreeNode* curr = root;

        // 外层循环条件两个都不能少：
        //   - curr != nullptr：说明还有一条「向左」的路要走，或某节点刚被访问、要去看它的右子树。
        //   - !stk.empty()：说明虽然 curr 暂时走到空了，但栈里还压着没访问的祖先节点，得回去处理它们。
        //   用「或」连接：只要还有「没访问到的节点」就继续，节点全访问完两个条件同时为假才退出。
        while (curr != nullptr || !stk.empty()) {
            // 内层循环：从 curr 一路向左，边走边压栈。
            //   - 为什么？中序要求「左在根前」，curr 这条左链上越靠左的越该先访问，
            //     压进栈后，栈顶自然是最左的那个，稍后第一个被弹出访问。
            //   - 注意顺序：先 push(curr) 再 curr = curr->left，保证 curr 自己也被存住。
            while (curr != nullptr) {
                stk.push(curr);
                curr = curr->left;
            }

            // 走到这里说明 curr 已经是 nullptr（左到头了），该轮到栈顶节点。
            //   - top() 看栈顶但不弹出；pop() 弹出但不返回值，所以要先用 top 取值再 pop。
            //   - 这两句的顺序不能反：pop 之后栈顶就变了，再调 top 拿到的是下一个节点。
            curr = stk.top();
            stk.pop();

            // 此时 curr 的左子树要么为空、要么已经全部访问完毕（因为刚才它是栈顶 = 最左），
            // 按「左→根→右」，现在正是访问「根」curr 的时机。
            res.push_back(curr->val);

            // 接着去访问 curr 的右子树：把 curr 指向右孩子，回到外层循环开头。
            //   - 若右孩子非空：外层进内层，一路向左压栈，对右子树重复同样流程。
            //   - 若右孩子为空：内层不进，外层靠 !stk.empty() 继续弹出上一个积压的祖先。
            curr = curr->right;
        }

        return res;
    }
};
```

## 复杂度

- **时间**：O(n)，其中 n 为二叉树节点个数。
  - 每个节点恰好被压栈一次、弹出一次、访问一次，总共 O(n)。
- **空间**：O(n)。
  - 取决于栈深度，而栈深度等于树高 h。平衡树 h = O(log n)，但树退化成一条链时 h = O(n)，所以最坏 O(n)。
  - （递归写法的空间也是 O(h) 同理，因为递归调用栈本质上就是这个显式栈。）

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：外层循环条件为什么必须写两个（`curr != nullptr || !stk.empty()`），只写一个行不行？

不行，两个分别管不同的情况，缺一个都会漏节点或提前退出：

- **`curr != nullptr` 管的是「还要往左走 / 还要看右子树」**：当前正有一条向左的路没走完，或者刚访问完一个节点、要去看它的右孩子。如果只有这个条件、把栈判断去掉——一旦 `curr` 走到空（比如访问完某节点它没右孩子），循环就会提前结束，**栈里积压的祖先节点全被丢弃**，遍历不完整。
- **`!stk.empty()` 管的是「curr 暂时空了，但栈里还有没访问的节点」**：这正是手动推导里第三段那步——`curr=nullptr`，但栈里还有节点 2 没处理。靠这个条件才能让循环继续，把 2 弹出来。如果只有这个条件、把 curr 判断去掉——当 `curr` 非空但栈为空时（一开始就是这种情况），循环根本进不去。

合起来用「或」就是表达：**「还有没向左走的路」或「还有积压没访问的节点」只要成立一个，遍历就没结束**。两个条件同时为假（curr 空且栈空）才是真正的终点。

### Q2：什么时候压栈、什么时候弹出？

记住一句话：**「往左走时压栈，走到头时弹出访问」**。

- 压栈（`stk.push(curr)`）发生在内层循环里——每往左走一步，把当前节点存住，因为它的左子树还没处理完，它本身得「排队」等着。
- 弹出（`stk.top(); stk.pop();`）发生在内层循环结束、`curr` 已经走到空之后——此时栈顶是最左的、没有更左的节点挡它了，该轮到它被访问。

换句话说：**压栈是「登记排队」，弹出是「轮到你了」**。

### Q3：中序迭代和前序、后序迭代的区别在哪？

三者都用「栈 + 往左走」的框架，差别只在**访问根的时机**：

- **前序（根→左→右）**：压栈时就访问（每往左走一步，先把它 push 进答案，再继续往左），转向右子树的方式类似但写法略有不同。
- **中序（左→根→右）**：先一路向左压栈不访问，到头弹出时才访问（本题）。
- **后序（左→右→根）**：最难，弹出时还不能马上访问——要判断「右子树是否已处理」，没处理就得先转右、处理完再回头访问根。

所以**中序迭代是三序遍历里最干净的一个**，把它彻底弄懂，前序只需微调访问时机，后序在它基础上加「右子树是否已访问」的判断即可。这套「栈模拟递归」的写法是**二叉树迭代遍历的通用模板**。

### Q4：空树（`root = nullptr`）会出错吗？

不会，**天然覆盖、不用特判**。空树时 `curr = root = nullptr`，`stk` 初始为空，外层循环条件 `nullptr != nullptr (假) || !empty (假)` 整体为假，直接不进循环，`return res`（空 vector）。结果 `[]`，正确。

这也是为什么外层条件用 `||` 而不是直接 `while (true) + 手动 break`——`||` 把「空树」这种边界情况自动处理掉了。

## 复盘

### 可迁移套路

- **「栈模拟递归」是二叉树迭代遍历的通用模板**。凡是要把递归（系统调用栈）改写成迭代，思路都是：**显式开一个 `stack`，把原本递归要「记住回来」的现场手动压栈**。本题的中序写法背熟后，前序、后序迭代都能照搬。
- **「一路向左压栈 + 弹出转右」** 这个动作组合是中序遍历的招牌。看到任何「按中序访问二叉搜索树」的题（如 230 题「二叉搜索树中第 K 小的元素」、98 题「验证二叉搜索树」），第一反应就是这套迭代模板。
- **遍历类问题的复杂度基准**：树遍历时间一定是 O(n)（每个节点访问一次），空间取决于树高 O(h)，最坏退化成链就是 O(n)。

### 解法二：递归法（官方方法一，最简单）

「进阶」说「递归算法很简单」，确实如此——直接照着中序「左→根→右」的定义写，三行就完事，初学用来验证结果最方便。

```cpp
class Solution {
public:
    // inorder：把 root 子树的中序遍历结果追加到 res 里。
    //   - vector<int>&：传引用，所有递归层共用同一个 res，避免反复拷贝。
    void inorder(TreeNode* root, vector<int>& res) {
        if (!root) {
            return;  // 空节点：没东西可访问
        }
        inorder(root->left, res);    // 1. 先递归左子树
        res.push_back(root->val);    // 2. 再访问根（把值追加进答案）
        inorder(root->right, res);   // 3. 最后递归右子树
    }
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        inorder(root, res);
        return res;
    }
};
```

- **时间**：O(n)，每个节点访问一次。
- **空间**：O(n)，递归栈深度等于树高，最坏 O(n)。
- **对比**：写法最简洁，但完全依赖系统调用栈，树很深时有栈溢出风险，也学不到「进阶」要求的迭代能力。建议先用递归理解题意，再用迭代法练手。

### 解法三：Morris 中序遍历（官方方法三，O(1) 空间，进阶了解）

Morris 遍历的精髓是：**利用树里大量空闲的 `right` 指针（叶子节点和只有左孩子的节点的右孩子都是空），临时把它们改造成「回指祖先」的线索**，从而**不用栈、也不用递归**就能在 O(1) 额外空间完成中序遍历。代价是遍历过程中要**临时修改树的结构**（访问完再还原）。

核心思路：对每个节点，先找它的**中序前驱**（左子树里最靠右的那个节点）。

- 若前驱的 `right` 是空：把前驱的 `right` 指向当前节点（建立「线索」），然后当前节点往左走。
- 若前驱的 `right` 已经指向当前节点：说明左子树已经访问完了（线索是上次留下的），**断开线索**，访问当前节点，然后往右走。
- 若当前节点没有左孩子：直接访问当前节点，往右走。

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> res;
        TreeNode* predecessor = nullptr;  // 中序前驱节点
        while (root != nullptr) {
            if (root->left != nullptr) {
                // 找前驱：先向左走一步，再一路向右走到底
                predecessor = root->left;
                while (predecessor->right != nullptr && predecessor->right != root) {
                    predecessor = predecessor->right;
                }
                if (predecessor->right == nullptr) {
                    // 还没建线索：建一条回指 root 的线索，然后往左走
                    predecessor->right = root;
                    root = root->left;
                } else {
                    // 线索已存在：左子树访问完了，断开线索，访问 root，往右走
                    res.push_back(root->val);
                    predecessor->right = nullptr;
                    root = root->right;
                }
            } else {
                // 没有左孩子：直接访问，往右走
                res.push_back(root->val);
                root = root->right;
            }
        }
        return res;
    }
};
```

- **时间**：O(n)。每条边最多被走两次（一次建线索、一次断线索），整体仍是 O(n)。
- **空间**：O(1)，**只用常数个指针**，是三种解法里空间最优的。
- **定位**：面试里考得少，理解「线索二叉树」的思想即可，一般把递归法和迭代法掌握就够用。Morris 适合在「对空间要求极苛刻」或「专门考这个套路」的场景才拿出来。
