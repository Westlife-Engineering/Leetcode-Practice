## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的**先序遍历**，`inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**示例 1：**

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2：**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

**数据范围：**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均**无重复**元素
- `inorder` 均出现在 `preorder`
- `preorder` **保证**为二叉树的前序遍历序列
- `inorder` **保证**为二叉树的中序遍历序列

## 思路

> 本题参考力扣官方「方法一：递归」。

### 前序 / 中序各自长什么样

任意一棵（子）树：

- **前序**：`[ 根 | 左子树前序 | 右子树前序 ]` → 第一个元素一定是根
- **中序**：`[ 左子树中序 | 根 | 右子树中序 ]`

在中序里找到根的位置后：

- 根左边那一段 → 左子树（节点个数可知）
- 根右边那一段 → 右子树

同一棵子树的前序、中序长度相同，所以能把前序也切成「左 / 右」两段，然后递归构造左右子树，挂到根上。

示意（示例 1）：

```
preorder: [3 | 9 | 20,15,7]
           ↑根 左   右子树前序
inorder:  [9 | 3 | 15,20,7]
           左  ↑根  右子树中序
```

### 用哈希表加速「找根」

朴素做法：每次在中序区间里线性扫描找根，最坏会偏慢。

官方做法：先对整段 `inorder` 建一张「值 → 下标」的哈希表，之后每次定位根是 O(1)。题目保证节点值**无重复**，所以可以放心用值当 key。

### 递归边界怎么切

记当前要构造的区间为：

- 前序：`[preL, preR]`
- 中序：`[inL, inR]`

步骤：

1. `preL > preR` → 空树，返回 `nullptr`
2. 根值 = `preorder[preL]`，在哈希表里得到中序下标 `inRoot`
3. 左子树节点数 `sizeLeft = inRoot - inL`
4. 左子树：前序 `[preL+1, preL+sizeLeft]`，中序 `[inL, inRoot-1]`
5. 右子树：前序 `[preL+sizeLeft+1, preR]`，中序 `[inRoot+1, inR]`

## 代码

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    // unordered_map<int, int>：哈希表，key=节点值，value=该值在中序数组中的下标
    // 查找/插入均摊 O(1)；本题节点值无重复，所以一个值只会对应一个下标
    // 注意：不要用 operator[] 去“查是否存在”——不存在时会插入默认值 0，污染表；本题保证存在，用 [] 取值即可
    unordered_map<int, int> index;

    // 在前序区间 [preL, preR]、中序区间 [inL, inR] 上递归建树
    // const vector<int>&：常量引用，只读、不拷贝整段数组（拷贝是 O(n)，会拖慢甚至爆空间）
    TreeNode* myBuildTree(const vector<int>& preorder, const vector<int>& inorder,
                          int preL, int preR, int inL, int inR) {
        if (preL > preR) {
            return nullptr;  // 空区间：没有节点
        }

        // 前序第一个就是当前子树的根
        int preRoot = preL;
        // index[val]：返回 val 在中序中的下标（均摊 O(1)）
        int inRoot = index[preorder[preRoot]];

        // new TreeNode(x)：在堆上分配节点，力扣环境会接管内存，提交代码一般不用手动 delete
        TreeNode* root = new TreeNode(preorder[preRoot]);

        // 左子树节点个数 = 中序里根左边有多少个
        int sizeLeft = inRoot - inL;

        // 左：前序从根后一位起取 sizeLeft 个；中序从 inL 到 inRoot-1
        root->left = myBuildTree(preorder, inorder,
                                 preL + 1, preL + sizeLeft,
                                 inL, inRoot - 1);
        // 右：前序剩下那段；中序从 inRoot+1 到 inR
        root->right = myBuildTree(preorder, inorder,
                                  preL + sizeLeft + 1, preR,
                                  inRoot + 1, inR);
        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = static_cast<int>(preorder.size());  // vector::size() 返回 size_t（无符号），转成 int 方便当下标算
        // 建「中序值 → 下标」映射；index[key] = i：不存在则插入，存在则覆盖（本题无重复）
        for (int i = 0; i < n; ++i) {
            index[inorder[i]] = i;
        }
        return myBuildTree(preorder, inorder, 0, n - 1, 0, n - 1);
    }
};
```

## 复杂度

- 时间：O(n)。每个节点恰好创建一次；建哈希表扫一遍中序 O(n)；定位根 O(1)。
- 空间：O(n)。哈希表 O(n)；递归栈 O(h)，最坏退化成链时 h = n；答案树本身也要 O(n)。

## 复盘

### 可迁移套路

- **前序定根，中序定左右边界**：凡是「用两种遍历序列还原二叉树」（前+中、后+中）都是同一套分治。
- **值唯一时，用哈希表把「找位置」从 O(n) 降到 O(1)**。
- 递归参数用**下标区间**，不要每次 `vector` 切片拷贝（Python 切片写法思路清晰，但 C++ 里拷贝很贵）。

### 解法二：迭代（官方方法二）

用栈维护「还没考虑过右儿子的祖先」；用指针扫中序。前序相邻两点要么是「栈顶的左儿子」，要么是「栈里某祖先的右儿子」。

```cpp
class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        // vector::empty() / size()：判空与长度；这里 !preorder.size() 等价于 empty()
        if (preorder.empty()) {
            return nullptr;
        }
        TreeNode* root = new TreeNode(preorder[0]);
        // stack<TreeNode*>：栈，存指针；push/pop/top 均摊 O(1)
        // 语义：当前节点的所有「还没考虑过右儿子」的祖先，栈顶=当前节点
        stack<TreeNode*> stk;
        stk.push(root);
        int inorderIndex = 0;  // 指向中序中「当前不断往左走最终应到达」的位置

        // 从第二个前序节点开始枚举
        for (int i = 1; i < static_cast<int>(preorder.size()); ++i) {
            int preorderVal = preorder[i];
            TreeNode* node = stk.top();  // stack::top()：返回栈顶引用，不弹出
            if (node->val != inorder[inorderIndex]) {
                // 还没走到栈顶对应的中序位置 → 当前值只能是栈顶的左儿子
                node->left = new TreeNode(preorderVal);
                stk.push(node->left);
            } else {
                // 栈顶已在中序中对上 → 不断弹栈并右移中序指针，最后一个弹出的接右儿子
                // stack::empty()：是否为空；pop()：弹出栈顶，无返回值
                while (!stk.empty() && stk.top()->val == inorder[inorderIndex]) {
                    node = stk.top();
                    stk.pop();
                    ++inorderIndex;
                }
                node->right = new TreeNode(preorderVal);
                stk.push(node->right);
            }
        }
        return root;
    }
};
```

- 时间 O(n)，空间 O(h)（栈），最坏 O(n)。
- 比递归更绕，初学优先把「方法一」写熟即可。
