# Leetcode-Practice

个人 LeetCode 刷题笔记仓库，围绕 [力扣 Hot 100](https://leetcode.cn/studyplan/top-100-liked/) 按题型整理，主要使用 **C++17**，用于学习算法、记录卡点和复盘，也包含部分机试变体练习。

目前已整理 **100 道题的笔记**，覆盖 **16 个题型目录**。这里的完成度指笔记整理进度，不代表个人刷题通过率或熟练程度；详细清单见 [进度.md](./进度.md)。

## 内容特点

- **不只存代码**：笔记通常包含题目描述、解题思路、代码、复杂度、疑惑 / 卡点和复盘。
- **重视 C++ 基础**：对 STL 容器、方法、返回值和常见副作用提供详细注释。
- **对照官方题解学习**：笔记附力扣链接，主解优先参考官方题解，复盘中补充解法对比和可迁移的套路。
- **兼顾机试练习**：部分笔记在文末追加变体，讨论返回类型、输入输出、下标约定和自测数据。

## 阅读与练习

1. 从题型目录或 [进度.md](./进度.md) 找到题目，通过笔记中的力扣链接读题并独立尝试。
2. 对照「思路」和「代码」检查解法，重点理解边界条件、复杂度和 STL 用法。
3. 在 [练习/playground.cpp](./练习/playground.cpp) 中手写代码、自测，再回到力扣提交。
4. 将疑问和易错点记入对应笔记，复习时优先看「疑惑 / 卡点」和「复盘」。

可以先从 [哈希/1-两数之和.md](./哈希/1-两数之和.md) 或 [动态规划/322-零钱兑换.md](./动态规划/322-零钱兑换.md) 开始，了解笔记的组织方式。

### 本地运行说明

阅读笔记无需安装依赖，直接使用 GitHub 或 VS Code 的 Markdown 预览即可。本仓库不是统一构建的程序项目，没有统一的构建系统或测试套件。

本地练习需要自行准备支持 **C++17** 的编译器，例如 GCC、Clang 或 MSVC：

- 正文代码通常是力扣提交格式，包含 `Solution` 类，不包含完整的本地运行入口。
- 本地运行时需要补齐头文件、`main` 和测试数据；提交到力扣时保留题目要求的类与方法签名。
- 使用 MSVC 时不要依赖 `bits/stdc++.h`，应按需包含标准头文件。
- [练习/playground.cpp](./练习/playground.cpp) 是可反复修改的草稿，不是所有题目的自动化测试或标准答案集合。
