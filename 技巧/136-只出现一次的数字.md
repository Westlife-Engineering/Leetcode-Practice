# 136 只出现一次的数字

- 难度：简单
- 标签：**位运算**、数组
- 力扣链接：https://leetcode.cn/problems/single-number/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[只出现一次的数字](https://leetcode.cn/problems/single-number/solution/zhi-chu-xian-yi-ci-de-shu-zi-by-leetcode-solution/)」。正文主解是 **位运算（异或）**，O(n) 时间 O(1) 空间，是本题的「最优解」；用哈希表计数的 O(n) 时间 O(n) 空间做法放在「复盘」作对比。

## 题目描述

给你一个 **非空** 整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法**只使用常量额外空间**。

**示例 1：**

```
输入：nums = [2,2,1]
输出：1
```

**示例 2：**

```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**

```
输入：nums = [1]
输出：1
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

## 思路

> 本题主要参考力扣官方题解「方法一：位运算」。

题目的核心条件是「**其余每个元素均出现两次，只有 1 个元素出现一次**」。这个「成对出现 + 一个落单」的结构，正是**异或（XOR）**运算的天然适用场景。

### 异或运算的三个性质（本题的全部基础）

异或写作 `^`（C++ 里就是位运算符 `^`），按位运算：两个二进制位相同得 0，不同得 1。它有三个关键性质：

1. **任何数和 0 异或，结果还是它自己**：`a ^ 0 = a`。
2. **任何数和自己异或，结果是 0**：`a ^ a = 0`。
3. **异或满足交换律和结合律**：`a ^ b ^ a = b ^ a ^ a = b ^ (a ^ a) = b ^ 0 = b`。换句话说，**异或的顺序可以任意打乱**，结果不受影响。

### 把性质串起来：全部异或一遍就能找出落单的数

假设数组里有 `2m + 1` 个数：`m` 个数各出现两次（记为 `a₁, a₂, ..., a_m`），1 个数出现一次（记为 `a_{m+1}`）。

把整个数组所有元素**依次异或起来**，由性质 3（可任意交换顺序），结果一定能整理成：

```
(a₁ ^ a₁) ^ (a₂ ^ a₂) ^ ... ^ (a_m ^ a_m) ^ a_{m+1}
```

由性质 2，每个 `a_i ^ a_i = 0`，所以前 `m` 对全部抵消成 0：

```
0 ^ 0 ^ ... ^ 0 ^ a_{m+1}
```

再由性质 1，`0 ^ a_{m+1} = a_{m+1}`。**最终剩下的，就是那个只出现一次的数。**

一句话总结：**成对出现的数互相异或会「抵消」成 0，落单的那个没法配对，所以原封不动地留了下来**。

### 为什么是 O(1) 空间？

整个过程只用一个累加变量 `ans` 从头异或到尾，不需要哈希表、不需要排序、不需要新数组。这就是题目「**只使用常量额外空间**」要求的正解。

### 用示例手动推导一遍

`nums = [4,1,2,1,2]`（`ans` 初始化为 0）：

```
ans = 0
ans = 0 ^ 4 = 4              ← 性质 1：0 ^ a = a
ans = 4 ^ 1 = 5              ← 4(100) ^ 1(001) = 5(101)
ans = 5 ^ 2 = 7              ← 5(101) ^ 2(010) = 7(111)
ans = 7 ^ 1 = 6              ← 7(111) ^ 1(001) = 6(110)，把之前那个 1 抵消掉了
ans = 6 ^ 2 = 4              ← 6(110) ^ 2(010) = 4(100)，再把之前那个 2 抵消掉了
返回 4 ✓
```

注意每一步中间结果看起来乱七八糟（4→5→7→6→4），但**最终一定回到落单的 4**——这就是异或的神奇之处：成对的数迟早会两两相遇并抵消，唯独落单的那个永远找不到伴侣，最后留在结果里。

## 代码

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        // ans：累加异或的结果，初始化为 0。
        //   - 为什么是 0 不是别的？因为性质 a ^ 0 = a：
        //     第一个元素 nums[0] 异或 0 还是 nums[0] 自己，不会污染结果。
        //     若初始化成别的值 v，最终结果会变成 v ^ (落单数)，多出一个 v，就错了。
        //   - 这个变量既是「累计器」也是最终答案：成对的抵消成 0，0 ^ 落单数 = 落单数。
        int ans = 0;

        // 范围 for 循环：依次取出 nums 的每个元素。
        //   - const int num：只读拷贝，对 int 没性能差异（写 auto num 也行）。
        //   - 异或运算 ^ 是 C++ 的位运算符（不是逻辑运算符），
        //     逐位比较：两位相同得 0、不同得 1。对 int 是 O(1)（32 位一次算完）。
        //   - ans ^= num 等价于 ans = ans ^ num：
        //     把当前数异或进累计器。由交换律结合律，处理顺序无所谓，
        //     成对的数迟早会两两相遇抵消（a ^ a = 0），落单数没有伴侣，最终留下。
        for (const int num : nums) {
            ans ^= num;
        }

        // 此时 ans 里只剩下那个无法配对、出现一次的数，直接返回。
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n)
  - 只遍历数组一遍，每次做一次异或（O(1)），共 n 次。
- **空间**：O(1)
  - 只用了 `ans` 一个变量，没有开哈希表或新数组，满足题目「常量额外空间」要求。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：异或为什么能找出「只出现一次」的数？原理再讲一遍。

核心就两条性质组合：**`a ^ a = 0`（成对抵消）** 和 **`a ^ 0 = a`（落单保留）**，再配合**交换律结合律**（顺序不影响）。

把全部数异或起来后，由于顺序可任意重排，所有「出现两次」的数都能配成对，每对异或成 0；而那个只出现一次的数找不到伴侣，跟 0 异或后保持原值。所以最终结果就是它。

**前提是「其余元素恰好出现两次」**——如果改成「其余出现三次」或「其余出现奇数次」，这个简单异或就失效了（见 Q3）。

### Q2：`a ^ a = 0` 是怎么来的？从二进制角度理解。

异或的定义是「**逐位比较，相同为 0、不同为 1**」。`a` 和 `a` 完全一样，每一位都相同，所以每一位异或结果都是 0，整体就是 0。

举例 `5 ^ 5`：

```
  5 = 101
  5 = 101
  -------  逐位异或
      000  = 0
```

同理 `a ^ 0 = a`：任何位和 0 比，相同得 0（保持原位的 0）、不同得 1（保持原位的 1），所以等于原数本身。这也是为什么初始化累加器要给 0：`0` 是异或运算的**单位元**（类似加法里的 0、乘法里的 1）。

### Q3：如果题目改成「其余元素出现 3 次」，这个方法还管用吗？

**不管用。** 异或（`^`）本质上是「**模 2 计数**」——每个数贡献它出现的次数，对 2 取模。出现 2 次 → 抵消成 0；出现 1 次 → 保留。出现 3 次的话，3 mod 2 = 1，会被错误地当成「出现 1 次」保留下来，结果就错了。

「其余出现 3 次，找出现 1 次的」是另一道经典题 **[137. 只出现一次的数字 II](https://leetcode.cn/problems/single-number-ii/)**，需要用「**模 3 计数**」——通常做法是：对每一个二进制位，统计整个数组里该位为 1 的个数，对 3 取模，剩下的就是落单数对应那一位的值。也可以用「状态机两次异或」的技巧（`once = (once ^ x) & ~twice; twice = (twice ^ x) & ~once;`）。结论：**简单异或只适用于「恰好出现两次」**。

### Q4：数组里元素的顺序会影响结果吗？

**不会。** 由异或的交换律和结合律（性质 3），无论按什么顺序异或，结果都一样。前面手推 `[4,1,2,1,2]` 时中间值一路乱跳（4→5→7→6→4），但最终都能回到 4，正是因为「抵消」只取决于「哪些数成对、哪个落单」，与先后顺序无关。

这也是为什么代码敢放心地一趟 `for` 扫过去，不用先排序、不用挑顺序。

## 复盘

- **核心套路**：**「一堆数里有成对出现的、还有几个落单的」** → 想到 **异或（XOR）找落单 / 抵消成对**。一次遍历、一个累加变量、O(n) 时间 O(1) 空间，是这类题的最优解。本题是这条套路最干净的代表。
- **异或的本质记忆点**：
  - `a ^ a = 0`（成对抵消）
  - `a ^ 0 = a`（落单保留）
  - 0 是异或的单位元（累加器初始化为 0）
  - 满足交换律、结合律（顺序无所谓）
- **适用边界**：只适用于「**其余元素恰好出现偶数次（一般 2 次）**」。出现 3 次 / 奇数次要换「按位模计数」或状态机（见 137 题），不可硬套异或。
- **可迁移场景**：交换两个变量不用临时变量（`a ^= b; b ^= a; a ^= b;`）、找缺失的数（把「应有的」和「实际的」一起异或，缺失的那个会留下）、判断两数符号是否相同（`a ^ b < 0` 则异号）。都是「抵消成对 / 找不同」这一思路的延伸。

### 解法二：哈希表计数（对比用，非主解）

最直观的通用做法：用哈希表统计每个数出现的次数，再扫一遍哈希表找出次数为 1 的那个。优点是好想、对「出现 3 次 / k 次」也能扩展；缺点是**空间 O(n)**，不满足本题「常量额外空间」的进阶要求。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        // unordered_map<int,int>：哈希表，key 是数值，value 是出现次数。
        //   - 查找/插入均摊 O(1)，比 map（红黑树 O(log n)）快。
        //   - 这里只做精确查找和计数，不需要按 key 排序，故选 unordered_map。
        unordered_map<int, int> count;

        // 第一趟：计数。
        //   - count[num]++：num 不存在时先自动插入默认值 0，再 +1（[] 的副作用正好用上）。
        for (const int num : nums) {
            count[num]++;
        }

        // 第二趟：找次数为 1 的数。
        //   - for (const auto &[k, v] : count)：结构化绑定（C++17），
        //     k 是 key、v 是 value，比写 pair.first/pair.second 直观。
        for (const auto &[k, v] : count) {
            if (v == 1) {
                return k;
            }
        }
        return 0;  // 题目保证有解，不会执行。
    }
};
```

- **时间**：O(n)——两趟遍历，每趟哈希操作均摊 O(1)。
- **空间**：O(n)——最坏情况下哈希表存了约 `n/2 + 1` 个不同元素。
- **对比**：哈希表法**通用性强**（出现 3 次、k 次都能改 `v == 1` 的判断），但**空间不是 O(1)**；异或法**空间最优**但**只适用于「恰好出现两次」**。本题要求 O(1) 空间，正解是异或。
