# 42 接雨水

- 难度：困难
- 标签：栈、数组、双指针、动态规划、**单调栈**
- 力扣链接：https://leetcode.cn/problems/trapping-rain-water/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题有多种解法（暴力、DP、单调栈、双指针）。正文主解是 **双指针 O(1) 空间**（和本目录主题对应）；DP、单调栈见文末「复盘」。

## 题目描述

给定 `n` 个非负整数表示每个柱子的高度图，计算按此排列的柱子，下雨后能接多少雨水。

**示例 1：**

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
```

**示例 2：**

```
输入：height = [4,2,0,3,2,5]
输出：9
```

**数据范围：**

- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

## 思路

> 本题参考力扣题解的双指针做法。
> 注：题解页动态渲染，初稿是双指针经典解法。

### 关键观察：每个位置能接多少水？

对于下标 `i` 处的柱子，**它上方能接的水量**取决于它左右两侧的最高柱子：

```
water[i] = max(0, min(left_max[i], right_max[i]) - height[i])
                  └───────────┬───────────┘
                  两侧最高柱子中的较矮者（木桶效应）
                                └────────────┘
                                减去自己占的高度
```

> 类比"木桶效应"：水会从两侧最矮的那条边溢出，所以水位 = 两侧最高中的较矮者。
> 当前柱子能接的水 = 水位 - 自己的高度（若为负则接 0）。

### 暴力想法（O(n²)）

对每个 `i`，分别向左扫找 `left_max`，向右扫找 `right_max`，再算 `water[i]`。超时。

### DP 预处理（O(n) 时间、O(n) 空间）

提前用两个数组 `left_max[]` 和 `right_max[]` 存好每个位置左侧/右侧的最大值。细节与代码见「复盘」。

### 单调栈（O(n) 时间、O(n) 空间）

换一种视角：不按「每个位置能接多少」，而是按「每次弹出栈顶时，与左右墙形成的凹槽能接多少」。细节与代码见「复盘」。

### 双指针（O(n) 时间、**O(1) 空间**）

**核心想法**：能不能不算两个完整的 `left_max[]` 和 `right_max[]` 数组，而是**边走边维护**两个变量？

**关键 trick**：维护两个变量 `left_max`、`right_max`，分别表示"目前左指针扫过的最大值"和"右指针扫过的最大值"。

- 哪边的 `max` 较小，就处理哪边的指针：
  - 若 `left_max < right_max`：处理左指针 `left`。因为对 `left` 来说，它的**右侧一定有一个比 `left_max` 更高的柱子**（否则 `right_max` 不会更大），所以它的**水位由 `left_max` 决定**，可以直接算。
  - 否则处理右指针 `right`，对称同理。
- 这样不需要完整数组，**两个变量就够了**。

**为什么这是对的？**

核心是：**当 `left_max < right_max` 时，`left` 处的水量已经完全由 `left_max` 决定**，跟右边更具体的高度无关——因为我们已经知道右边有一个 ≥ `right_max` > `left_max` 的柱子在等着"挡水"。所以可以放心算 `water[left]` 然后右移 left。

## 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = (int)height.size();
        int ans = 0;

        // 双指针：left、right 从两端向中间收拢。
        int left = 0;
        int right = n - 1;

        // left_max：左指针扫过的柱子里的最大高度（含 left 当前位置）。
        // right_max：右指针扫过的柱子里的最大高度（含 right 当前位置）。
        //   - 初始化为 0，扫到更高的就更新。
        int left_max = 0;
        int right_max = 0;

        while (left < right) {
            // 始终处理"较矮一侧"的指针：
            //   - 哪边 max 较小，就处理哪边，因为那边的位置水位已确定。
            if (height[left] < height[right]) {
                // 左侧较矮：对 left 来说，右边一定有 height[right] 或更高的挡着，
                //   所以 left 处水位 = left_max（左侧已知最高）。
                if (height[left] >= left_max) {
                    // 当前柱子比 left_max 还高 → 更新 left_max，不接水。
                    left_max = height[left];
                } else {
                    // 当前柱子比 left_max 矮 → 能接 (left_max - height[left]) 的水。
                    ans += left_max - height[left];
                }
                ++left;
            } else {
                // 对称地处理右指针。
                if (height[right] >= right_max) {
                    right_max = height[right];
                } else {
                    ans += right_max - height[right];
                }
                --right;
            }
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n)
  - 两指针一共最多移动 n 次。
- **空间**：O(1)
  - 只用了常数个变量（`left`, `right`, `left_max`, `right_max`, `ans`）。这是双指针相对 DP 解法的最大优势。

## 复盘

- **核心套路**：每个位置能接的水量 = `min(左侧最高, 右侧最高) - 当前高度`。难点在如何 O(n) 求两侧最高。
- **四种解法对比**：

  | 解法 | 时间 | 空间 | 关键 |
  |---|---|---|---|
  | 暴力 | O(n²) | O(1) | 每个 i 双向扫描 |
  | DP 预处理 | O(n) | O(n) | 两个数组 `left_max[]`、`right_max[]` |
  | 单调栈 | O(n) | O(n) | 维护下标单调递减栈，按「层」接水 |
  | **双指针** | O(n) | **O(1)** | 边走边维护 max，靠"较小侧已确定"的洞察省下数组 |

- **关键 trick**：**当 `left_max < right_max`，left 处水位已由 `left_max` 决定**，因为右边一定有更高的柱子在挡着——这就是双指针 O(1) 空间的根本来源。
- **类比**：和 [11 盛最多水](./11-盛最多水的容器.md) 一样用"木桶效应"思想，但本题是逐位置算水，那题是选两条边围容器。两题都用左右双指针 + 移动较矮边，**思想相通**。

### 解法二：DP 预处理

**思路**：把暴力里「每次向左/向右扫找最大值」预处理成两个数组，每个位置 O(1) 查两侧最高。

```
left_max[i]  = max(height[0..i])     // 含 i 自己
right_max[i] = max(height[i..n-1])   // 含 i 自己
water[i]     = min(left_max[i], right_max[i]) - height[i]
```

递推：

- `left_max[0] = height[0]`，`left_max[i] = max(left_max[i-1], height[i])`
- `right_max[n-1] = height[n-1]`，`right_max[i] = max(right_max[i+1], height[i])`

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = (int)height.size();
        if (n == 0) return 0;

        // vector<int> left_max(n)：长度为 n 的整型动态数组，初始值全为 0。
        //   - 构造签名：vector(size_type count) → 创建 count 个默认值元素。
        //   - left_max[i] 含义：下标 0..i 中的最大高度（含 i）。
        vector<int> left_max(n);
        // right_max[i]：下标 i..n-1 中的最大高度（含 i）。
        vector<int> right_max(n);

        left_max[0] = height[0];
        // 从左往右扫：当前位置的左侧最高 = max(前一个位置的左侧最高, 自己)。
        for (int i = 1; i < n; ++i) {
            // max(a, b)：<algorithm> 里的函数，返回两者较大值；力扣环境默认可用。
            left_max[i] = max(left_max[i - 1], height[i]);
        }

        right_max[n - 1] = height[n - 1];
        // 从右往左扫：对称地填 right_max。
        for (int i = n - 2; i >= 0; --i) {
            right_max[i] = max(right_max[i + 1], height[i]);
        }

        int ans = 0;
        for (int i = 0; i < n; ++i) {
            // 水位 = 两侧最高中的较矮者；减掉柱子自身高度就是接水量。
            // 因为 left_max / right_max 都含自己，所以结果一定 ≥ 0，不用再 max(0, ...)。
            ans += min(left_max[i], right_max[i]) - height[i];
        }
        return ans;
    }
};
```

- **时间**：O(n)——三次线性扫描。
- **空间**：O(n)——两个辅助数组。双指针正是在此基础上把数组压成两个变量。

### 解法三：单调栈

**思路切换**：前面是「按列」算每个位置的水；单调栈是「按行 / 按层」——维护一根**下标单调递减**的栈（栈内对应高度递减）。遇到更高柱子时，说明形成了凹槽，弹出栈顶作为坑底，用左右两堵墙算这一层能接的水。

示意（栈里存下标，高度递减）：

```
栈里 ... left, mid,  来了一个更高的 right
         ↑墙    ↑坑底          ↑右墙（当前柱）
这一层接水量 = (min(height[left], height[right]) - height[mid]) * (right - left - 1)
```

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = (int)height.size();
        int ans = 0;

        // stack<int> st：栈，元素类型 int（这里存柱子下标，不是高度）。
        //   - 空构造：stack() → 默认底层容器是 deque<int>。
        //   - 本题维护「下标对应高度单调递减」：栈顶是当前最矮的、尚未找到右墙的柱子。
        //   - 常用操作：
        //       st.push(x) / st.emplace(x)：入栈；emplace 少一次临时对象构造。
        //       st.top()：返回栈顶引用，不弹出；空栈时调用是未定义行为。
        //       st.pop()：弹出栈顶，无返回值；空栈时调用是未定义行为。
        //       st.empty()：是否为空，O(1)。
        //   - 每个下标最多入栈、出栈各一次 → 均摊 O(1)，总时间 O(n)。
        stack<int> st;

        for (int i = 0; i < n; ++i) {
            // 当前柱子比栈顶更高 → 栈顶是一个「坑」，可以被当前柱子封住右边界。
            // while：可能连续弹出多个更矮的坑底（一层层往上填水）。
            while (!st.empty() && height[i] > height[st.top()]) {
                int mid = st.top();  // 坑底下标
                st.pop();
                if (st.empty()) {
                    // 左边没有墙了，接不住水。
                    break;
                }
                int left = st.top();  // 左墙下标（弹出 mid 后的新栈顶）
                int h = min(height[left], height[i]) - height[mid];  // 这一层的高度
                int w = i - left - 1;                                 // 这一层的宽度
                ans += h * w;
            }
            // 当前柱子入栈，等待以后可能成为别人的左墙 / 坑底。
            st.push(i);
        }
        return ans;
    }
};
```

- **时间**：O(n)——每个下标进出栈各一次。
- **空间**：O(n)——最坏整列递减，栈里塞满 n 个下标。
- **和 DP / 双指针的区别**：DP、双指针按列算 `water[i]`；单调栈按「凹槽的一层」算面积，适合体会「单调栈处理下一个更大元素 / 围成区间」的套路。

- **STL 要点小结**：
  - 双指针主解几乎只用基础变量。
  - DP：`vector<int>(n)` 预分配长度；`min` / `max`。
  - 单调栈：`stack<int>` 存下标；注意 `top`/`pop` 前先判 `empty()`。
