# 15 三数之和

- 难度：中等
- 标签：数组、双指针、排序
- 力扣链接：https://leetcode.cn/problems/3sum/?envType=study-plan-v2&envId=top-100-liked

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有在数组 `nums` 中满足条件且**不重复**的三元组。

**注意**：答案中不可以包含重复的三元组。

**示例 1：**

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
```

**示例 2：**

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

**示例 3：**

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

**数据范围：**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 思路

> 本题参考力扣题解列表中的「排序 + 双指针」做法。
> 注：题解列表页动态渲染，初稿代码是这道题最标准的「排序 + 双指针」解法；如需对齐某篇特定题解再贴 URL 替换。

### 暴力想法（O(n³)，必超时）

三层循环枚举所有三元组，判断 sum == 0。再加去重。显然太慢。

### 双指针优化（O(n²)）

**核心思路**：把"三数之和"转化为"两数之和"。

1. **先排序**：`sort(nums)` → O(n log n)，让数组从小到大排列，方便双指针和去重。
2. **枚举第一个数 `nums[i]`**（外层 for）。
3. **对剩下的部分 `[i+1, n)`，用双指针找两个数 `nums[j] + nums[k] = -nums[i]`**：
   - `left = i + 1`、`right = n - 1`；
   - 当前和 `s = nums[i] + nums[left] + nums[right]`：
     - `s < 0` → 太小，`left++`；
     - `s > 0` → 太大，`right--`；
     - `s == 0` → 找到一组，记下来，然后 `left++`、`right--` 继续找。
4. **去重**（排序后好处理）：
   - `nums[i] == nums[i-1]` → 跳过（同样的第一个数之前已搜过）；
   - 找到一组后，`nums[left] == nums[left+1]` 时 `left++`；`nums[right] == nums[right-1]` 时 `right--`。

### 几个关键剪枝

- 如果 `nums[i] > 0`，因为数组已排序，后面三个数必然都 > 0，sum 不可能等于 0 → **提前结束**。
- 外层跳过相同的 `nums[i]`，避免重复答案。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;          // 收集所有满足条件的三元组

        // sort(begin, end)：STL 排序算法，默认升序，就地排序，O(n log n)。
        //   - 排序后：① 双指针移动方向有依据（小→左移右，大→右移左）；
        //             ② 重复元素相邻，方便去重。
        sort(nums.begin(), nums.end());

        int n = (int)nums.size();

        // 外层：枚举三元组的第一个数 nums[i]。
        //   - i 最多到 n-3（后面还要留两个数给 left、right），所以 i < n - 2。
        for (int i = 0; i < n - 2; ++i) {
            // 剪枝 1：nums[i] 是当前最小值，>0 说明剩下的三个数都 > 0，sum 必 > 0。
            if (nums[i] > 0) break;

            // 去重 1：当前 nums[i] 和上一个 nums[i-1] 相同时跳过，
            //   - 因为相同的第一个数之前已经搜完，再做一遍会产生重复三元组。
            //   - 注意 i > 0 是为了防止越界（i=0 时没有 i-1）。
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            // 双指针：left、right 分别指向 i+1 和 n-1。
            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    // 和太小 → 需要变大，左指针右移（数组已排序，nums[left+1] >= nums[left]）。
                    ++left;
                } else if (sum > 0) {
                    // 和太大 → 需要变小，右指针左移。
                    --right;
                } else {
                    // sum == 0，找到一组解。
                    //   - push_back({a, b, c})：把一个三元组追加到 ans 末尾。
                    //   - 这里用 push_back 是因为元素已经齐了；emplace_back 也行。
                    ans.push_back({nums[i], nums[left], nums[right]});

                    // 去重 2：跳过 left 重复值。
                    //   - 注意 while 条件里 left < right，防止越界。
                    while (left < right && nums[left] == nums[left + 1]) ++left;
                    // 去重 3：跳过 right 重复值。
                    while (left < right && nums[right] == nums[right - 1]) --right;

                    // 找到一组后两指针都要动，否则会死循环。
                    ++left;
                    --right;
                }
            }
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n²)
  - 排序 O(n log n)；外层 for O(n)，每次 for 内的双指针总共 O(n)，所以双指针部分合计 O(n²)。
  - 总体 O(n²)（n² 主导 n log n）。
- **空间**：O(log n)
  - 排序的栈空间（不算返回的 ans）。

## 复盘

- **核心套路**：三数之和 → **排序 + 双指针**，把 3Sum 转成 "枚举一个数 + 两数之和的双指针"。
- **关键 trick**：
  1. **先排序**——既让双指针有移动依据，又让重复元素相邻便于去重。
  2. **三处去重**——`nums[i]` 跳过相同、找到答案后跳过 `nums[left]` 和 `nums[right]` 的连续重复值。
  3. **提前剪枝**——`nums[i] > 0` 直接 break。
- **易错点**：
  - 去重时下标别越界（`i > 0`、`left < right` 守卫）。
  - `sum == 0` 后两指针**都要**移动，否则死循环。
  - 注意 `left` 起点 `i+1` 而不是 `0`，避免重复使用同一个元素。
- **STL 要点**：
  - `sort(begin, end)`：升序就地排序，O(n log n)。
  - `vector::push_back({...})`：可以直接用花括号初始化塞一个临时 vector 进去。
  - `emplace_back` vs `push_back`：复杂对象 emplace 更高效；本题三元组规模小，用哪个都行。
