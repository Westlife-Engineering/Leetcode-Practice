## 一、二叉树：表示、遍历与重建

### 核心约定

每个结点保存整数值和左右孩子指针，`0` 表示没有孩子。空树的根指针为 `0`。结点只由 `BinaryTree` 创建和销毁，不向调用者暴露可修改的结点指针。

| 接口 | 返回结果与副作用 |
|---|---|
| `buildFromPreIn(preorder, inorder)` | 用前序和中序重建；成功为 `true`，不合法为 `false` |
| `buildFromInPost(inorder, postorder)` | 用中序和后序重建；返回约定相同 |
| 六个前/中/后序接口、`levelorder()` | 返回遍历结果 `vector<int>`；空树返回空数组，不修改树 |
| `empty()` | 是否为空树 |
| `clear()` / 析构函数 | 后序销毁全部结点；反复清空也安全 |

两种构建都先释放旧树，所以失败后是空树，**不会保留上一次构建的结果**。递归中发现非法序列时先停止继续分配，再由公共接口统一释放已接上的部分树。

重建要求两序列长度相同、结点值互异、描述同一棵树。空序列配空序列是合法空树。程序检查中序重复值、找不到根、根不在当前中序区间等情况；另一条序列的重复值也会被区间检查拒绝。

- 前序是“根、左、右”：每次顺序取根，按中序位置分出左右子树，再先建左、后建右。
- 后序是“左、右、根”：从末尾逆序取根，必须先建右、后建左。
- 中序区间统一为左闭右开 `[left, right)`，`left == right` 是空子树。
- 预先用 `std::unordered_map<int, int>` 保存“值 → 中序下标”，避免在每个递归调用中线性寻找根。散列查找期望常数时间，整次重建期望 $O(n)$；若严重散列冲突，每次查找可能退化为 $O(n)$，总时间最坏 $O(n^2)$。逐次扫描中序区间的写法最坏也是 $O(n^2)$。
- 即使结点值互异，只有前序和后序一般仍不能唯一重建：前序 `1 2`、后序 `2 1` 无法区分 `2` 是左孩子还是右孩子。

### 完整程序 1

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <queue>
#include <unordered_map>
#include <cassert>

class BinaryTree {
private:
    struct Node {
        int value;
        Node* left;
        Node* right;

        explicit Node(int nodeValue)
            : value(nodeValue), left(0), right(0) {}
    };

    Node* root;

    BinaryTree(const BinaryTree&);
    BinaryTree& operator=(const BinaryTree&);

    static void destroy(Node* current) {
        if (current == 0) {
            return;
        }
        destroy(current->left);
        destroy(current->right);
        delete current;
    }

    static bool indexInorder(
        const std::vector<int>& inorder,
        std::unordered_map<int, int>& positions) {
        // unordered_map<int, int> 的键是结点值，值是中序下标；键没有排序保证。
        for (int index = 0; index < static_cast<int>(inorder.size()); ++index) {
            // find(key) 返回迭代器；end() 表示未找到，不能解引用；查找不会插入。
            if (positions.find(inorder[index]) != positions.end()) {
                return false;
            }
            // operator[] 在键不存在时先插入默认值 0，再赋为 index；期望 O(1)。
            positions[inorder[index]] = index;
        }
        return true;
    }

    static Node* buildPre(
        const std::vector<int>& preorder, int& next,
        int left, int right,
        const std::unordered_map<int, int>& positions, bool& valid) {
        if (!valid || left == right) {
            return 0;
        }
        if (next >= static_cast<int>(preorder.size())) {
            valid = false;
            return 0;
        }
        int value = preorder[next++];
        // const_iterator 只能读取表项；first 是键，second 是保存的中序下标。
        std::unordered_map<int, int>::const_iterator found = positions.find(value);
        if (found == positions.end() || found->second < left || found->second >= right) {
            valid = false;
            return 0;
        }
        int middle = found->second;
        Node* current = new Node(value);
        current->left = buildPre(preorder, next, left, middle, positions, valid);
        current->right = buildPre(preorder, next, middle + 1, right, positions, valid);
        return current;
    }

    static Node* buildPost(
        const std::vector<int>& postorder, int& next,
        int left, int right,
        const std::unordered_map<int, int>& positions, bool& valid) {
        if (!valid || left == right) {
            return 0;
        }
        if (next < 0) {
            valid = false;
            return 0;
        }
        int value = postorder[next--];
        std::unordered_map<int, int>::const_iterator found = positions.find(value);
        if (found == positions.end() || found->second < left || found->second >= right) {
            valid = false;
            return 0;
        }
        int middle = found->second;
        Node* current = new Node(value);
        // 逆读后序得到“根、右、左”，不能先递归左子树。
        current->right = buildPost(postorder, next, middle + 1, right, positions, valid);
        current->left = buildPost(postorder, next, left, middle, positions, valid);
        return current;
    }

    static void visitPre(const Node* current, std::vector<int>& result) {
        if (current == 0) {
            return;
        }
        // vector<int> 是连续的整数动态数组；push_back(value) 在末尾追加，摊还 O(1)。
        result.push_back(current->value);
        visitPre(current->left, result);
        visitPre(current->right, result);
    }

    static void visitIn(const Node* current, std::vector<int>& result) {
        if (current == 0) {
            return;
        }
        visitIn(current->left, result);
        result.push_back(current->value);
        visitIn(current->right, result);
    }

    static void visitPost(const Node* current, std::vector<int>& result) {
        if (current == 0) {
            return;
        }
        visitPost(current->left, result);
        visitPost(current->right, result);
        result.push_back(current->value);
    }

public:
    BinaryTree() : root(0) {}

    ~BinaryTree() {
        clear();
    }

    bool empty() const {
        return root == 0;
    }

    void clear() {
        destroy(root);
        root = 0;
    }

    bool buildFromPreIn(const std::vector<int>& preorder,
                        const std::vector<int>& inorder) {
        clear();
        // size() 返回元素个数，其类型是无符号的 size_type；本例约定个数能用 int 表示。
        if (preorder.size() != inorder.size()) {
            return false;
        }
        std::unordered_map<int, int> positions;
        if (!indexInorder(inorder, positions)) {
            return false;
        }
        bool valid = true;
        int next = 0;
        root = buildPre(preorder, next, 0, static_cast<int>(inorder.size()), positions, valid);
        if (!valid || next != static_cast<int>(preorder.size())) {
            clear();
            return false;
        }
        return true;
    }

    bool buildFromInPost(const std::vector<int>& inorder,
                         const std::vector<int>& postorder) {
        clear();
        if (inorder.size() != postorder.size()) {
            return false;
        }
        std::unordered_map<int, int> positions;
        if (!indexInorder(inorder, positions)) {
            return false;
        }
        bool valid = true;
        // 先转 int 再减一，避免空 vector 的无符号 size() - 1 下溢。
        int next = static_cast<int>(postorder.size()) - 1;
        root = buildPost(postorder, next, 0, static_cast<int>(inorder.size()), positions, valid);
        if (!valid || next != -1) {
            clear();
            return false;
        }
        return true;
    }

    std::vector<int> preorderRecursive() const {
        std::vector<int> result;
        visitPre(root, result);
        return result;
    }

    std::vector<int> inorderRecursive() const {
        std::vector<int> result;
        visitIn(root, result);
        return result;
    }

    std::vector<int> postorderRecursive() const {
        std::vector<int> result;
        visitPost(root, result);
        return result;
    }

    std::vector<int> preorderIterative() const {
        std::vector<int> result;
        // stack<const Node*> 保存只读结点指针，后进先出；不拥有也不释放这些结点。
        std::stack<const Node*> pending;
        if (root != 0) {
            pending.push(root);
        }
        // empty() 返回是否为空；top() 取栈顶引用，pop() 删除栈顶但不返回元素。
        while (!pending.empty()) {
            const Node* current = pending.top();
            pending.pop();
            result.push_back(current->value);
            // push(pointer) 将指针压栈；先右后左，保证出栈时先处理左孩子。
            if (current->right != 0) {
                pending.push(current->right);
            }
            if (current->left != 0) {
                pending.push(current->left);
            }
        }
        return result;
    }

    std::vector<int> inorderIterative() const {
        std::vector<int> result;
        std::stack<const Node*> pending;
        const Node* current = root;
        while (current != 0 || !pending.empty()) {
            while (current != 0) {
                pending.push(current);
                current = current->left;
            }
            current = pending.top();
            pending.pop();
            result.push_back(current->value);
            current = current->right;
        }
        return result;
    }

    std::vector<int> postorderIterative() const {
        std::vector<int> result;
        std::stack<const Node*> pending;
        const Node* current = root;
        const Node* lastVisited = 0;
        while (current != 0 || !pending.empty()) {
            if (current != 0) {
                pending.push(current);
                current = current->left;
            } else {
                const Node* candidate = pending.top();
                // 左边已经走完；只有右子树也访问完，才允许输出并弹出父结点。
                if (candidate->right != 0 && lastVisited != candidate->right) {
                    current = candidate->right;
                } else {
                    result.push_back(candidate->value);
                    lastVisited = candidate;
                    pending.pop();
                }
            }
        }
        return result;
    }

    std::vector<int> levelorder() const {
        std::vector<int> result;
        // queue<const Node*> 先进先出；push 加到队尾，front 取队首，pop 删除队首。
        std::queue<const Node*> pending;
        if (root != 0) {
            pending.push(root);
        }
        while (!pending.empty()) {
            // front() 和 pop() 都要求非空；pop() 返回 void，必须先保存队首。
            const Node* current = pending.front();
            pending.pop();
            result.push_back(current->value);
            if (current->left != 0) {
                pending.push(current->left);
            }
            if (current->right != 0) {
                pending.push(current->right);
            }
        }
        return result;
    }
};

void printSequence(const char* label, const std::vector<int>& values) {
    std::cout << label;
    for (std::vector<int>::size_type index = 0; index < values.size(); ++index) {
        // operator[] 返回下标处元素，不检查越界；循环条件保证 index 合法。
        std::cout << ' ' << values[index];
    }
    std::cout << '\n';
}

int main() {
    BinaryTree tree;
    // vector::empty() 返回是否没有元素；容器 == 会逐项比较长度和元素内容。
    assert(tree.empty() && tree.levelorder().empty());
    assert(tree.preorderIterative().empty() && tree.postorderIterative().empty());

    int preorderData[] = {1, 2, 4, 5, 3, 6, 7};
    int inorderData[] = {4, 2, 5, 1, 6, 3, 7};
    int postorderData[] = {4, 5, 2, 6, 7, 3, 1};
    // vector(first, last) 复制左闭右开区间；C 数组指针可充当迭代器，末端不解引用。
    std::vector<int> preorder(preorderData, preorderData + 7);
    std::vector<int> inorder(inorderData, inorderData + 7);
    std::vector<int> postorder(postorderData, postorderData + 7);
    bool success = tree.buildFromPreIn(preorder, inorder);
    assert(success);
    if (!success) {
        return 1;
    }
    assert(tree.preorderRecursive() == preorder);
    assert(tree.inorderRecursive() == inorder);
    assert(tree.postorderRecursive() == postorder);
    assert(tree.preorderIterative() == preorder);
    assert(tree.inorderIterative() == inorder);
    assert(tree.postorderIterative() == postorder);
    printSequence("Preorder:", tree.preorderRecursive());
    printSequence("Inorder:", tree.inorderRecursive());
    printSequence("Postorder:", tree.postorderRecursive());
    printSequence("Levelorder:", tree.levelorder());

    success = tree.buildFromInPost(inorder, postorder);
    assert(success && tree.preorderRecursive() == preorder);
    printSequence("Rebuild from in+post:", tree.levelorder());

    int smallInorderData[] = {1, 2, 3};
    int badPreorderData[] = {2, 3, 1};
    int badPostorderData[] = {3, 1, 2};
    std::vector<int> smallInorder(smallInorderData, smallInorderData + 3);
    std::vector<int> badPreorder(badPreorderData, badPreorderData + 3);
    std::vector<int> badPostorder(badPostorderData, badPostorderData + 3);
    success = tree.buildFromPreIn(badPreorder, smallInorder);
    assert(!success && tree.empty());
    success = tree.buildFromInPost(smallInorder, badPostorder);
    assert(!success && tree.empty());

    int duplicateData[] = {1, 1};
    std::vector<int> duplicates(duplicateData, duplicateData + 2);
    success = tree.buildFromPreIn(duplicates, duplicates);
    assert(!success && tree.empty());

    // vector(count, value) 构造 count 个相同元素，不是迭代器区间构造。
    std::vector<int> single(1, 9);
    success = tree.buildFromInPost(single, single);
    assert(success && tree.postorderIterative() == single);
    std::vector<int> noValues;
    success = tree.buildFromPreIn(single, noValues);
    assert(!success && tree.empty());
    success = tree.buildFromPreIn(noValues, noValues);
    assert(success && tree.empty());
    success = tree.buildFromInPost(noValues, noValues);
    assert(success && tree.inorderIterative().empty());
    tree.clear();
    tree.clear();
    assert(tree.empty());
    std::cout << "BinaryTree checks passed\n";
    return 0;
}
```

### 复杂度与易错点

设结点数为 $n$、树高为 $h$、最大层宽为 $w$。

| 操作 | 时间 | 辅助空间，不计树结点及返回数组 |
|---|---|---|
| 两种重建 | 期望 $O(n)$，散列最坏 $O(n^2)$ | 索引表 $O(n)$，递归栈 $O(h)$ |
| 递归前、中、后序 | $O(n)$ | $O(h)$ |
| 本例单栈式前、中、后序 | $O(n)$ | $O(h)$ |
| 层序遍历 | $O(n)$ | $O(w)$ |
| 销毁 | $O(n)$ | $O(h)$ |

遍历接口返回的数组本身另占 $O(n)$。重建接口还需花 $O(n_{old})$ 时间销毁原树；上表重建时间以待建树为主，不应漏算旧树清理。栈和队列中的指针只是借用，不负责 `delete`；散列表在重建结束后销毁也不会影响树，因为结点保存的是整数副本。

后序销毁必须在两个孩子释放后再释放父结点；删除父结点后不能继续读取它的孩子。单栈后序的 `lastVisited` 是结点指针，不是结点值，用来判断某个右子树是否已经处理完。

## 二、二叉搜索树：查找、插入与删除

### 不变量与接口

二叉搜索树简称 BST。本例采用严格关系：任一结点的左子树键值全小于它，右子树键值全大于它。因此中序遍历应当严格递增。

**重复键策略：不允许重复键，重复插入返回 `false`，树不变。** 不采用“重复值都放右边”或额外计数的策略。所有 `int` 值都可以作为键，没有特殊哨兵值。

| 接口 | 含义 |
|---|---|
| `contains(key)` | 找到返回 `true`，未找到或空树返回 `false` |
| `insert(key)` | 新插入成功返回 `true`，键已存在返回 `false` |
| `erase(key)` | 实际删除一个结点返回 `true`；键不存在或空树返回 `false` |
| `inorder()` | 返回有序的键数组，空树返回空数组 |
| `empty()`、`clear()` | 查询空树、释放全部结点并置为空树 |

删除分三类处理：

1. 叶子：释放结点，返回空指针作为该子树的新根。
2. 一个孩子：保存孩子指针，释放旧结点，让孩子接替旧结点。
3. 两个孩子：找到右子树最小结点，即中序后继；把后继键复制到当前结点，再在右子树中删除后继。后继没有左孩子，所以第二次删除只会落到前两类。

辅助函数返回“修改后的子树根”，必须接回父结点的 `left/right`；公共接口也必须更新 `root`，否则删除根结点时容易留下悬空指针。这里只保存整数键，若结点还带业务数据，替换后继时需连同关联数据一起处理。

### 完整程序 2

```cpp
#include <iostream>
#include <vector>
#include <cassert>

class BinarySearchTree {
private:
    struct Node {
        int key;
        Node* left;
        Node* right;

        explicit Node(int nodeKey) : key(nodeKey), left(0), right(0) {}
    };

    Node* root;

    BinarySearchTree(const BinarySearchTree&);
    BinarySearchTree& operator=(const BinarySearchTree&);

    static void destroy(Node* current) {
        if (current == 0) {
            return;
        }
        destroy(current->left);
        destroy(current->right);
        delete current;
    }

    static Node* insertNode(Node* current, int key, bool& inserted) {
        if (current == 0) {
            inserted = true;
            return new Node(key);
        }
        if (key < current->key) {
            current->left = insertNode(current->left, key, inserted);
        } else if (key > current->key) {
            current->right = insertNode(current->right, key, inserted);
        }
        return current;
    }

    static Node* eraseNode(Node* current, int key, bool& removed) {
        if (current == 0) {
            return 0;
        }
        if (key < current->key) {
            current->left = eraseNode(current->left, key, removed);
        } else if (key > current->key) {
            current->right = eraseNode(current->right, key, removed);
        } else {
            removed = true;
            if (current->left == 0) {
                // 也包含叶子：right 为 0 时，新子树就是空树。
                Node* replacement = current->right;
                delete current;
                return replacement;
            }
            if (current->right == 0) {
                Node* replacement = current->left;
                delete current;
                return replacement;
            }
            Node* successor = current->right;
            while (successor->left != 0) {
                successor = successor->left;
            }
            current->key = successor->key;
            current->right = eraseNode(current->right, successor->key, removed);
        }
        return current;
    }

    static void collectInorder(const Node* current, std::vector<int>& result) {
        if (current == 0) {
            return;
        }
        collectInorder(current->left, result);
        // vector<int> 为连续整数动态数组；push_back(key) 在尾部追加，摊还 O(1)。
        result.push_back(current->key);
        collectInorder(current->right, result);
    }

public:
    BinarySearchTree() : root(0) {}

    ~BinarySearchTree() {
        clear();
    }

    bool empty() const {
        return root == 0;
    }

    void clear() {
        destroy(root);
        root = 0;
    }

    bool contains(int key) const {
        const Node* current = root;
        while (current != 0) {
            if (key == current->key) {
                return true;
            }
            if (key < current->key) {
                current = current->left;
            } else {
                current = current->right;
            }
        }
        return false;
    }

    bool insert(int key) {
        bool inserted = false;
        root = insertNode(root, key, inserted);
        return inserted;
    }

    bool erase(int key) {
        bool removed = false;
        root = eraseNode(root, key, removed);
        return removed;
    }

    std::vector<int> inorder() const {
        std::vector<int> result;
        collectInorder(root, result);
        return result;
    }
};

void printSequence(const char* label, const std::vector<int>& values) {
    std::cout << label;
    // size_type 是容器的无符号大小类型；size() 返回元素个数，O(1)。
    for (std::vector<int>::size_type index = 0; index < values.size(); ++index) {
        // operator[] 不做越界检查；这里由循环边界保证合法。
        std::cout << ' ' << values[index];
    }
    std::cout << '\n';
}

int main() {
    BinarySearchTree tree;
    // empty() 检查结果数组是否为空；contains 对空树返回 false。
    assert(tree.empty() && tree.inorder().empty() && !tree.contains(8));
    bool changed = tree.erase(8);
    assert(!changed);

    int keys[] = {8, 3, 10, 1, 6, 14, 4, 7, 13};
    for (int index = 0; index < 9; ++index) {
        changed = tree.insert(keys[index]);
        assert(changed);
    }
    changed = tree.insert(6);
    assert(!changed);
    int expectedData[] = {1, 3, 4, 6, 7, 8, 10, 13, 14};
    // vector(first, last) 复制 [first, last)；C 数组末端地址只作边界，不会读取。
    std::vector<int> expected(expectedData, expectedData + 9);
    // vector 的 == 比较长度及每个位置的元素，不是比较底层地址。
    assert(tree.inorder() == expected);
    printSequence("Initial:", tree.inorder());
    std::cout << "Contains 6: " << tree.contains(6) << '\n';
    std::cout << "Contains 99: " << tree.contains(99) << '\n';

    changed = tree.erase(7);
    assert(changed && !tree.contains(7));
    printSequence("Erase leaf 7:", tree.inorder());
    changed = tree.erase(14);
    assert(changed && tree.contains(13));
    printSequence("Erase one-child 14:", tree.inorder());
    changed = tree.erase(3);
    assert(changed && !tree.contains(3));
    printSequence("Erase two-child 3:", tree.inorder());
    changed = tree.erase(8);
    assert(changed && !tree.contains(8));
    printSequence("Erase root 8:", tree.inorder());

    std::vector<int> ordered = tree.inorder();
    for (std::vector<int>::size_type index = 1; index < ordered.size(); ++index) {
        assert(ordered[index - 1] < ordered[index]);
    }
    changed = tree.erase(99);
    assert(!changed && tree.inorder() == ordered);
    tree.clear();
    tree.clear();
    assert(tree.empty());
    changed = tree.insert(42);
    assert(changed && tree.contains(42));
    changed = tree.erase(42);
    assert(changed && tree.empty());
    std::cout << "BST checks passed\n";
    return 0;
}
```

按程序中的次序插入 `8 3 10 1 6 14 4 7 13`。删除 `3` 时用右子树中的 `4` 代替；删除根 `8` 时用 `10` 代替，同时保留后继的右孩子 `13`。

```text

Contains 6: 1
Contains 99: 0

Erase root 8: 1 4 6 10 13
```

### 复杂度与所有权

设树高为 $h$、结点数为 $n$。查找、插入、删除均为 $O(h)$ 时间；形状较平衡时为 $O(\log n)$，按递增顺序插入可能退化成链，此时为 $O(n)$。本例不是平衡搜索树，不能承诺每次操作都是对数时间。

迭代查找辅助空间为 $O(1)$；递归插入、删除、中序遍历及销毁需要 $O(h)$ 调用栈。中序遍历和销毁时间都是 $O(n)$，遍历返回数组另占 $O(n)$。建树只是反复插入，最坏总时间为 $O(n^2)$。

`new Node` 产生的结点只能由树释放；删除一个结点不会自动递归删除其孩子，故一个孩子的情况可以先保存并接回孩子。整树清理由 `destroy` 显式后序遍历完成，返回的 `vector<int>` 则拥有独立的整数副本。

## 三、哈夫曼树：小根堆合并、编码与 WPL

### 输入、贪心步骤与返回结果

输入为等长的 `vector<char>` 符号数组和 `vector<int>` 权值数组。符号是互异的单字节 `char`，不是完整的中文字符；样例使用 ASCII。权值必须非负，允许 `0`，负数或重复符号会被拒绝。权值可以理解为出现次数，若题目要求严格正权，则把检查条件改成拒绝 `<= 0`。

1. 每个符号建立一个叶子，放入小根堆。
2. 弹出权值最小的两个子树根，第一个作为左孩子，第二个作为右孩子。
3. 创建父结点，其权值为两个孩子的权值之和，再放回小根堆。
4. 剩下一个结点时，它就是树根。编码约定左边为 `0`、右边为 `1`。

`std::priority_queue` 默认行为是大根堆，不能只看名字就以为它会弹出最小值。本例比较器在第一个结点权值更大时返回 `true`，使它的优先级更低。权值相同则创建序号较小者先出堆：叶子按输入顺序编号，内部结点继续递增编号。因此**相同输入顺序会产生确定编码**；改变符号输入顺序可能得到不同但同样最优的编码。

| 接口 | 含义 |
|---|---|
| `build(symbols, weights)` | 先清空旧树；合法输入返回 `true`，非法返回 `false` 且树为空；两数组都空为合法输入 |
| `codes()` | 返回 `map<char, string>` 编码表，按符号顺序排列；空树返回空表 |
| `weightedPathLength()` | 返回叶子权值乘树深度之和；根深度为 `0`，空树为 `0` |
| `encodedBitCost()` | 把权值作为频次时的编码总位数，不含编码表、文件头及字节补齐 |
| `empty()`、`clear()` | 查询空树、释放全树 |

所有树结点只由 `HuffmanTree` 管理，堆只是暂存各棵子树根的指针；弹出指针不等于删除结点。合并后父结点拥有两棵子树，最后整树交给 `root`。输入合法性在创建结点前检查，不会因非法输入遗留半棵树；内存分配失败时的异常清理不在本例范围内。

### WPL 与单符号特例

设第 $i$ 个叶子的权值为 $w_i$、到根的边数为 $d_i$，带权路径长度为

$$
\mathrm{WPL}=\sum_i w_i d_i.
$$

只有一个符号时，它自身就是根，深度为 `0`，按定义 WPL 为 `0`。但本例为这个符号分配字符串编码 `"0"`，避免空码字：若它出现 `5` 次，实际输出 `00000`，编码成本为 `5` 位，**不是 WPL 的 `0`**。两个或更多符号时，码长等于树深度，两种计算相同。若权值不是频次，`encodedBitCost()` 应理解为加权码长，而非文件大小。

累计权值及计算结果采用 VS2010 支持的 `long long`；仍约定总权值及加权码长不超出该类型范围。内部结点的符号字段不参与编码，是否为叶子只根据孩子指针判断。

### 完整程序 3

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <map>
#include <set>
#include <string>
#include <cassert>

class HuffmanTree {
private:
    struct Node {
        long long weight;
        char symbol;
        int order;
        Node* left;
        Node* right;

        Node(long long nodeWeight, char nodeSymbol, int creationOrder,
             Node* leftChild = 0, Node* rightChild = 0)
            : weight(nodeWeight), symbol(nodeSymbol), order(creationOrder),
              left(leftChild), right(rightChild) {}

        bool isLeaf() const {
            return left == 0 && right == 0;
        }
    };

    struct Compare {
        bool operator()(const Node* first, const Node* second) const {
            if (first->weight != second->weight) {
                return first->weight > second->weight;
            }
            return first->order > second->order;
        }
    };

    Node* root;

    HuffmanTree(const HuffmanTree&);
    HuffmanTree& operator=(const HuffmanTree&);

    static void destroy(Node* current) {
        if (current == 0) {
            return;
        }
        destroy(current->left);
        destroy(current->right);
        delete current;
    }

    static void collectCodes(const Node* current, std::string& path,
                             std::map<char, std::string>& result) {
        if (current == 0) {
            return;
        }
        if (current->isLeaf()) {
            // map<char, string> 是按 char 键排序的映射；[] 查找/插入键需要 O(log n)。
            // 键不存在时 [] 创建空 string，再复制码字；不能用 [] 做无副作用的查询。
            result[current->symbol] = path.empty() ? "0" : path;
            return;
        }
        // string 保存字符序列；push_back(char) 在末尾追加字符，empty() 检查是否为空。
        path.push_back('0');
        collectCodes(current->left, path, result);
        // size() 是字符数；[] 返回字符引用且不查越界，这里至少已经追加了一个字符。
        path[path.size() - 1] = '1';
        collectCodes(current->right, path, result);
        // erase(pos) 删除 [pos, size())，返回当前 string 的引用；这里仅去掉最后一位。
        path.erase(path.size() - 1);
    }

    static long long calculateWpl(const Node* current, int depth) {
        if (current == 0) {
            return 0;
        }
        if (current->isLeaf()) {
            return current->weight * depth;
        }
        return calculateWpl(current->left, depth + 1)
             + calculateWpl(current->right, depth + 1);
    }

public:
    HuffmanTree() : root(0) {}

    ~HuffmanTree() {
        clear();
    }

    bool empty() const {
        return root == 0;
    }

    void clear() {
        destroy(root);
        root = 0;
    }

    bool build(const std::vector<char>& symbols, const std::vector<int>& weights) {
        clear();
        // vector<T> 保存同类型元素；size() 返回元素个数，[] 不做边界检查。
        if (symbols.size() != weights.size()) {
            return false;
        }
        // set<char> 保存不重复的有序字符；这里仅用于检测重复符号。
        std::set<char> seen;
        for (int index = 0; index < static_cast<int>(symbols.size()); ++index) {
            // insert(value) 返回 pair<iterator, bool>，second 为是否真的插入；O(log n)。
            if (weights[index] < 0 || !seen.insert(symbols[index]).second) {
                return false;
            }
        }
        if (symbols.empty()) {
            return true;
        }

        // priority_queue<元素类型, 底层容器, 比较器>；vector<Node*> 只保存指针。
        // Compare 令 (weight, order) 最小者位于 top；堆不会自动 delete 指向的结点。
        std::priority_queue<Node*, std::vector<Node*>, Compare> pending;
        for (int index = 0; index < static_cast<int>(symbols.size()); ++index) {
            // push(value) 插入元素并恢复堆序，O(log n)；这里创建叶子后放入堆。
            pending.push(new Node(weights[index], symbols[index], index));
        }
        int nextOrder = static_cast<int>(symbols.size());
        // size() 返回堆内元素个数，O(1)；大于 1 时才可连续弹出两个子树。
        while (pending.size() > 1) {
            // top() 返回堆顶引用，O(1)；pop() 移除堆顶，O(log n)，不返回元素。
            Node* left = pending.top();
            pending.pop();
            Node* right = pending.top();
            pending.pop();
            Node* parent = new Node(left->weight + right->weight, 0,
                                    nextOrder++, left, right);
            pending.push(parent);
        }
        root = pending.top();
        pending.pop();
        return true;
    }

    std::map<char, std::string> codes() const {
        std::map<char, std::string> result;
        std::string path;
        collectCodes(root, path, result);
        return result;
    }

    long long weightedPathLength() const {
        return calculateWpl(root, 0);
    }

    long long encodedBitCost() const {
        if (root == 0) {
            return 0;
        }
        if (root->isLeaf()) {
            return root->weight;
        }
        return weightedPathLength();
    }
};

int main() {
    HuffmanTree tree;
    // map::empty() 判断是否没有表项，不会修改编码表。
    assert(tree.empty() && tree.codes().empty());
    assert(tree.weightedPathLength() == 0 && tree.encodedBitCost() == 0);

    char symbolData[] = {'A', 'B', 'C', 'D'};
    int weightData[] = {1, 1, 2, 4};
    // vector(first, last) 复制 [first, last)，两个参数是数组首地址和尾后地址。
    std::vector<char> symbols(symbolData, symbolData + 4);
    std::vector<int> weights(weightData, weightData + 4);
    bool success = tree.build(symbols, weights);
    assert(success);
    if (!success) {
        return 1;
    }
    std::map<char, std::string> encoding = tree.codes();
    // count(key) 对 map 返回 0 或 1；find(key) 返回迭代器，未找到时为 end()。
    assert(encoding.count('A') == 1 && encoding.find('A')->second == "110");
    assert(encoding.size() == 4 && tree.weightedPathLength() == 14);
    // begin()/end() 描述有序表的 [首项, 尾后)；++ 访问下一项，end() 不能解引用。
    for (std::map<char, std::string>::const_iterator entry = encoding.begin();
         entry != encoding.end(); ++entry) {
        // first 是符号键，second 是对应码字；const_iterator 不允许修改表项。
        std::cout << entry->first << ": " << entry->second << '\n';
    }
    std::cout << "WPL: " << tree.weightedPathLength() << '\n';
    std::cout << "Encoded bits: " << tree.encodedBitCost() << '\n';
    assert(tree.encodedBitCost() == 14);

    // vector(count, value) 构造 count 个相同元素；此处是单符号边界。
    std::vector<char> singleSymbol(1, 'X');
    std::vector<int> singleWeight(1, 5);
    success = tree.build(singleSymbol, singleWeight);
    assert(success);
    std::map<char, std::string> singleCode = tree.codes();
    assert(singleCode.count('X') == 1 && singleCode.find('X')->second == "0");
    assert(tree.weightedPathLength() == 0 && tree.encodedBitCost() == 5);
    std::cout << "Single X: " << singleCode.find('X')->second << '\n';
    std::cout << "Single WPL: " << tree.weightedPathLength() << '\n';
    std::cout << "Single encoded bits: " << tree.encodedBitCost() << '\n';

    std::vector<int> zeroWeight(1, 0);
    success = tree.build(singleSymbol, zeroWeight);
    assert(success && !tree.empty() && tree.encodedBitCost() == 0);
    std::vector<int> negativeWeight(1, -1);
    success = tree.build(singleSymbol, negativeWeight);
    assert(!success && tree.empty());
    std::vector<char> repeatedSymbols(2, 'A');
    std::vector<int> repeatedWeights(2, 1);
    success = tree.build(repeatedSymbols, repeatedWeights);
    assert(!success && tree.empty());
    std::vector<int> noWeights;
    success = tree.build(symbols, noWeights);
    assert(!success && tree.empty());
    std::vector<char> noSymbols;
    success = tree.build(noSymbols, noWeights);
    assert(success && tree.empty() && tree.codes().empty());
    tree.clear();
    tree.clear();
    std::cout << "Huffman checks passed\n";
    return 0;
}
```

输入顺序固定为 `A:1, B:1, C:2, D:4`。先合并 `A、B` 得到权值 `2` 的子树；同权时 `C` 创建更早，所以接下来 `C` 在左，该子树在右。最后 `D` 在左，权值 `4` 的新子树在右。非叶子合并权值之和 `2 + 4 + 8 = 14`，也可用来手工核对 WPL。

### 复杂度与常见错误

设符号数为 $n$、树高为 $h$、返回码字的总字符数为 $L$。

- 建树时间 $O(n\log n)$，包括合法性检查、初始入堆和 $n-1$ 次合并；额外还需 $O(n_{old})$ 销毁旧树。非空时共创建 $2n-1$ 个结点，树和临时堆占 $O(n)$ 空间。
- 生成编码需要 $O(n\log n + L)$ 时间：本实现把 $n$ 个码字插入 `map`，还需复制实际码字内容，不能只写成 $O(n)$。调用栈和共享路径占 $O(h)$，返回编码表占 $O(n+L)$。
- 计算 WPL、销毁均为 $O(n)$ 时间、$O(h)$ 调用栈。空树/单符号成本查询为 $O(1)$，其余 `encodedBitCost()` 需要重新遍历，为 $O(n)$。
- 堆中结点不能在 `pop()` 后立即 `delete`，它们还要接到新父结点下。不能同时让堆和根都负责递归释放，否则会重复删除。
- 编码只分配给叶子；内部结点不能当作符号输出。零权符号仍建立叶子并获得码字，不会被静默丢弃。

## 四、手写小根堆：上滤、下滤与任意位置删除

### 数组表示与调整前提

二叉堆是用数组表示的完全二叉树。本例是小根堆，任一父结点的值不大于孩子，所以根是全局最小值；**整个底层数组并不保证有序**。允许重复值和负数。

设当前下标为 `index`，使用从 `0` 开始的下标：

| 位置 | 下标公式与条件 |
|---|---|
| 根 | `0`，仅非空时存在 |
| 父结点 | `(index - 1) / 2`，要求 `index > 0` |
| 左孩子 | `2 * index + 1`，小于元素个数才存在 |
| 右孩子 | `2 * index + 2`，小于元素个数才存在 |
| 最后一个非叶子 | `size / 2 - 1`，空堆或单元素时为 `-1` |

两种局部调整的前提不能混淆：

- `siftUp(index)` 自底向上：适用于原本合法的堆刚追加一个叶子，或者原堆某位置的键减小。把该值与父结点比较并逐层交换。本例任意删除时，若替补值比父结点还小，就属于键减小的情况。
- `siftDown(index)` 自顶向下：要求左右子树各自已经是堆，当前根可能大于孩子；选择较小的孩子交换并继续下移。它修复的是以该位置为根的子树，不负责修复其与父结点之间的逆序关系。

**“自底向上建堆”说的是处理各子树根的次序，不是说每次都调用上滤。** 从最后一个非叶子到根依次调用 `siftDown` 时，孩子子树已经先处理好，正好满足下滤前提。

| 建堆方式 | 步骤 | 时间 |
|---|---|---|
| 逐个插入 | 空堆不断 `push`，每次对新叶子 `siftUp` | 最坏 $O(n\log n)$ |
| 整数组建堆 | 复制数组，从 `size / 2 - 1` 到 `0` 对每个位置 `siftDown` | $O(n)$ |

线性建堆的原因是大多数结点在底层、只能下移很少几层；高度约为 $k$ 的结点至多有 $n/2^k$ 个，总工作量受 $n\sum_{k\geq 1} k/2^k=O(n)$ 控制。不能把每个结点都按最大树高计算后，就断言该方法只能达到 $O(n\log n)$。

### 接口与任意下标删除

| 接口 | 返回值与约定 |
|---|---|
| `MinHeap()` | 构造空堆 |
| `MinHeap(values)` | 复制数组并在线性时间内建堆，不修改传入数组 |
| `push(value)` | 加入一个值，允许重复值 |
| `top(value)` | 非空时把堆顶复制到输出引用并返回 `true`，不删除 |
| `pop(value)` | 非空时移除堆顶，将被删除值写入输出引用并返回 `true` |
| `eraseAt(index, value)` | 移除当前底层数组下标处的值，输出被删值，成功返回 `true` |
| `empty()`、`size()` | 查询是否为空、返回元素个数 |

空堆 `top/pop`、非法下标 `eraseAt` 均返回 `false`，**不改写输出参数，也不改动堆**。返回的元素是整数副本，不是指向内部存储的引用。

任意删除先拿末尾元素填补空位，再 `pop_back` 缩短数组。如果删的就是末尾，到此结束；否则替补值小于父结点时上滤，其他情况则下滤。总是只做下滤会漏掉“替补值比新父结点更小”的情况。

`eraseAt` 参数是当前的堆内下标，不是原输入下标、键值或排序后的名次。堆调整会改变元素位置；若想按值删除，需要先查找下标，本例不维护额外索引。演示的上滤、下滤数组本身已经是小根堆，因此可以明确知道初始下标处的值。

### 完整程序 4

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cassert>

class MinHeap {
private:
    // vector<int> 是连续整数动态数组，由它管理内存；默认复制会复制全部元素。
    std::vector<int> data;

    void siftUp(int index) {
        while (index > 0) {
            int parent = (index - 1) / 2;
            if (data[parent] <= data[index]) {
                break;
            }
            // swap(first, second) 交换两个对象；对 int 为 O(1)，不会改变 vector 大小。
            std::swap(data[parent], data[index]);
            index = parent;
        }
    }

    void siftDown(int index) {
        int count = size();
        // index < count / 2 表示还有左孩子，也避免先对叶子算 2 * index 导致溢出。
        while (index < count / 2) {
            int smallerChild = 2 * index + 1;
            int rightChild = smallerChild + 1;
            if (rightChild < count && data[rightChild] < data[smallerChild]) {
                smallerChild = rightChild;
            }
            if (data[index] <= data[smallerChild]) {
                break;
            }
            std::swap(data[index], data[smallerChild]);
            index = smallerChild;
        }
    }

public:
    MinHeap() {}

    explicit MinHeap(const std::vector<int>& values) : data(values) {
        // vector 的复制构造独立复制所有元素，O(n)；修改 data 不影响 values。
        // 使用有符号 int 递减，空数组从 -1 开始就跳过循环，不会发生无符号下溢。
        for (int parent = size() / 2 - 1; parent >= 0; --parent) {
            siftDown(parent);
        }
    }

    bool empty() const {
        // empty() 判断元素个数是否为零；size() 返回元素个数，两者均为 O(1)。
        return data.empty();
    }

    int size() const {
        return static_cast<int>(data.size());
    }

    void push(int value) {
        // push_back(value) 在末尾追加，摊还 O(1)；容量不足时会重新分配并复制元素。
        data.push_back(value);
        siftUp(size() - 1);
    }

    bool top(int& value) const {
        if (empty()) {
            return false;
        }
        // operator[] 不检查边界；确认非空后，下标 0 一定存在。
        value = data[0];
        return true;
    }

    bool pop(int& value) {
        return eraseAt(0, value);
    }

    bool eraseAt(int index, int& value) {
        if (index < 0 || index >= size()) {
            return false;
        }
        value = data[index];
        // back() 返回末尾元素引用，要求非空，O(1)；先复制末尾值再缩短数组。
        data[index] = data.back();
        // pop_back() 删除最后一个元素，返回 void；不负责修复任何堆序，O(1)。
        data.pop_back();
        if (index == size()) {
            return true;
        }
        if (index > 0 && data[index] < data[(index - 1) / 2]) {
            siftUp(index);
        } else {
            siftDown(index);
        }
        return true;
    }
};

void printAndDrain(const char* label, MinHeap& heap) {
    std::cout << label;
    int value = 0;
    while (heap.pop(value)) {
        std::cout << ' ' << value;
    }
    std::cout << '\n';
}

int main() {
    MinHeap emptyHeap;
    int value = 123;
    bool success = emptyHeap.top(value);
    assert(!success && value == 123);
    success = emptyHeap.pop(value);
    assert(!success && value == 123);
    // vector 默认构造得到空数组；数组建堆接口也必须接受空数组。
    std::vector<int> noValues;
    MinHeap builtEmpty(noValues);
    assert(builtEmpty.empty());

    int inputData[] = {9, 4, 7, 1, -2, 6, 5};
    // vector(first, last) 复制 [first, last)；末端地址不属于被复制的元素。
    std::vector<int> input(inputData, inputData + 7);
    MinHeap heap(input);
    success = heap.top(value);
    assert(success && value == -2 && input[0] == 9);
    std::cout << "Top: " << value << '\n';
    heap.push(-2);
    heap.push(0);
    success = heap.pop(value);
    assert(success && value == -2);
    std::cout << "Pop: " << value << '\n';
    printAndDrain("Drain:", heap);
    assert(heap.empty());

    int upwardData[] = {1, 4, 2, 7, 8, 3};
    MinHeap upward;
    for (int index = 0; index < 6; ++index) {
        upward.push(upwardData[index]);
    }
    success = upward.eraseAt(3, value);
    assert(success && value == 7);
    std::cout << "Erase index 3 (up): " << value << '\n';
    printAndDrain("Remaining:", upward);

    int downwardData[] = {1, 2, 3, 4, 5, 6, 7};
    std::vector<int> downwardValues(downwardData, downwardData + 7);
    MinHeap downward(downwardValues);
    success = downward.eraseAt(1, value);
    assert(success && value == 2);
    std::cout << "Erase index 1 (down): " << value << '\n';
    printAndDrain("Remaining:", downward);

    emptyHeap.push(5);
    value = 123;
    success = emptyHeap.eraseAt(-1, value);
    assert(!success && value == 123 && emptyHeap.size() == 1);
    success = emptyHeap.eraseAt(emptyHeap.size(), value);
    assert(!success && value == 123 && emptyHeap.size() == 1);
    success = emptyHeap.eraseAt(0, value);
    assert(success && value == 5 && emptyHeap.empty());
    std::cout << "Heap checks passed\n";
    return 0;
}
```

### 复杂度、空间与 STL 堆算法

`top/empty/size` 为 $O(1)$；一次上滤或下滤为 $O(\log n)$；`pop/eraseAt` 最坏为 $O(\log n)$。`push` 的堆调整为 $O(\log n)$，考虑 `vector` 末尾追加后是摊还 $O(\log n)$；若某次扩容，需要复制原元素，该次操作可能为 $O(n)$。反复弹出全部元素为 $O(n\log n)$。

底层 `vector` 占 $O(n)$ 空间，调整过程只用 $O(1)$ 辅助空间，无递归。类不含独占裸指针，默认复制会复制 `vector` 内容而非共享底层数组，因此不需要禁用复制或手写析构函数。示例采用 `int` 下标，要求元素个数在 `int` 范围内。

标准库 `<algorithm>` 的四个堆算法都作用于随机访问迭代器的 `[first, last)`，例如 `values.begin(), values.end()`；返回值均为 `void`，直接修改区间内元素。`begin()` 指向首元素，`end()` 是尾后位置，不能解引用。它们**不会替你增加或减少 `vector` 的元素个数**：

| 方法 | 前提与效果 | 时间 |
|---|---|---|
| `make_heap(first, last)` | 把任意区间就地变成堆；默认是大根堆，空区间可用 | $O(n)$ |
| `push_heap(first, last)` | 前缀 `[first, last - 1)` 已是堆，且末尾已经追加一个新元素；调整使整个非空区间成堆 | $O(\log n)$ |
| `pop_heap(first, last)` | 原区间是非空堆；原堆顶移到 `last - 1`，剩余前缀仍是堆；若要真正删除，再保存 `back()` 并调用 `pop_back()` | $O(\log n)$ |
| `sort_heap(first, last)` | 前提是整个区间已经成堆；默认得到升序数组，通常不再满足原堆序，不能直接接着 `push_heap/pop_heap` | $O(n\log n)$ |

若要用这些标准算法维护小根堆，可为四个调用都传入相同的 `std::greater<int>()` 比较器，并包含 `<functional>`；此时 `sort_heap` 得到降序数组。不能建堆时用小根堆比较器、后续操作却省略比较器而切回默认大根堆规则。
