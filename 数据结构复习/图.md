# 图：基础表示、遍历、生成树与最短路径

## 题目描述与使用约定

本文用于考核前复习基础数据结构的 C++ 实现，不是某一道力扣题的题解。目标是能默写表示方法、遍历、路径、最小生成树和最短路，并能说明它们各自解决什么问题。

- **编译目标：Microsoft Visual Studio 2010。** 下文四个程序互相独立，每个代码块都有自己的头文件、辅助类型、函数和一个 `main`；不要把四块拼进同一个源文件。使用普通 `for`、显式类型、普通构造函数、`push_back`，嵌套模板写成 `> >`。`long long` 是 VC2010 已支持的类型。本篇不以仓库默认的 C++17 为准。
- 顶点从 `0` 编号到 `vertexCount - 1`，约定 `0 <= vertexCount <= 200`。这里的上限是教学程序主动选择的输入限制，不是图算法本身的限制。
- 整数边权限定为 `[-1000000, 1000000]`；Dijkstra 进一步要求非负。边权、距离、生成树总权都用 `long long`；带权算法用 `INF = 1000000000000LL` 表示无边或不可达，不能用 `0` 代替无边。BFS 的距离仅表示边数，另用 `-1` 表示不可达。
- 无负环时，最短路总能选为不重复顶点的路径；路径和生成树至多含 199 条边，权值绝对值至多 199000000，远小于 `INF`。计算之前仍须判断操作数不是 `INF`，不能把哨兵参与加法。
- 建边函数检查顶点范围和权值范围：顶点数或权值非法抛 `invalid_argument`，顶点下标非法抛 `out_of_range`。这些是调用错误，不等于“合法图中不可达”。示例不做复杂输入解析；若改成 `cin`，先读顶点数和边数，再逐条调用对应的 `addEdge`，并按题意处理输入失败。
- 以下结构的成员公开是为了便于学习；**图必须通过构造函数和 `addEdge` 建立，结果只能由相应算法产生，不要手工破坏矩阵尺寸或前驱数组**。还原路径时使用同一次计算得到的结果。
- 空图允许建立；全图遍历返回空序列，Floyd 返回空结果。空图没有合法起点，带起点的搜索会抛越界异常。本篇约定空图不存在 MST，MST 接口返回失败；单点图的 MST 成功，边集为空、总权为 0。

## 思路：先分清要优化什么

| 问题 | 核心动作 | 得到的是什么 | 适用条件 |
|---|---|---|---|
| BFS 遍历 | 入队时标记，逐层扩展 | 访问顺序 | 有向、无向都可以 |
| DFS 遍历 | 先标记，再递归邻居 | 访问顺序 | 有向、无向都可以 |
| DFS 找一条简单路径 | 记录当前路径，失败时弹出 | 一条可行路径，不保证最短 | 不重复顶点 |
| BFS 最短路 | 第一次发现邻居时确定距离 | 从源点出发的最少边数 | 无权图，或每条边代价相同 |
| Prim | 每次选接入当前树最便宜的顶点 | 覆盖全图的最小生成树 | 无向带权图，可有负边 |
| Kruskal | 按边权排序，只接不同集合 | 覆盖全图的最小生成树 | 无向带权图，可有负边 |
| Dijkstra | 每次确定尚未确定的最近顶点 | 单源最短距离及路径 | **所有边权非负** |
| Floyd | 枚举允许经过的中转点 | 任意两点间最短距离及路径 | 可有负边，不能有负环 |

**MST 最小化的是选出的整棵树的边权总和，不是从某个源点到所有顶点的距离，也不是这些距离的总和。** 例如无向三角形的边权是 `0-1:2, 1-2:2, 0-2:3`，MST 总权为 4，但沿该树从 0 到 2 要走权值 4 的路径，原图的最短路却是直连边，权值为 3。

### 三种表示与建边方向

| 表示 | 元素含义 | 查询一条边 | 扫描一个顶点的邻居 | 存储空间 |
|---|---|---|---|---|
| 邻接矩阵 `vector<vector<long long> >` | `matrix[from][to]` 是最小直接边权 | $O(1)$ | $O(V)$ | $O(V^2)$ |
| 无权邻接表 `vector<vector<int> >` | `adjacency[from]` 保存邻居编号 | $O(\deg(from))$ | $O(\deg(from))$ | $O(V+E)$ |
| 带权邻接表 `vector<vector<Edge> >` | `Edge` 保存 `to` 和 `weight` | $O(\deg(from))$ | $O(\deg(from))$ | $O(V+E)$ |

有向边 `from -> to` 只登记一个方向。无向边 `from - to` 登记两个方向；自环只登记一次，遍历靠访问标记避免循环。邻接表保留输入的重边，所以遍历时仍要检查标记；矩阵中同方向重边只保留最小权值。

一般表示矩阵的所有位置最初都是 `INF`，包括没有自环的对角线。**Floyd 的工作距离矩阵另有初始化规则：对角线为 0，代表不走任何边的空路径。** 存在负自环时要保留负权并报告负环，不能再用 0 覆盖掉它。

## 程序一：表示、BFS / DFS 与路径

### 思路与接口

- `Graph(vertexCount, directed)` 同时维护三种表示，便于对照学习；实际考试按需要保留一种即可。`addEdge(from, to, weight)` 按 `directed` 决定是否建反向边。
- `bfsAll(graph)`、`dfsAll(graph)` 返回全图访问序列。最外层按编号扫描所有未访问顶点，因而不会漏掉孤立点或非连通部分。有向图中这个外层循环只是补齐所有顶点，不是在求强连通分量。
- `findDfsPath(graph, source, target, path)` 返回 `bool`，用引用参数 `path` 传出一条简单路径；失败时 `path` 为空，起终点相同则是单个顶点。
- DFS 找路径中的 `visited` 表示**这次搜索中曾经访问过**，失败回退时不清零；`path` 表示**当前递归链**，失败回退时执行 `pop_back`。只找一条路径时，已完整探索的失败分支不必再探索，因此仍是线性遍历。不是枚举所有简单路径，不要把两类标记混淆。
- `bfsShortestPaths(graph, source)` 返回 `dist` 和 `predecessor`；`restoreBfsPath(result, target)` 返回实际路径。不可达的 `dist` 为 `-1`，路径为空；源点距离为 0、前驱为 `-1`、路径只有自身。
- 此处 BFS 把每条边当作一步，**不使用 `Edge::weight`**。若边权不同，应改用后文满足条件的带权最短路算法。

### 完整代码

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <stdexcept>
#include <cassert>

using namespace std;

const int MAX_VERTICES = 200;
const long long MAX_WEIGHT = 1000000;
const long long INF = 1000000000000LL;

struct Edge {
    int to;
    long long weight;

    Edge(int destination, long long edgeWeight)
        : to(destination), weight(edgeWeight) {}
};

struct Graph {
    int vertexCount;
    bool directed;
    vector<vector<long long> > matrix;
    vector<vector<int> > adjacency;
    vector<vector<Edge> > weightedAdjacency;

    Graph(int count, bool isDirected)
        : vertexCount(count), directed(isDirected) {
        if (count < 0 || count > MAX_VERTICES) {
            throw invalid_argument("invalid vertex count");
        }
        // vector<T>(count, value) 创建 count 个 value 的副本。
        // assign(count, value) 覆盖原内容，返回 void；这里每一行是独立 vector。
        // 先校验 count，避免负数转成无符号长度后申请巨量内存。
        matrix.assign(count, vector<long long>(count, INF));
        adjacency.assign(count, vector<int>());
        weightedAdjacency.assign(count, vector<Edge>());
    }

    void checkVertex(int vertex) const {
        if (vertex < 0 || vertex >= vertexCount) {
            throw out_of_range("invalid vertex");
        }
    }

    void addArc(int from, int to, long long weight) {
        // operator[] 返回元素引用，不检查越界；调用前已经检查两个编号。
        // min(a, b) 取较小值；必须赋回矩阵，才能保留重边中的最小权。
        matrix[from][to] = min(matrix[from][to], weight);
        // push_back(value) 在尾部追加一个元素，返回 void，均摊 O(1)。
        // 扩容可能使旧引用/迭代器失效；此处不保存它们。邻接表保留重边。
        adjacency[from].push_back(to);
        weightedAdjacency[from].push_back(Edge(to, weight));
    }

    void addEdge(int from, int to, long long weight) {
        checkVertex(from);
        checkVertex(to);
        if (weight < -MAX_WEIGHT || weight > MAX_WEIGHT) {
            throw invalid_argument("weight out of range");
        }
        addArc(from, to, weight);
        if (!directed && from != to) {
            addArc(to, from, weight);
        }
    }
};

vector<int> bfsAll(const Graph& graph) {
    // const Graph& 只读引用避免复制图；visited 用 int，0/1 表示未访问/已访问。
    vector<int> visited(graph.vertexCount, 0);
    vector<int> order;
    // queue<int> 是先进先出队列；push(value) 入队，返回 void。
    queue<int> pending;
    for (int start = 0; start < graph.vertexCount; ++start) {
        if (visited[start]) {
            continue;
        }
        visited[start] = 1;
        pending.push(start);
        // empty() 返回 bool；不能在空队列上调用 front() 或 pop()。
        while (!pending.empty()) {
            // front() 读取队头但不删除；pop() 删除队头，返回 void，不返回元素。
            int current = pending.front();
            pending.pop();
            order.push_back(current);
            // size() 是无符号长度；此处使用相同的 size_type，避免混用符号。
            for (vector<int>::size_type index = 0;
                 index < graph.adjacency[current].size(); ++index) {
                int neighbor = graph.adjacency[current][index];
                if (!visited[neighbor]) {
                    visited[neighbor] = 1;
                    pending.push(neighbor);
                }
            }
        }
    }
    return order;
}

void dfsVisit(const Graph& graph, int current,
              vector<int>& visited, vector<int>& order) {
    visited[current] = 1;
    order.push_back(current);
    for (vector<int>::size_type index = 0;
         index < graph.adjacency[current].size(); ++index) {
        int neighbor = graph.adjacency[current][index];
        if (!visited[neighbor]) {
            dfsVisit(graph, neighbor, visited, order);
        }
    }
}

vector<int> dfsAll(const Graph& graph) {
    vector<int> visited(graph.vertexCount, 0);
    vector<int> order;
    for (int start = 0; start < graph.vertexCount; ++start) {
        if (!visited[start]) {
            dfsVisit(graph, start, visited, order);
        }
    }
    return order;
}

bool dfsPathVisit(const Graph& graph, int current, int target,
                  vector<int>& visited, vector<int>& path) {
    visited[current] = 1;
    path.push_back(current);
    if (current == target) {
        return true;
    }
    for (vector<int>::size_type index = 0;
         index < graph.adjacency[current].size(); ++index) {
        int neighbor = graph.adjacency[current][index];
        if (!visited[neighbor] &&
            dfsPathVisit(graph, neighbor, target, visited, path)) {
            return true;
        }
    }
    // pop_back() 删除末尾元素，返回 void，要求非空；这里与入口的追加配对。
    // 回溯的是候选路径，不是 visited；成功时提前返回，保留整条递归链。
    path.pop_back();
    return false;
}

bool findDfsPath(const Graph& graph, int source, int target,
                 vector<int>& path) {
    graph.checkVertex(source);
    graph.checkVertex(target);
    // clear() 删除全部元素、使 size() 为 0，返回 void，不保证释放容量。
    path.clear();
    vector<int> visited(graph.vertexCount, 0);
    return dfsPathVisit(graph, source, target, visited, path);
}

struct BfsResult {
    vector<long long> dist;
    vector<int> predecessor;
};

BfsResult bfsShortestPaths(const Graph& graph, int source) {
    graph.checkVertex(source);
    BfsResult result;
    result.dist.assign(graph.vertexCount, -1);
    result.predecessor.assign(graph.vertexCount, -1);
    queue<int> pending;
    result.dist[source] = 0;
    pending.push(source);
    while (!pending.empty()) {
        int current = pending.front();
        pending.pop();
        for (vector<int>::size_type index = 0;
             index < graph.adjacency[current].size(); ++index) {
            int neighbor = graph.adjacency[current][index];
            if (result.dist[neighbor] == -1) {
                // 在入队时确定距离/前驱，重边和环都不会导致重复入队。
                result.dist[neighbor] = result.dist[current] + 1;
                result.predecessor[neighbor] = current;
                pending.push(neighbor);
            }
        }
    }
    return result;
}

vector<int> restoreBfsPath(const BfsResult& result, int target) {
    // 顶点数最多 200，size() 转 int 在本程序范围内安全。
    if (target < 0 || target >= static_cast<int>(result.dist.size())) {
        throw out_of_range("invalid target");
    }
    vector<int> path;
    if (result.dist[target] == -1) {
        return path;
    }
    for (int current = target; current != -1;
         current = result.predecessor[current]) {
        path.push_back(current);
    }
    // begin()/end() 构成左闭右开区间，end() 指向末尾之后，不能解引用。
    // reverse(first, last) 原地反转区间，返回 void，耗时 O(路径长度)。
    reverse(path.begin(), path.end());
    return path;
}

void printSequence(const char* label, const vector<int>& sequence) {
    cout << label;
    if (sequence.empty()) {
        cout << " none";
    }
    for (vector<int>::size_type index = 0; index < sequence.size(); ++index) {
        cout << " " << sequence[index];
    }
    cout << "\n";
}

int main() {
    Graph graph(7, false);
    graph.addEdge(0, 1, 1);
    graph.addEdge(1, 2, 1);
    graph.addEdge(1, 3, 1);
    graph.addEdge(3, 4, 1);
    graph.addEdge(0, 4, 1);
    graph.addEdge(5, 6, 1);

    cout << "matrix[0][1] = " << graph.matrix[0][1] << "\n";
    printSequence("adjacency[1]:", graph.adjacency[1]);
    cout << "weighted[1][0] = (" << graph.weightedAdjacency[1][0].to
         << "," << graph.weightedAdjacency[1][0].weight << ")\n";
    printSequence("BFS all:", bfsAll(graph));
    printSequence("DFS all:", dfsAll(graph));

    vector<int> path;
    bool found = findDfsPath(graph, 0, 4, path);
    assert(found);
    printSequence("DFS 0->4:", path);
    int expectedDfsArray[] = {0, 1, 3, 4};
    // vector(first, last) 从 C 数组的左闭右开区间复制元素；不是花括号初始化 vector。
    vector<int> expectedDfs(expectedDfsArray, expectedDfsArray + 4);
    // vector 的 == 比较长度和逐个元素，耗时 O(元素个数)，并非比较地址。
    assert(path == expectedDfs);

    BfsResult shortest = bfsShortestPaths(graph, 0);
    cout << "BFS 0->4 distance: " << shortest.dist[4] << "\n";
    printSequence("BFS 0->4 path:", restoreBfsPath(shortest, 4));
    cout << "BFS 0->6 distance: " << shortest.dist[6] << "\n";
    printSequence("BFS 0->6 path:", restoreBfsPath(shortest, 6));
    printSequence("BFS 0->0 path:", restoreBfsPath(shortest, 0));
    assert(shortest.dist[4] == 1 && shortest.predecessor[4] == 0);
    assert(shortest.dist[6] == -1 && restoreBfsPath(shortest, 6).empty());
    found = findDfsPath(graph, 0, 6, path);
    assert(!found && path.empty());

    Graph emptyGraph(0, false);
    assert(bfsAll(emptyGraph).empty() && dfsAll(emptyGraph).empty());
    Graph singleGraph(1, false);
    found = findDfsPath(singleGraph, 0, 0, path);
    assert(found && path.size() == 1 && path[0] == 0);
    BfsResult singleResult = bfsShortestPaths(singleGraph, 0);
    assert(singleResult.dist[0] == 0 && singleResult.predecessor[0] == -1);
    assert(bfsAll(singleGraph).size() == 1 && dfsAll(singleGraph).size() == 1);

    Graph directedGraph(2, true);
    directedGraph.addEdge(0, 1, 0);
    assert(directedGraph.matrix[0][1] == 0);
    directedGraph.addEdge(0, 1, -2);
    assert(directedGraph.matrix[0][1] == -2);
    assert(directedGraph.matrix[1][0] == INF);
    assert(directedGraph.adjacency[0].size() == 2);
    BfsResult directedResult = bfsShortestPaths(directedGraph, 1);
    assert(directedResult.dist[0] == -1);
    return 0;
}
```

### 复杂度与易错点

邻接表上的 BFS、DFS、DFS 找一条路径、BFS 单源最短路都是 $O(V+E)$ 时间，辅助空间 $O(V)$；DFS 的递归栈最多 $V$ 层。路径还原为 $O(V)$ 时间和空间。本程序为了同时演示三种表示，额外保留了 $O(V^2)$ 的矩阵，不要把这部分存储当成 BFS 必须付出的代价。

- BFS 必须在**入队时**标记，若出队才标记，同一顶点可能被重复加入。
- 遍历的 `visited` 不能每个起点都重置；非连通图的外层扫描共享一份标记。
- DFS 的失败分支从 `path` 弹出顶点，成功分支保留；本例顶点 2 会被试探，但不出现在最终 `0 -> 4` 路径里。
- 最短路径可以不唯一；这里用首次发现的前驱，不追求某种字典序。
- 自环、重边和孤立点都不妨碍遍历；空图不能调用带起点的接口。

## 程序二：Prim / Kruskal 最小生成树

### 思路与接口

只处理**无向带权图**。0 权和负边都合法，自环不能帮助连接不同顶点，两个算法都会忽略它。`addEdge` 为矩阵登记两个方向，但 Kruskal 的边表中每条输入边只登记一次；调用者不要再额外调用一次反向建边。

- `prim(graph)`：`bestEdgeWeight[vertex]` 是这个顶点接入**当前树**所需的最小单条边权，`parent[vertex]` 是这条边在树内的端点。它不是源点到该顶点的累计路径长度。每次选一个尚未入树且接入代价最小的顶点，再更新邻居。
- `kruskal(graph)`：把边按权值从小到大排列，只有两端属于不同集合时才接纳。并查集 `findRoot` 做路径压缩；`unite` 把小集合挂到大集合上，并更新大小，返回是否确实合并。
- 两者返回 `MstResult`：`success == true` 时，`edges` 有恰好 `vertexCount - 1` 条边，`totalWeight` 是这些边权之和；`success == false` 时，边集为空、总权为 0，**这些空值不表示存在总权为 0 的生成树**。
- Prim 无法再选出有限接入代价的顶点，或 Kruskal 最后不足 `vertexCount - 1` 条边，就拒绝整张图。不能把已经得到的局部树或生成森林当成整图 MST 返回。
- 空图按本篇约定失败；单点图成功，0 条边、总权 0。合法非连通图不是异常，查看 `success` 即可。

### 完整代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <stdexcept>
#include <cassert>

using namespace std;

const int MAX_VERTICES = 200;
const long long MAX_WEIGHT = 1000000;
const long long INF = 1000000000000LL;

struct WeightedEdge {
    int from;
    int to;
    long long weight;

    WeightedEdge(int source, int destination, long long edgeWeight)
        : from(source), to(destination), weight(edgeWeight) {}
};

struct UndirectedGraph {
    int vertexCount;
    vector<vector<long long> > matrix;
    vector<WeightedEdge> edges;

    explicit UndirectedGraph(int count) : vertexCount(count) {
        if (count < 0 || count > MAX_VERTICES) {
            throw invalid_argument("invalid vertex count");
        }
        // vector<T>(count, value) 创建定长数组；assign 覆盖内容、返回 void。
        // 每行都是独立副本；所有无边位置为 INF，0 也可以是真实边权。
        matrix.assign(count, vector<long long>(count, INF));
    }

    void checkVertex(int vertex) const {
        if (vertex < 0 || vertex >= vertexCount) {
            throw out_of_range("invalid vertex");
        }
    }

    void addEdge(int from, int to, long long weight) {
        checkVertex(from);
        checkVertex(to);
        if (weight < -MAX_WEIGHT || weight > MAX_WEIGHT) {
            throw invalid_argument("weight out of range");
        }
        // [] 返回可修改的引用但不检查越界；min(a, b) 返回较小值。
        matrix[from][to] = min(matrix[from][to], weight);
        matrix[to][from] = min(matrix[to][from], weight);
        // 边表保留重边，端点编号规范成小编号在前，方便固定排序和输出。
        // push_back(value) 追加并复制一个元素、返回 void，均摊 O(1)；可能扩容。
        edges.push_back(WeightedEdge(min(from, to), max(from, to), weight));
    }
};

struct MstResult {
    bool success;
    long long totalWeight;
    vector<WeightedEdge> edges;

    MstResult() : success(false), totalWeight(0) {}
};

MstResult prim(const UndirectedGraph& graph) {
    MstResult result;
    if (graph.vertexCount == 0) {
        return result;
    }
    vector<long long> bestEdgeWeight(graph.vertexCount, INF);
    vector<int> parent(graph.vertexCount, -1);
    vector<int> inTree(graph.vertexCount, 0);
    bestEdgeWeight[0] = 0;

    for (int iteration = 0; iteration < graph.vertexCount; ++iteration) {
        int chosen = -1;
        for (int vertex = 0; vertex < graph.vertexCount; ++vertex) {
            if (!inTree[vertex] &&
                (chosen == -1 || bestEdgeWeight[vertex] < bestEdgeWeight[chosen])) {
                chosen = vertex;
            }
        }
        if (chosen == -1 || bestEdgeWeight[chosen] == INF) {
            // 返回全新的失败结果，丢弃之前的局部树，不能伪装成整图 MST。
            return MstResult();
        }
        inTree[chosen] = 1;
        if (parent[chosen] != -1) {
            result.edges.push_back(
                WeightedEdge(parent[chosen], chosen, bestEdgeWeight[chosen]));
            result.totalWeight += bestEdgeWeight[chosen];
        }
        for (int neighbor = 0; neighbor < graph.vertexCount; ++neighbor) {
            if (!inTree[neighbor] &&
                graph.matrix[chosen][neighbor] < bestEdgeWeight[neighbor]) {
                bestEdgeWeight[neighbor] = graph.matrix[chosen][neighbor];
                parent[neighbor] = chosen;
            }
        }
    }
    result.success = true;
    return result;
}

struct DisjointSet {
    vector<int> parent;
    vector<int> componentSize;

    explicit DisjointSet(int count)
        : parent(count), componentSize(count, 1) {
        // vector<int>(count) 创建 count 个初始化为 0 的元素，再逐个设为自身。
        // 本辅助结构只由合法图调用，根编号始终落在 [0, count) 内。
        for (int vertex = 0; vertex < count; ++vertex) {
            parent[vertex] = vertex;
        }
    }

    int findRoot(int vertex) {
        if (parent[vertex] != vertex) {
            parent[vertex] = findRoot(parent[vertex]);
        }
        return parent[vertex];
    }

    bool unite(int first, int second) {
        int firstRoot = findRoot(first);
        int secondRoot = findRoot(second);
        if (firstRoot == secondRoot) {
            return false;
        }
        if (componentSize[firstRoot] < componentSize[secondRoot]) {
            // swap(a, b) 交换两个变量、返回 void；这里只交换 int，耗时 O(1)。
            swap(firstRoot, secondRoot);
        }
        parent[secondRoot] = firstRoot;
        componentSize[firstRoot] += componentSize[secondRoot];
        return true;
    }
};

struct EdgeLess {
    bool operator()(const WeightedEdge& first, const WeightedEdge& second) const {
        if (first.weight != second.weight) {
            return first.weight < second.weight;
        }
        if (first.from != second.from) {
            return first.from < second.from;
        }
        return first.to < second.to;
    }
};

MstResult kruskal(const UndirectedGraph& graph) {
    MstResult result;
    if (graph.vertexCount == 0) {
        return result;
    }
    // vector 拷贝构造会复制全部元素，O(E)；排序副本，不修改调用者的边表。
    vector<WeightedEdge> sortedEdges(graph.edges);
    // sort(first, last, comparator) 原地排序 [first, last)，返回 void。
    // begin() 是首元素位置，end() 是末尾之后，不能解引用 end()。
    // EdgeLess() 是普通比较器对象；true 表示 first 应排在 second 前面。
    // 比较器必须用严格小于，不能写 <=；相同元素之间必须返回 false。
    sort(sortedEdges.begin(), sortedEdges.end(), EdgeLess());
    DisjointSet sets(graph.vertexCount);
    // size() 返回无符号长度；size_type 与容器长度类型一致，不截断大边表。
    for (vector<WeightedEdge>::size_type index = 0;
         index < sortedEdges.size() &&
         result.edges.size() < static_cast<vector<WeightedEdge>::size_type>(
             graph.vertexCount - 1); ++index) {
        // const 引用不复制元素；排序已完成，循环内不修改 sortedEdges 的容量。
        const WeightedEdge& edge = sortedEdges[index];
        if (sets.unite(edge.from, edge.to)) {
            result.edges.push_back(edge);
            result.totalWeight += edge.weight;
        }
    }
    if (result.edges.size() !=
        static_cast<vector<WeightedEdge>::size_type>(graph.vertexCount - 1)) {
        return MstResult();
    }
    result.success = true;
    return result;
}

void printMst(const char* label, const MstResult& result) {
    cout << label;
    if (!result.success) {
        cout << " failed\n";
        return;
    }
    cout << " total=" << result.totalWeight << " edges:";
    if (result.edges.empty()) {
        // empty() 返回是否没有元素，与总权是否为 0 无关。
        cout << " none";
    }
    for (vector<WeightedEdge>::size_type index = 0;
         index < result.edges.size(); ++index) {
        const WeightedEdge& edge = result.edges[index];
        cout << " " << edge.from << "-" << edge.to << "(" << edge.weight << ")";
    }
    cout << "\n";
}

int main() {
    UndirectedGraph graph(4);
    graph.addEdge(0, 1, 4);
    graph.addEdge(0, 1, 0);
    graph.addEdge(1, 2, -2);
    graph.addEdge(2, 3, 3);
    graph.addEdge(0, 3, 10);
    graph.addEdge(1, 3, 5);
    graph.addEdge(2, 2, -100);
    MstResult primResult = prim(graph);
    MstResult kruskalResult = kruskal(graph);
    printMst("Prim", primResult);
    printMst("Kruskal", kruskalResult);
    assert(graph.matrix[0][1] == 0 && graph.matrix[1][0] == 0);
    assert(primResult.success && kruskalResult.success);
    assert(primResult.totalWeight == 1 && kruskalResult.totalWeight == 1);
    assert(primResult.edges.size() == 3 && kruskalResult.edges.size() == 3);

    UndirectedGraph disconnected(3);
    disconnected.addEdge(0, 1, 2);
    MstResult failedPrim = prim(disconnected);
    MstResult failedKruskal = kruskal(disconnected);
    printMst("Disconnected Prim", failedPrim);
    printMst("Disconnected Kruskal", failedKruskal);
    assert(!failedPrim.success && failedPrim.edges.empty() &&
           failedPrim.totalWeight == 0);
    assert(!failedKruskal.success && failedKruskal.edges.empty() &&
           failedKruskal.totalWeight == 0);

    UndirectedGraph singleGraph(1);
    MstResult singlePrim = prim(singleGraph);
    MstResult singleKruskal = kruskal(singleGraph);
    printMst("Single Prim", singlePrim);
    printMst("Single Kruskal", singleKruskal);
    assert(singlePrim.success && singlePrim.totalWeight == 0 && singlePrim.edges.empty());
    assert(singleKruskal.success && singleKruskal.totalWeight == 0 &&
           singleKruskal.edges.empty());

    UndirectedGraph emptyGraph(0);
    MstResult emptyPrim = prim(emptyGraph);
    MstResult emptyKruskal = kruskal(emptyGraph);
    printMst("Empty Prim", emptyPrim);
    printMst("Empty Kruskal", emptyKruskal);
    assert(!emptyPrim.success && !emptyKruskal.success);

}
```

### 复杂度与易错点

- Prim：邻接矩阵实现，时间 $O(V^2)$，矩阵空间 $O(V^2)$，工作数组和结果空间 $O(V)$。
- Kruskal：排序是 $O(E\log E)$，路径压缩加按大小合并使并查集操作均摊 $O(\alpha(V))$，整体为 $O(V+E\log E)$；额外空间为边表副本和并查集的 $O(E+V)$。$\alpha(V)$ 增长极慢，考试可理解为接近常数。本合并演示仍保留 Prim 的矩阵，Kruskal 本身不需要矩阵。
- `E` 按输入的无向边条数计算，重边也计入。选边不能出现环，重边之间最多选一条；负自环也不能进入树。
- Prim 的更新是 `bestEdgeWeight[neighbor] = matrix[chosen][neighbor]`，**不是加上源点到 chosen 的距离**。这一行最容易与 Dijkstra 混写。
- Kruskal 的并查集 `parent` 表示集合父节点，不是图上生成树的父节点；输出树边要单独存进结果。
- MST 可以不唯一，Prim 和 Kruskal 选边顺序也可能不同；判断正确性要看连通、无环、边数与最小总权，不能强求两个边序列完全相同。

## 程序三：Dijkstra 单源最短路

### 思路与接口

`dist[vertex]` 表示源点到该点的当前最短距离，`settled[vertex]` 表示该距离已经确定。每轮从未确定的顶点中选距离最小者 `chosen`，再尝试用 `dist[chosen] + matrix[chosen][neighbor]` 改善邻居，这一步叫“松弛”。

**非负边保证：后续绕经尚未确定的顶点，不会再把 chosen 的距离变小。负边会破坏这个前提，不能只是照样跑完后相信结果。** 本程序在 `addEdge` 时拒绝任何负权，哪怕负边位于源点到不了的部分，也不允许加入图。

- `NonnegativeGraph(count, directed)` 支持有向或无向图，但边权只允许 `[0, 1000000]`；非法负权抛 `invalid_argument`，不修改图。
- `dijkstra(graph, source)` 返回 `DijkstraResult`，其中有 `source`、`dist`、`predecessor`。源点距离 0，前驱 `-1`；不可达顶点的距离 `INF`、前驱 `-1`。
- `restoreDijkstraPath(result, target)` 返回顶点序列，不可达时返回空 `vector`，目标等于源点时返回仅含源点的序列。读取数值距离前先判断是不是 `INF`。
- 若剩余顶点的最小距离仍是 `INF`，就结束；这表示剩余点不可达，不是错误，也不是非连通图上不能运行 Dijkstra。
- 空图的构造合法，但调用 `dijkstra(emptyGraph, 0)` 抛 `out_of_range`；单点图从 0 到 0 的距离为 0。

### 完整代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <stdexcept>
#include <cassert>

using namespace std;

const int MAX_VERTICES = 200;
const long long MAX_WEIGHT = 1000000;
const long long INF = 1000000000000LL;

struct NonnegativeGraph {
    int vertexCount;
    bool directed;
    vector<vector<long long> > matrix;

    NonnegativeGraph(int count, bool isDirected)
        : vertexCount(count), directed(isDirected) {
        if (count < 0 || count > MAX_VERTICES) {
            throw invalid_argument("invalid vertex count");
        }
        // vector<long long>(count, INF) 生成一行；assign(count, row) 复制成 count 行。
        // assign 覆盖原内容、返回 void，各行不共享元素，矩阵空间为 O(V^2)。
        matrix.assign(count, vector<long long>(count, INF));
    }

    void checkVertex(int vertex) const {
        if (vertex < 0 || vertex >= vertexCount) {
            throw out_of_range("invalid vertex");
        }
    }

    void addEdge(int from, int to, long long weight) {
        checkVertex(from);
        checkVertex(to);
        if (weight < 0 || weight > MAX_WEIGHT) {
            throw invalid_argument("Dijkstra requires weight in [0, 1000000]");
        }
        // [] 访问元素且不检查越界；min(a, b) 取较小值，重边必须赋回最小权。
        matrix[from][to] = min(matrix[from][to], weight);
        if (!directed && from != to) {
            matrix[to][from] = min(matrix[to][from], weight);
        }
    }
};

struct DijkstraResult {
    int source;
    vector<long long> dist;
    vector<int> predecessor;

    DijkstraResult() : source(-1) {}
};

DijkstraResult dijkstra(const NonnegativeGraph& graph, int source) {
    graph.checkVertex(source);
    DijkstraResult result;
    result.source = source;
    result.dist.assign(graph.vertexCount, INF);
    result.predecessor.assign(graph.vertexCount, -1);
    // vector<int>(count, 0) 创建 count 个 0，不是只创建两个元素。
    vector<int> settled(graph.vertexCount, 0);
    result.dist[source] = 0;

    for (int iteration = 0; iteration < graph.vertexCount; ++iteration) {
        int chosen = -1;
        for (int vertex = 0; vertex < graph.vertexCount; ++vertex) {
            if (!settled[vertex] &&
                (chosen == -1 || result.dist[vertex] < result.dist[chosen])) {
                chosen = vertex;
            }
        }
        if (chosen == -1 || result.dist[chosen] == INF) {
            break;
        }
        settled[chosen] = 1;
        for (int neighbor = 0; neighbor < graph.vertexCount; ++neighbor) {
            if (settled[neighbor] || graph.matrix[chosen][neighbor] == INF) {
                continue;
            }
            // 两个加数都有限；非负输入和最多 200 个顶点保证 long long 足够。
            long long candidate = result.dist[chosen] + graph.matrix[chosen][neighbor];
            if (candidate < result.dist[neighbor]) {
                result.dist[neighbor] = candidate;
                result.predecessor[neighbor] = chosen;
            }
        }
    }
    return result;
}

vector<int> restoreDijkstraPath(const DijkstraResult& result, int target) {
    // size() 返回无符号长度；结果最多 200 项，转 int 在此范围内安全。
    if (target < 0 || target >= static_cast<int>(result.dist.size())) {
        throw out_of_range("invalid target");
    }
    vector<int> path;
    if (result.dist[target] == INF) {
        return path;
    }
    for (int current = target; current != -1;
         current = result.predecessor[current]) {
        // push_back(value) 追加一个顶点，返回 void，均摊 O(1)，可能扩容。
        path.push_back(current);
    }
    // begin()/end() 表示左闭右开区间；end() 不能解引用。
    // reverse(first, last) 原地反转区间、返回 void，O(路径长度)。
    reverse(path.begin(), path.end());
    return path;
}

void printDistances(const vector<long long>& distances) {
    cout << "Dijkstra distances:";
    for (vector<long long>::size_type index = 0;
         index < distances.size(); ++index) {
        if (distances[index] == INF) {
            cout << " INF";
        } else {
            cout << " " << distances[index];
        }
    }
    cout << "\n";
}

void printSequence(const char* label, const vector<int>& sequence) {
    cout << label;
    // empty() 返回 bool，表示没有元素；不可达路径不能访问 sequence[0]。
    if (sequence.empty()) {
        cout << " none";
    }
    for (vector<int>::size_type index = 0; index < sequence.size(); ++index) {
        cout << " " << sequence[index];
    }
    cout << "\n";
}

int main() {
    NonnegativeGraph graph(6, true);
    graph.addEdge(0, 1, 5);
    graph.addEdge(0, 1, 0);
    graph.addEdge(1, 0, 0);
    graph.addEdge(0, 2, 7);
    graph.addEdge(1, 2, 2);
    graph.addEdge(1, 3, 6);
    graph.addEdge(2, 3, 1);
    graph.addEdge(3, 4, 3);
    graph.addEdge(2, 4, 10);
    DijkstraResult result = dijkstra(graph, 0);
    printDistances(result.dist);
    printSequence("Dijkstra predecessors:", result.predecessor);
    printSequence("Path 0->4:", restoreDijkstraPath(result, 4));
    printSequence("Path 0->5:", restoreDijkstraPath(result, 5));
    printSequence("Path 0->0:", restoreDijkstraPath(result, 0));

    long long expectedArray[] = {0, 0, 2, 3, 6, INF};
    // vector(first, last) 复制 C 数组 [first, last)；末尾指针在最后元素之后。
    vector<long long> expected(expectedArray, expectedArray + 6);
    // vector 的 == 比较长度和逐项内容，O(V)，不是比较两块内存的地址。
    assert(result.dist == expected);
    int expectedPathArray[] = {0, 1, 2, 3, 4};
    vector<int> expectedPath(expectedPathArray, expectedPathArray + 5);
    assert(restoreDijkstraPath(result, 4) == expectedPath);
    assert(result.predecessor[0] == -1 && result.predecessor[5] == -1);
    assert(restoreDijkstraPath(result, 5).empty());
    assert(restoreDijkstraPath(result, 0).size() == 1);
    assert(graph.matrix[0][1] == 0);

    NonnegativeGraph singleGraph(1, false);
    DijkstraResult singleResult = dijkstra(singleGraph, 0);
    cout << "Single distance: " << singleResult.dist[0] << "\n";
    assert(singleResult.dist[0] == 0 && singleResult.predecessor[0] == -1);
    NonnegativeGraph undirectedGraph(2, false);
    undirectedGraph.addEdge(0, 1, 0);
    DijkstraResult reverseResult = dijkstra(undirectedGraph, 1);
    assert(reverseResult.dist[0] == 0 && reverseResult.predecessor[0] == 1);

    bool negativeRejected = false;
    try {
        graph.addEdge(5, 5, -1);
    } catch (const invalid_argument&) {
        negativeRejected = true;
    }
    cout << "Negative edge: " << (negativeRejected ? "rejected" : "accepted") << "\n";
    assert(negativeRejected && graph.matrix[5][5] == INF);

    NonnegativeGraph emptyGraph(0, true);
    bool emptySourceRejected = false;
    try {
        dijkstra(emptyGraph, 0);
    } catch (const out_of_range&) {
        emptySourceRejected = true;
    }
    cout << "Empty source: " << (emptySourceRejected ? "rejected" : "accepted") << "\n";
    assert(emptySourceRejected);
    return 0;
}
```

```text
Dijkstra predecessors: -1 0 1 2 3 -1

Path 0->0: 0
```

### 复杂度与易错点

选最小距离和扫描邻居都用普通循环，时间 $O(V^2)$；矩阵空间 $O(V^2)$，算法工作数组与结果空间 $O(V)$；单条路径还原为 $O(V)$。

- 不要用 `if (weight)` 判断存在边，0 权边也是合法边；要与 `INF` 比较。
- 只有严格变短才更新距离和前驱，等长路线保留先找到的那一条。即使有 0 权环，前驱也来自先确定的顶点，不会形成前驱环。
- 不可达时不要继续用 `INF + weight` 松弛；不要把 `predecessor == -1` 单独当成不可达，因为源点的前驱也是 `-1`。
- 不能用 BFS 代替不等权最短路，也不能把 Prim 的“最小接入边”当成 Dijkstra 的“累计最短距离”。

## 程序四：Floyd 全源最短路与路径还原

### 思路与接口

`dist[from][to]` 是从 `from` 到 `to` 的当前最短距离。每轮允许多用一个编号为 `middle` 的中转点：如果两段都可达，尝试用 `dist[from][middle] + dist[middle][to]` 改善原距离。**middle 必须在最外层**，内层才是起点和终点，不能随意调换这层动态规划的顺序。

本程序的 `matrix` 直接采用 Floyd 初始距离约定：对角线为 0，其余无边位置为 `INF`。`addEdge` 取原值和边权的较小者，因而重边取最小权，正自环不覆盖 0，负自环保留为负数。无向负边等价于两个方向的负边，可以来回走出负环，因此这种输入会被拒绝；这和 MST 允许无向负边不矛盾。

- `floyd(graph)` 返回 `FloydResult`：正常时 `hasNegativeCycle == false`，带有距离矩阵 `dist` 和下一跳矩阵 `next`。无边、不可达是 `INF` 和 `-1`，不是 0。
- `next[from][to]` 表示从 `from` 去往 `to` 时，**下一步实际走到的相邻顶点**。初始化时，有限直接距离对应 `next[from][to] = to`，对角为自身。经中转点变短后，下一跳取 `next[from][middle]`，不是简单地填 `middle`。
- `restoreFloydPath(result, source, target)` 返回实际路径。不可达返回空 `vector`；起终点相同返回一个顶点，表示权值 0 的空走法。
- 如果某个 `dist[vertex][vertex] < 0`，就存在负环。**初始化后先检查负自环，每完成一轮 middle 再扫描全部对角线，发现后立即返回。** 返回值的 `hasNegativeCycle == true`，两个矩阵都为空，不暴露半成品距离。
- 本篇采用简单的全图失败约定：任何连通部分出现负环，都拒绝整份结果，不细分哪些点对仍然安全。对失败结果调用还原函数会抛 `logic_error`，不会开始沿 `next` 循环；正常结果的还原也设有最多 `V - 1` 次跳转的保护。
- 空图正常返回两个空矩阵，但没有合法的路径查询下标；孤立点到自身为 0，到其他点不可达。

### 为什么不会把 INF 或负环算出溢出

两段距离只要有一个是 `INF`，就不做加法。否则 `INF + (-2)` 会比 `INF` 小，错误地产生“可达”路径。

每一轮开始时，先前的对角检查保证对角线均为 0。当前 `middle` 的行、列不会因为加上自己的 0 对角而变短，所以本轮的候选值只是两段已有有限距离之和。尚未检出负环时，可以选择不重复顶点的最短路径；每段绝对值至多 `199 * 1000000`，单次候选绝对值至多 `398000000`。即使本轮刚暴露负环，也会立即在轮末拒绝，不会继续后面的中转轮次反复放大负数。配合固定输入上限、`long long` 和远大的 `INF`，不需要额外的饱和数运算。

### 完整代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <stdexcept>
#include <cassert>

using namespace std;

const int MAX_VERTICES = 200;
const long long MAX_WEIGHT = 1000000;
const long long INF = 1000000000000LL;

struct FloydGraph {
    int vertexCount;
    bool directed;
    vector<vector<long long> > matrix;

    FloydGraph(int count, bool isDirected)
        : vertexCount(count), directed(isDirected) {
        if (count < 0 || count > MAX_VERTICES) {
            throw invalid_argument("invalid vertex count");
        }
        // vector<T>(count, value) 创建 count 个副本；assign 覆盖内容，返回 void。
        // 外层复制独立的行，不能把无边初始化为 0。
        matrix.assign(count, vector<long long>(count, INF));
        for (int vertex = 0; vertex < count; ++vertex) {
            matrix[vertex][vertex] = 0;
        }
    }

    void checkVertex(int vertex) const {
        if (vertex < 0 || vertex >= vertexCount) {
            throw out_of_range("invalid vertex");
        }
    }

    void addEdge(int from, int to, long long weight) {
        checkVertex(from);
        checkVertex(to);
        if (weight < -MAX_WEIGHT || weight > MAX_WEIGHT) {
            throw invalid_argument("weight out of range");
        }
        // [] 返回元素引用但不检查越界；min(a, b) 返回较小值，需赋回保存。
        // 重边取最小；负自环不会被对角线原有的 0 吞掉。
        matrix[from][to] = min(matrix[from][to], weight);
        if (!directed && from != to) {
            matrix[to][from] = min(matrix[to][from], weight);
        }
    }
};

struct FloydResult {
    bool hasNegativeCycle;
    vector<vector<long long> > dist;
    vector<vector<int> > next;

    explicit FloydResult(bool negativeCycle = false)
        : hasNegativeCycle(negativeCycle) {}
};

bool hasNegativeDiagonal(const vector<vector<long long> >& distances) {
    // size() 返回无符号长度；本图最多 200 行，转 int 安全。
    int vertexCount = static_cast<int>(distances.size());
    for (int vertex = 0; vertex < vertexCount; ++vertex) {
        if (distances[vertex][vertex] < 0) {
            return true;
        }
    }
    return false;
}

FloydResult floyd(const FloydGraph& graph) {
    FloydResult result;
    // vector 赋值逐项复制，包括每行，O(V^2)；更新 result 不会修改原图。
    result.dist = graph.matrix;
    result.next.assign(graph.vertexCount, vector<int>(graph.vertexCount, -1));
    for (int from = 0; from < graph.vertexCount; ++from) {
        for (int to = 0; to < graph.vertexCount; ++to) {
            if (result.dist[from][to] != INF) {
                result.next[from][to] = to;
            }
        }
    }
    if (hasNegativeDiagonal(result.dist)) {
        return FloydResult(true);
    }

    for (int middle = 0; middle < graph.vertexCount; ++middle) {
        for (int from = 0; from < graph.vertexCount; ++from) {
            if (result.dist[from][middle] == INF) {
                continue;
            }
            for (int to = 0; to < graph.vertexCount; ++to) {
                if (result.dist[middle][to] == INF) {
                    continue;
                }
                long long candidate = result.dist[from][middle] + result.dist[middle][to];
                if (candidate < result.dist[from][to]) {
                    result.dist[from][to] = candidate;
                    result.next[from][to] = result.next[from][middle];
                }
            }
        }
        // 必须在每轮结束后检查，不等所有 middle 跑完再拒绝负环。
        // 新建失败结果：标志为 true、矩阵为空，禁止误用局部距离/下一跳。
        if (hasNegativeDiagonal(result.dist)) {
            return FloydResult(true);
        }
    }
    return result;
}

vector<int> restoreFloydPath(const FloydResult& result, int source, int target) {
    if (result.hasNegativeCycle) {
        throw logic_error("negative cycle: paths unavailable");
    }
    int vertexCount = static_cast<int>(result.dist.size());
    if (source < 0 || source >= vertexCount || target < 0 || target >= vertexCount) {
        throw out_of_range("invalid path endpoint");
    }
    vector<int> path;
    if (result.next[source][target] == -1) {
        return path;
    }
    int current = source;
    // push_back(value) 向尾部追加元素，返回 void，均摊 O(1)，扩容可能移动内存。
    path.push_back(current);
    for (int step = 0; current != target && step < vertexCount - 1; ++step) {
        int following = result.next[current][target];
        if (following < 0 || following >= vertexCount) {
            throw logic_error("invalid next matrix");
        }
        current = following;
        path.push_back(current);
    }
    if (current != target) {
        throw logic_error("path reconstruction did not terminate");
    }
    return path;
}

void printDistances(const FloydResult& result) {
    if (result.hasNegativeCycle) {
        cout << "Floyd failed: negative cycle\n";
        return;
    }
    cout << "Floyd distances:\n";
    int vertexCount = static_cast<int>(result.dist.size());
    for (int from = 0; from < vertexCount; ++from) {
        for (int to = 0; to < vertexCount; ++to) {
            if (to != 0) {
                cout << " ";
            }
            if (result.dist[from][to] == INF) {
                cout << "INF";
            } else {
                cout << result.dist[from][to];
            }
        }
        cout << "\n";
    }
}

void printPath(const char* label, const vector<int>& path) {
    cout << label;
    // empty() 返回 bool；size() 是无符号长度，循环用匹配的 size_type。
    if (path.empty()) {
        cout << " none";
    }
    for (vector<int>::size_type index = 0; index < path.size(); ++index) {
        cout << " " << path[index];
    }
    cout << "\n";
}

int main() {
    FloydGraph graph(5, true);
    graph.addEdge(0, 1, 4);
    graph.addEdge(0, 1, 0);
    graph.addEdge(1, 2, -2);
    graph.addEdge(2, 3, 3);
    graph.addEdge(0, 3, 10);
    graph.addEdge(3, 1, 4);
    FloydResult result = floyd(graph);
    assert(!result.hasNegativeCycle);
    printDistances(result);
    printPath("Path 0->3:", restoreFloydPath(result, 0, 3));
    printPath("Path 3->2:", restoreFloydPath(result, 3, 2));
    printPath("Path 0->4:", restoreFloydPath(result, 0, 4));
    printPath("Path 0->0:", restoreFloydPath(result, 0, 0));
    assert(graph.matrix[0][1] == 0 && result.dist[0][3] == 1);
    assert(result.dist[4][2] == INF && result.next[4][2] == -1);
    assert(restoreFloydPath(result, 0, 4).empty());
    int expectedPathArray[] = {0, 1, 2, 3};
    // vector(first, last) 从 C 数组的 [first, last) 复制，不是新版列表初始化。
    vector<int> expectedPath(expectedPathArray, expectedPathArray + 4);
    // == 比较长度和逐项值，O(路径长度)，不比较容器的地址。
    assert(restoreFloydPath(result, 0, 3) == expectedPath);

    FloydGraph singleGraph(1, true);
    FloydResult singleResult = floyd(singleGraph);
    cout << "Single distance: " << singleResult.dist[0][0] << "\n";
    assert(!singleResult.hasNegativeCycle && singleResult.dist[0][0] == 0);
    assert(restoreFloydPath(singleResult, 0, 0).size() == 1);
    FloydGraph emptyGraph(0, true);
    FloydResult emptyResult = floyd(emptyGraph);
    cout << "Empty result: " << (!emptyResult.hasNegativeCycle ? "ok" : "failed") << "\n";
    assert(!emptyResult.hasNegativeCycle && emptyResult.dist.empty() &&
           emptyResult.next.empty());

    FloydGraph negativeGraph(3, true);
    negativeGraph.addEdge(0, 1, 1);
    negativeGraph.addEdge(1, 2, -3);
    negativeGraph.addEdge(2, 0, 1);
    FloydResult negativeResult = floyd(negativeGraph);
    cout << "Negative cycle: " << (negativeResult.hasNegativeCycle ? "detected" : "missed")
         << "\n";
    assert(negativeResult.hasNegativeCycle && negativeResult.dist.empty() &&
           negativeResult.next.empty());
    bool pathRejected = false;
    try {
        restoreFloydPath(negativeResult, 0, 2);
    } catch (const logic_error&) {
        pathRejected = true;
    }
    cout << "Negative-cycle path: " << (pathRejected ? "rejected" : "accepted") << "\n";
    assert(pathRejected);

    FloydGraph negativeSelfLoop(1, true);
    negativeSelfLoop.addEdge(0, 0, -1);
    FloydResult selfLoopResult = floyd(negativeSelfLoop);
    assert(selfLoopResult.hasNegativeCycle);
    FloydGraph undirectedNegative(2, false);
    undirectedNegative.addEdge(0, 1, -1);
    FloydResult undirectedResult = floyd(undirectedNegative);
    assert(undirectedResult.hasNegativeCycle);

    FloydGraph boundaryGraph(MAX_VERTICES, true);
    for (int vertex = 0; vertex < MAX_VERTICES - 1; ++vertex) {
        boundaryGraph.addEdge(vertex, vertex + 1, -MAX_WEIGHT);
    }
    FloydResult boundaryResult = floyd(boundaryGraph);
    assert(!boundaryResult.hasNegativeCycle);
    assert(boundaryResult.dist[0][MAX_VERTICES - 1] ==
           -(MAX_VERTICES - 1) * MAX_WEIGHT);
    assert(restoreFloydPath(boundaryResult, 0, MAX_VERTICES - 1).size() == MAX_VERTICES);
    return 0;
}
```

### 复杂度与易错点

时间 $O(V^3)$，距离矩阵和下一跳矩阵各用 $O(V^2)$ 空间；每轮扫描对角的总开销 $O(V^2)$，不改变总体复杂度。每次路径还原为 $O(V)$ 时间和输出空间。

- 最外层记为 `middle`；若把它放在里面，一轮更新不能表达“只允许使用已枚举中转点”的状态。
- 先将对角置 0，再用最小边权更新；不能在读完边后无条件重置对角，否则会抹掉负自环。
- 加法前必须检查**两段**不是 `INF`，并且不要把 `INF` 当一个真实大边权输入。
- 更新 `next` 必须与距离更新同步；只有严格更短才改，避免等长 0 权路线把下一跳改成自己。
- 有负环时不能继续将距离当答案，更不能无限沿着 `next` 还原。这里整份拒绝，不承诺失败结果中还保存可用点对。

## 默写前的对照表

下表的辅助空间不计输入图，但计入算法返回的结果；完整图表示的存储开销见前文。邻接表里的 $E$ 包括重边，无向表会登记两个方向，但只增加常数倍开销。

| 算法 | 核心状态 | 更新或推进方式 | 时间 | 辅助空间 |
|---|---|---|---|---|
| BFS / DFS 全图遍历 | `visited`、访问序列 | 外层扫所有顶点，内部扩展未访问邻居 | $O(V+E)$ | $O(V)$ |
| DFS 找一条简单路径 | `visited`、当前 `path` | 入栈追加，失败弹出，成功保留 | $O(V+E)$ | $O(V)$ |
| BFS 无权最短路 | `dist`、`predecessor` | 首次发现时 `dist + 1`，入队标记 | $O(V+E)$ | $O(V)$ |
| Prim | `inTree`、`bestEdgeWeight`、`parent` | 用单条接入边权更新 | $O(V^2)$ | $O(V)$ |
| Kruskal | 有序边表、并查集、已选边 | 两端根不同才合并 | $O(V+E\log E)$ | $O(V+E)$ |
| Dijkstra | `settled`、`dist`、`predecessor` | 用源点累计距离加边权松弛 | $O(V^2)$ | $O(V)$ |
| Floyd | `dist`、`next` | 用两段距离之和松弛，中转在最外层 | $O(V^3)$ | $O(V^2)$ |

### 最后检查

1. 图有向还是无向？无向边的矩阵/邻接表补反向，Kruskal 的输入边表不再复制反向。
2. 0 是边权还是无边？这里 0 是合法权，带权无边/不可达用 `INF`。
3. 在找任意路径、最少边数、最小生成树，还是带权最短路？DFS 不保证最短，BFS 不处理不同边权，MST 不优化源点距离。
4. 原图可能不连通吗？遍历加外层扫描，MST 返回失败，最短路保留不可达标记。
5. 前驱或下一跳是否和距离同时更新？不可达与起终点相同是否能分别还原？
6. 权值可能为负吗？MST 允许；Dijkstra 拒绝；Floyd 允许负边，但发现负环立即拒绝结果。
7. 是否仍在本篇 `V <= 200`、权值幅度不超过一百万的范围内？扩大输入前先重新估算复杂度、递归深度、距离界和 `INF`，不要只改常量。
8. 检查配置是否启用了 `assert`。以上示例按 VS2010 可用的语法和库编写，但未据此声称已经在真实 VS2010 编译器上实测；以实际编译运行结果为准。
