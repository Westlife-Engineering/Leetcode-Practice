## 一、vector 基础与顺序栈

### 概念与接口

`vector<int>` 是连续存放 `int` 的动态数组。它适合用末尾作为栈顶：入栈追加到末尾，出栈删除末尾，避免在数组开头移动元素。

- `size()` 是已有元素个数，`capacity()` 是当前分配空间可容纳的元素数，两者不是一回事。
- `vector<int> values(count, value)` 创建 `count` 个初值为 `value` 的元素；`reserve(count)` 只预留空间，不创建元素，不能因此直接访问原先不存在的下标。
- `operator[]` 不检查越界；`back()`、`pop_back()` 要求非空。`push_back()` 可能扩容，使之前保存的指针、引用、迭代器失效。
- `size()` 返回无符号的 `vector<int>::size_type`。不要在空数组上计算 `size() - 1`，也不要用无符号下标判断 `index >= 0` 来结束倒序循环；需要倒序时从 `size()` 开始，先判断 `index > 0`，再访问 `index - 1`。

下面的 `ArrayStack` 只存 `int`，不设固定容量。`top(int& value)` 成功时复制栈顶到输出参数并返回 `true`；空栈时返回 `false`，不修改输出参数。`pop()` 不返回元素，空栈时直接结束。这个带输出参数的 `top` 是手写接口，不是 STL `stack::top()` 的签名。

### 程序 1：动态数组与顺序栈

```cpp
#include <iostream>
#include <vector>
using namespace std;

class ArrayStack {
private:
    vector<int> elements;  // 默认构造得到空动态数组，末尾作为栈顶。

public:
    bool empty() const {
        return elements.empty();  // empty() 返回是否没有元素，O(1)。
    }

    vector<int>::size_type size() const {
        return elements.size();  // size_type 是无符号计数类型；size() 为 O(1)。
    }

    void push(int value) {
        elements.push_back(value);  // 末尾追加一份 value，返回 void，均摊 O(1)。
    }

    bool top(int& value) const {
        if (elements.empty()) {
            return false;
        }
        value = elements.back();  // back() 返回末元素的引用；这里复制到 value，O(1)。
        return true;
    }

    void pop() {
        if (elements.empty()) {
            return;
        }
        elements.pop_back();  // 删除末元素，返回 void，不会返回被删值，O(1)。
    }
};

int main() {
    int initialValues[] = {10, 20, 30};
    // 区间构造复制 [first, last)，右端点不包含；这里复制 C 数组的三个元素。
    vector<int> values(initialValues, initialValues + 3);
    values.push_back(40);

    cout << "vector:";
    for (vector<int>::size_type index = 0; index < values.size(); ++index) {
        cout << ' ' << values[index];  // 下标必须小于 size()；随机访问为 O(1)。
    }
    cout << '\n';

    ArrayStack numbers;
    int topValue = 0;
    cout << "empty=" << numbers.empty() << '\n';
    cout << "top_empty=" << numbers.top(topValue) << '\n';
    numbers.pop();
    cout << "after_empty_pop=" << numbers.size() << '\n';

    for (vector<int>::size_type index = 0; index < values.size(); ++index) {
        numbers.push(values[index]);
    }
    cout << "size=" << numbers.size() << '\n';
    if (numbers.top(topValue)) {
        cout << "top=" << topValue << '\n';
    }

    cout << "pop_order:";
    while (numbers.top(topValue)) {
        numbers.pop();
        cout << ' ' << topValue;  // topValue 已经复制出来，弹栈后仍有效。
    }
    cout << '\n';
    cout << "empty=" << numbers.empty() << '\n';
    return 0;
}
```

### 期望输出

```text

empty=1
top_empty=0
after_empty_pop=0
size=4
top=40
pop_order: 40 30 20 10
empty=1
```

### 复杂度与常见错误

设当前栈内有 $n$ 个元素：`top`、`pop`、`empty`、`size` 都是 $O(1)$；`push` 均摊 $O(1)$，发生扩容的单次操作可能为 $O(n)$。批量压入再弹出 $n$ 个整数总计 $O(n)$。存储空间与底层 `vector` 的容量有关，弹空不保证立即释放已经分配的空间。

不要把“均摊常数”理解成每次都不会复制旧元素。不要保存 `back()` 的引用后再出栈，也不要把 `pop_back()` 当成返回整数的函数。

## 二、STL stack 与括号匹配

### 概念与接口

`stack<char>` 表示存放字符的栈，默认底层是 `deque<char>`。`push(value)` 入栈，`top()` 返回栈顶引用，`pop()` 删除栈顶且返回 `void`，`empty()` 判空，`size()` 返回无符号元素数。STL 的空栈不能调用 `top()` 或 `pop()`；它不会像上面的手写栈那样替你处理空栈。

应用约定：只检查 `()`、`[]`、`{}` 是否正确嵌套，忽略其他字符，不判断算术表达式是否合法。空字符串合法。遇到左括号入栈；遇到右括号，必须与最近尚未匹配的左括号配对，这正是后进先出。

### 程序 2：括号检查

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool bracketsMatch(const string& expression) {
    // const string& 只读引用传参，避免复制整个字符串。
    stack<char> openings;  // stack<T> 只开放栈操作，不能用下标访问内部元素。

    for (string::size_type index = 0; index < expression.size(); ++index) {
        char current = expression[index];  // string::size_type 也是无符号类型。
        if (current == '(' || current == '[' || current == '{') {
            openings.push(current);  // push(const T&) 复制元素入栈，返回 void。
        } else if (current == ')' || current == ']' || current == '}') {
            if (openings.empty()) {
                return false;
            }
            char opening = openings.top();  // top() 返回引用，先复制到局部变量。
            openings.pop();  // pop() 只删除，返回 void；前面已经确保栈不空。

            if ((opening == '(' && current != ')') ||
                (opening == '[' && current != ']') ||
                (opening == '{' && current != '}')) {
                return false;
            }
        }
    }
    return openings.empty();  // 还有左括号未配对时也应判为不合法。
}

int main() {
    const int exampleCount = 6;
    // 这是普通 C 数组初始化，不是 vector 的列表初始化。
    string expressions[exampleCount] = {
        "", "()[]{}", "a+(b*[c-{d}])", "([)]", "(()", ")"
    };

    for (int exampleIndex = 0; exampleIndex < exampleCount; ++exampleIndex) {
        cout << '"' << expressions[exampleIndex] << "\" -> "
             << (bracketsMatch(expressions[exampleIndex]) ? "valid" : "invalid")
             << '\n';
    }
    return 0;
}
```

### 期望输出

```text
"" -> valid
"()[]{}" -> valid
"a+(b*[c-{d}])" -> valid
"([)]" -> invalid
"(()" -> invalid
")" -> invalid
```

### 复杂度与常见错误

设字符串长度为 $n$，扫描时间 $O(n)$，栈的额外空间最坏 $O(n)$。这里默认使用 `deque`，单次 `push`、`pop`、`top`、`empty`、`size` 为 $O(1)$。

常见错误是只比较左右括号数量、不检查嵌套顺序；遇到右括号时不判空；扫描结束后忘记检查是否还剩左括号。字符比较使用单引号，如 `'('`。不能写 `char opening = openings.pop()`，也不能保存栈顶引用后再弹栈。

## 三、STL queue 与固定容量循环队列

### 概念与接口

`queue<int>` 是整数 FIFO 队列，默认底层为 `deque<int>`。`push(value)` 加到队尾，`front()` 返回队首引用，`back()` 返回队尾引用，`pop()` 删除队首且返回 `void`。`front()`、`back()`、`pop()` 都必须在非空时调用。没有 `top()`，也没有下标访问或直接遍历接口。

手写循环队列使用固定长度的 `vector<int>`，不是在每次出队时执行 `erase(begin())`：后者需要把后面的元素前移，单次为 $O(n)$。设固定容量为 $C$：

- `head` 指向队首；非满时 `tail` 指向下一次入队的写入位置；`count` 表示当前元素个数。
- 当 $C>0$ 时，下标处于 $[0,C)$；通过 `(index + 1) % C` 回绕。
- `count == 0` 判空，`count == C` 判满。空和满时都可能有 `head == tail`，不能只比较这两个下标。
- 入队成功才移动 `tail`、增加 `count`；出队成功才移动 `head`、减少 `count`。满队列不覆盖旧元素，失败操作不改变状态。
- 本例把非正容量规范为零容量，空和满同时为真，所有入队、取值、出队操作都失败；判空判满发生在下标访问和取模之前，避免对零取模。

`enqueue(value)`、`dequeue()` 的布尔返回值只表示操作是否成功，不返回元素。`front(int& value)` 成功时复制队首；失败时不修改输出参数。它们是手写类的约定，不要和 STL 的签名混用。

### 程序 3：FIFO 与循环回绕

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

class CircularQueue {
private:
    vector<int> buffer;
    vector<int>::size_type head;
    vector<int>::size_type tail;
    vector<int>::size_type count;

public:
    explicit CircularQueue(int capacity)
        : buffer(capacity > 0 ? capacity : 0, 0), head(0), tail(0), count(0) {
        // vector<int>(数量, 初值) 实际创建槽位，不能只 reserve 后就用下标写。
        // 先把负容量改成 0，避免负数转为无符号数量后申请巨量空间。
    }

    bool empty() const {
        return count == 0;
    }

    bool full() const {
        return count == buffer.size();  // size() 是固定槽位数，不是当前有效元素数。
    }

    vector<int>::size_type size() const {
        return count;
    }

    bool enqueue(int value) {
        if (full()) {
            return false;
        }
        buffer[tail] = value;  // vector 的下标访问为 O(1)；判满后这里才有可用槽位。
        tail = (tail + 1) % buffer.size();
        ++count;
        return true;
    }

    bool front(int& value) const {
        if (empty()) {
            return false;
        }
        value = buffer[head];
        return true;
    }

    bool dequeue() {
        if (empty()) {
            return false;
        }
        head = (head + 1) % buffer.size();
        --count;
        return true;
    }
};

int main() {
    queue<int> waiting;  // queue<T> 默认底层为 deque<T>，按先进先出处理。
    waiting.push(10);  // push(const T&) 在队尾加入元素，返回 void。
    waiting.push(20);
    waiting.push(30);

    if (!waiting.empty()) {
        // front()/back() 只查看队首/队尾，不删除；使用前必须判空。
        cout << "stl_front=" << waiting.front()
             << " stl_back=" << waiting.back() << '\n';
    }
    cout << "stl_fifo:";
    while (!waiting.empty()) {
        int currentValue = waiting.front();  // 返回引用，这里先复制。
        waiting.pop();  // 删除队首，返回 void，复制好的 currentValue 仍然有效。
        cout << ' ' << currentValue;
    }
    cout << '\n';
    cout << "stl_empty=" << waiting.empty() << '\n';

    CircularQueue ring(3);
    int frontValue = 0;
    cout << "ring_empty=" << ring.empty() << '\n';
    cout << "front_empty=" << ring.front(frontValue) << '\n';
    cout << "dequeue_empty=" << ring.dequeue() << '\n';
    ring.enqueue(10);
    ring.enqueue(20);
    ring.enqueue(30);
    cout << "ring_full=" << ring.full() << '\n';
    cout << "enqueue_full=" << ring.enqueue(40) << '\n';

    cout << "ring_removed:";
    for (int removedCount = 0; removedCount < 2; ++removedCount) {
        if (ring.front(frontValue)) {
            ring.dequeue();
            cout << ' ' << frontValue;
        }
    }
    cout << '\n';
    ring.enqueue(40);
    ring.enqueue(50);
    cout << "after_wrap size=" << ring.size() << " full=" << ring.full() << '\n';
    cout << "ring_fifo:";
    while (ring.front(frontValue)) {
        ring.dequeue();
        cout << ' ' << frontValue;
    }
    cout << '\n';
    cout << "ring_empty=" << ring.empty() << '\n';

    CircularQueue zeroCapacity(0);
    cout << "zero_empty=" << zeroCapacity.empty()
         << " zero_full=" << zeroCapacity.full() << '\n';
    cout << "zero_enqueue=" << zeroCapacity.enqueue(1) << '\n';
    cout << "zero_front=" << zeroCapacity.front(frontValue) << '\n';
    cout << "zero_dequeue=" << zeroCapacity.dequeue() << '\n';
    return 0;
}
```

stl_fifo: 10 20 30
stl_empty=1
ring_empty=1
front_empty=0
dequeue_empty=0

容量为 3 的关键状态可手算如下，逻辑内容从队首开始列出：

| 操作结束后 | head | tail | count | 逻辑内容 |
| --- | --- | --- | --- | --- |
| 初始 | 0 | 0 | 0 | 空 |
| 入队 10、20、30 | 0 | 0 | 3 | 10、20、30 |
| 满时尝试入队 40，失败 | 0 | 0 | 3 | 10、20、30 |
| 出队两次 | 2 | 0 | 1 | 30 |
| 入队 40、50 | 2 | 2 | 3 | 30、40、50 |
| 再出队三次 | 2 | 2 | 0 | 空 |

入队 40、50 后物理数组是 `[40, 50, 30]`，但队首在下标 2，因此不能把物理数组顺序当作出队顺序。出队无需清零旧槽位，是否有效由 `head` 和 `count` 决定。

### 复杂度与常见错误

默认 `deque` 支持下，STL `queue` 的 `push`、`pop`、`front`、`back`、`empty`、`size` 都为 $O(1)$。手写循环队列初始化 $O(C)$ 时间、$O(C)$ 空间，之后每次入队、出队、取队首、判空、判满、取当前大小均为 $O(1)$，不会扩容。

常见错误是用 `head == tail` 同时判空和判满；遗漏取模；满时仍推进 `tail` 或覆盖数据；对零容量取模；出队后忘记减少 `count`。本实现用计数区分空满，可以使用全部 $C$ 个槽位，不是“必须空出一个槽位”的另一种实现。

## 四、priority_queue 与任务调度顺序

### 概念与比较器

`priority_queue` 只保证堆顶最优，不保证底层数组整体有序。这里使用 STL，不重复实现堆；手写堆的结构和维护方法参见 [树结构复习](./树.md)。

- `priority_queue<int>`：默认底层 `vector<int>`，比较器为 `less<int>`，是大根堆，最大的整数在 `top()`。
- `priority_queue<int, vector<int>, greater<int> >`：小根堆，最小的整数在 `top()`；`greater<int>` 来自 `<functional>`，相邻模板结束符要写成 `> >`。
- `push(value)` 复制入队；`top()` 返回堆顶的只读引用；`pop()` 删除堆顶，返回 `void`。`top()`、`pop()` 都要求非空。
- 对优先级队列而言，`Compare(left, right)` 返回 `true` 表示左对象应排在右对象后面，即左对象的出队优先级更低。因此 `less<int>` 让较小值靠后，`greater<int>` 让较大值靠后。
- 比较器必须符合严格弱序：对象和自己比较要返回 `false`，先后关系应自洽；不能把 `<` 随意写成 `<=`。下面逐字段比较，不用两数相减，避免差值溢出。

调度约定：`priority` 数字越大越先处理；相同优先级按到达序号 `order` 从小到大处理。`order` 由调用者按到达顺序分配，要求不重复且不溢出，任务 `id` 不参与排序。优先级队列本身不保证稳定性，如果优先级和到达序号都相同，无法保证二者的先后。本例只演示待处理任务的取出顺序，不模拟时间或抢占。

### 程序 4：大小根堆与自定义任务比较器

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

struct Job {
    int id;
    int priority;
    int order;

    Job(int jobId, int jobPriority, int arrivalOrder)
        : id(jobId), priority(jobPriority), order(arrivalOrder) {
    }
};

struct JobCompare {
    // 函数对象：const 引用避免复制任务；末尾 const 表示比较不改变比较器。
    bool operator()(const Job& left, const Job& right) const {
        if (left.priority != right.priority) {
            return left.priority < right.priority;  // 数字小的优先级低。
        }
        return left.order > right.order;  // 同优先级时，后到的排在后面。
    }
};

int main() {
    int numbers[] = {4, 1, 7, 3};
    priority_queue<int> maxHeap;  // 默认 less<int>，top() 是最大值。
    // 参数依次为元素类型、底层容器、比较器类型；greater<int> 让最小值在顶。
    priority_queue<int, vector<int>, greater<int> > minHeap;
    for (int numberIndex = 0; numberIndex < 4; ++numberIndex) {
        maxHeap.push(numbers[numberIndex]);  // push(const T&) 复制元素，返回 void。
        minHeap.push(numbers[numberIndex]);
    }

    cout << "max_heap:";
    while (!maxHeap.empty()) {
        int currentValue = maxHeap.top();  // top() 返回只读引用，先复制再 pop()。
        maxHeap.pop();  // 删除堆顶、重新维护堆，返回 void，不返回被删值。
        cout << ' ' << currentValue;
    }
    cout << '\n';

    cout << "min_heap:";
    while (!minHeap.empty()) {
        int currentValue = minHeap.top();
        minHeap.pop();
        cout << ' ' << currentValue;
    }
    cout << '\n';

    priority_queue<Job, vector<Job>, JobCompare> jobs;
    jobs.push(Job(40, 2, 0));  // 普通构造函数生成任务；push 复制任务到内部容器。
    jobs.push(Job(20, 5, 1));
    jobs.push(Job(10, 5, 2));
    jobs.push(Job(30, 1, 3));

    cout << "schedule:" << '\n';
    while (!jobs.empty()) {
        Job currentJob = jobs.top();  // 复制整个结构体；不能留下堆顶引用再弹出。
        jobs.pop();
        cout << "id=" << currentJob.id << " priority=" << currentJob.priority
             << " order=" << currentJob.order << '\n';
    }
    cout << "jobs_empty=" << jobs.empty() << '\n';
    return 0;
}
```

### 复杂度与常见错误

设堆中有 $n$ 个元素，且复制元素、比较两个元素的代价为 $O(1)$，本例的整数和三个整数字段的任务满足这一点：

| 操作 | 复杂度 |
| --- | --- |
| `top()`、`empty()`、`size()` | $O(1)$ |
| `push(value)` | 堆调整 $O(\log n)$；默认 `vector` 下整体均摊 $O(\log n)$，扩容的单次操作可能 $O(n)$ |
| `pop()` | $O(\log n)$；删除堆顶后还要恢复堆序，不是普通栈的常数时间删除 |
| 逐个加入再全部取出 $n$ 个元素 | $O(n\log n)$ 时间，$O(n)$ 存储空间 |

常见错误是把比较器方向写反、以为同优先级自动 FIFO、未判空就取堆顶，以及试图直接修改 `top()` 返回对象的字段。`priority_queue` 不提供遍历、任意位置删除或修改优先级的接口；要处理当前堆顶，应先复制、弹出，修改后需要重新入队时再 `push`。外部对象改变不会自动改变已经复制到队列中的对象。

## 考前核对

- 能解释栈顶、队首、队尾和堆顶分别在哪里，能写对 `top()` 与 `front()`。
- STL 的 `pop()` 不返回元素；先判空，再复制取值，再弹出。不在弹出或扩容后继续使用旧引用。
- 能手算循环队列的 `head/tail/count`，能解释为什么“下标相等”不一定是空队列。
- 能把“数字越大越优先；相同则先到先处理”准确翻译成严格比较器。
- 能说明顺序栈追加的均摊复杂度，以及优先级队列为什么出队还需要 $O(\log n)$。
