# 84 柱状图中最大的矩形

- 难度：困难
- 标签：栈、数组、**单调栈**
- 力扣链接：https://leetcode.cn/problems/largest-rectangle-in-histogram/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/largest-rectangle-in-histogram/)（slug：`zhu-zhuang-tu-zhong-zui-da-de-ju-xing-by-leetcode-`，官方篇）。正文主解是 **单调递增栈 + 哨兵**，一次遍历 O(n) 同时确定每根柱子的左右边界。
>
> 这是**单调栈最经典的难题**。它和 `739 每日温度` 并称单调栈双壁：739 用**单调递减栈**找「下一个更大」（栈里存的等一个更高温度），84 用**单调递增栈**找「下一个更小」（栈里存的等一根更矮柱子来封边）。两者栈方向相反，但套路同源。

## 题目描述

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

> 两个要点：每根柱子**宽度都是 1**；矩形要**完全包在柱子内部**（不能悬空，矩形某段的高度不能超过那段最矮的柱子）。

**示例 1：**

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 5 × 2 = 10
```

**示例 2：**

```
输入：heights = [2,4]
输出：4
```

**数据范围：**

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

## 思路

> 本题参考力扣官方题解的「方法二：单调栈 + 常数优化」，主解用「哨兵」技巧把边界处理干净。

### 核心难点：最大矩形的高一定是某根柱子的高度

这是全题最关键的观察。我们要枚举的对象不是「矩形的位置」，而是**矩形的高**——而且这个高一定取自 `heights` 里的某一根柱子。

为什么？反证法：假设最大矩形的高 `h` 不是任何一根柱子的高度，那我们可以把 `h` 往上抬一点点，直到它顶到某根柱子的顶端（即等于某根 `heights[i]`）。抬高的过程中矩形宽度不变、面积变大，与「最大」矛盾。所以**最优矩形的高 = 某根 `heights[i]`**。

于是问题变成：**固定每根柱子 `i` 当高，求它能撑多宽**。

### 对每根柱子，要找左右两边第一个比它矮的柱子

固定 `heights[i]` 当高时，这个矩形能往左延伸到哪、往右延伸到哪？答案是：**左右两边各遇到第一根比 `heights[i]` 矮的柱子就停下**（更矮的柱子撑不住这个高度）。

设 `left[i]` = `i` 左侧第一个比 `heights[i]` 矮的柱子的下标，`right[i]` = `i` 右侧第一个比 `heights[i]` 矮的柱子的下标。则：

```
以 heights[i] 为高的最大矩形：
    宽 w = right[i] - left[i] - 1   （左右边界之间不含边界的柱子数）
    面积 = heights[i] × w
```

> 举例 `heights = [2,1,5,6,2,3]`，看下标 2 那根高 5 的柱子：
> - 左边第一个比 5 矮的是下标 1（高 1）→ `left[2] = 1`
> - 右边第一个比 5 矮的是下标 4（高 2）→ `right[4]... 即 right[2] = 4`
> - 宽 = 4 - 1 - 1 = 2（下标 2、3 两根柱子，即高 5 和高 6，都 ≥ 5）
> - 面积 = 5 × 2 = **10** ← 这就是答案
>
> 注意下标 3 那根高 6 的柱子单独当高时面积只有 6×1=6（它右边立刻遇到 2），所以最优解是「以高 5 那根为高」而不是「以高 6 那根为高」。这就是为什么**必须每根都枚举一遍**，不能只看最高的。

### 暴力（O(n²)，会超时）

对每个 `i`，向左右各扫一遍找第一根更矮的柱子。`n = 10^5` 时 `n² = 10^10`，超时。

### 关键观察：能用单调递增栈一次扫完左右边界

回顾刚才要找的东西：「**i 左侧第一个比它矮的下标**」和「**i 右侧第一个比它矮的下标**」。这正是单调栈的拿手好戏。

官方题解给了一个精炼的「挡住」论证：若有两根柱子 `j0 < j1` 且 `heights[j0] >= heights[j1]`，那么对 `j1` 之后出现的任何柱子 `i` 来说，`j0` **永远不可能是 `i` 左侧最近的更矮柱子**——因为 `j1` 更近又更矮（或等高），把 `j0` 「挡住」了。

由此推出：作为「候选左边界」留在栈里的柱子，其高度必须**严格单调递增**（从栈底到栈顶）。一旦违反，靠左那根就被挡住、没用了。

### 单调栈做法（栈里存下标）

维护一个**存下标**的单调递增栈（栈内下标对应的高度从栈底到栈顶递增）。从左往右遍历每根柱子 `i`：

1. **只要当前 `heights[i]` 比栈顶柱子矮**，栈顶柱子的矩形就**不能再往右延伸**了（`i` 就是它的右边界）。于是弹出栈顶，立刻结算它的面积。
2. 弹完后，**新的栈顶**就是这根被弹出的柱子的**左边界**（左边第一根比它矮的）。
3. 把 `i` 压栈，继续。

为什么「弹出时」就能确定右边界？因为 `i` 是从左往右第一个让栈顶「站不住」的位置，也就是说 `i` 是栈顶右边第一根更矮的柱子，正好就是 `right[栈顶]`。左边界同理——栈里维护的是递增序列，栈顶下面那根（弹出后的新栈顶）天然就是它左边第一根更矮的。

### 宽度公式 `i - stk.top() - 1` 怎么来的

设被弹出的下标是 `top`，此时：

- **右边界** = `i`（让 `top` 被弹出的那根更矮柱子）
- **左边界** = 弹出 `top` 后的**新栈顶**（`top` 左边第一根更矮的柱子）
- 矩形横跨下标 `(左边界, 右边界)`，即 `left+1, left+2, ..., right-1`，个数 = `(right-1) - (left+1) + 1 = right - left - 1`

代入 `right = i`、`left = stk.top()`（新栈顶）：

```
w = i - stk.top() - 1
```

**特殊情况**：如果弹空了栈（`top` 左边没有任何更矮柱子），左边界视为虚拟的 `-1`，此时 `w = i - (-1) - 1 = i`。代码里用三元 `stk.empty() ? i : i - stk.top() - 1` 兜住。

### 哨兵技巧：处理边界 + 收尾

还有两个麻烦：

- 遍历结束时，栈里可能还剩一些柱子（它们右边一直没遇到更矮的），**没被结算**。
- 每次判栈空 `stk.empty()` 有点烦。

**哨兵**一招解决：在 `heights` **末尾追加一个高度 0** 的虚拟柱子。因为 `0` 比任何柱子都矮，遍历到它时会把栈里残留的柱子**全部弹出结算**，一个不漏。这就是「哨兵」——一根不参与答案、专门负责把大家赶出栈的虚拟柱子。

> 官方题解还提到可以在**首部**也加一个 0 哨兵，那样栈底始终压着它、永远不会弹空，宽度公式就能省掉三元判断直接写 `i - stk.top() - 1`。本文主解只在尾部加哨兵、保留三元判断，是为了把「左边界 -1」这层逻辑写明白；两种写法等价，复盘里再细说。

### 手动推演 `heights = [2,1,5,6,2,3]`（末尾加哨兵 0 → `[2,1,5,6,2,3,0]`）

栈里存下标，括号标对应高度。`ans` 跟踪最大面积：

```
i=0 (2):  栈空，直接压。                       栈=[0(2)]                      ans=0
i=1 (1):  1<2 弹 0;  h=2, 栈空→w=1,  area=2;   压 1。 栈=[1(1)]               ans=2
i=2 (5):  5≥1 不弹，压。                       栈=[1(1),2(5)]                 ans=2
i=3 (6):  6≥5 不弹，压。                       栈=[1(1),2(5),3(6)]            ans=2
i=4 (2):  2<6 弹 3;  h=6, w=4-2-1=1, area=6;   ← 以高6为高，只有它自己
          2<5 弹 2;  h=5, w=4-1-1=2, area=10;  ← 以高5为高，横跨下标2,3（宽2）
          2≥1 停;  压 4。                       栈=[1(1),4(2)]                 ans=10
i=5 (3):  3≥2 不弹，压。                       栈=[1(1),4(2),5(3)]            ans=10
i=6 (0):  ← 哨兵登场，把残留全部赶出栈
          0<3 弹 5;  h=3, w=6-4-1=1, area=3;
          0<2 弹 4;  h=2, w=6-1-1=4, area=8;   ← 以高2为高，横跨下标2,3,4,5（宽4）
          0<1 弹 1;  h=1, 栈空→w=6, area=6;    ← 以高1为高，整条6根（宽6）
          压 6。                                栈=[6(0)]                      ans=10
```

最大面积 **10**（以高 5 那根柱子为高、宽 2 的矩形）。和示例一致。

## 代码

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();

        // 末尾追加一个高度 0 的「哨兵」柱子。
        //   - 0 比任何真实柱子都矮，遍历到它时会强制把栈里残留的柱子全部弹出结算，
        //     省掉「遍历结束再单独清栈」的收尾代码。
        //   - heights 是引用参数，push_back 会修改原数组；力扣判定不复用输入，安全。
        heights.push_back(0);

        // stack<int> stk：栈，元素是 int 类型的「数组下标」（不是高度值！）。
        //   - 头文件 <stack>，力扣 C++ 模板默认已包含。
        //   - 空构造 stack() 默认底层用 deque<int>。
        //   - 不变式：从栈底到栈顶，下标对应的高度「单调递增」（等高也弹，见下）。
        //   - 常用操作（均 O(1)）：
        //       stk.push(x) ：入栈；
        //       stk.top()   ：返回栈顶 const 引用，不弹出；空栈调用是未定义行为；
        //       stk.pop()   ：弹出栈顶，无返回值；空栈调用是未定义行为；
        //       stk.empty() ：是否为空。
        //   - 每个下标至多入栈一次、出栈一次 → 均摊 O(1)，总 O(n)。
        stack<int> stk;

        int ans = 0;

        // 遍历到 n（含哨兵）：原数组 0..n-1，加哨兵后长度 n+1，下标 0..n 都要走到。
        for (int i = 0; i <= n; ++i) {
            // 弹栈条件（单调递增栈的核心）：当前柱子比栈顶「矮」。
            //   - 含义：栈顶柱子的矩形不能再向右延伸了，i 就是它的右边界。
            //   - 必须先判 !stk.empty()：空栈时 top() 是未定义行为（会崩）。
            //   - 注意是严格 < 不是 <=：遇到等高时也弹，不影响最终答案
            //     （等高柱子中最右那根能算对边界，官方题解有论证，见 Q3）。
            while (!stk.empty() && heights[i] < heights[stk.top()]) {
                int h = heights[stk.top()];  // 被弹出柱子的高度，作为矩形的高
                stk.pop();                   // 弹出它，新的栈顶就是它的「左边界」

                // 宽度公式：右边界 i，左边界 = 弹出后的新栈顶 stk.top()。
                //   - 一般情况：w = i - stk.top() - 1（夹在两个更矮柱子之间的柱子数）
                //   - 栈弹空了：说明它左边没有更矮的柱子，左边界视为虚拟的 -1，
                //     此时 w = i - (-1) - 1 = i，直接取 i。
                //   - 两种情况用三元合并：stk.empty() ? i : i - stk.top() - 1
                int w = stk.empty() ? i : i - stk.top() - 1;

                // 以 h 为高、w 为宽的矩形面积，更新答案。
                ans = max(ans, h * w);
            }
            stk.push(i);  // 当前柱子入栈，等待以后被一根更矮的柱子「封边」结算
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n)
  - 每个下标（含哨兵）至多入栈一次、出栈一次，所有 push/pop 加起来是 O(n)，均摊到每步 O(1)。
- **空间**：O(n)
  - 最坏情况（数组严格单调递增，如 `[1,2,3,4,5]`）所有下标都压在栈里，直到哨兵出现才一次性弹出，栈最大 n 个元素。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：为什么「枚举高」而不是「枚举宽」？最大矩形的高为什么一定是某根柱子的高度？

反证法：如果最大矩形的高 `h` 不是任何 `heights[i]`，那把 `h` 稍微抬高一点点（宽度不变），直到顶到某根柱子的顶端 `heights[i]`，面积只会变大，与「最大」矛盾。所以**最优矩形的高一定取自某根柱子**。

「枚举宽」要双重循环定左右边界再求最小高度，本身已经 O(n²)，不好优化；「枚举高」只需一重循环，配上单调栈就能优化到 O(n)。所以官方和本文都走「枚举高」这条路。

### Q2：宽度公式 `i - stk.top() - 1` 怎么来的？为什么弹空了宽度就是 `i`？

被弹出的柱子下标记为 `top`：

- 右边界 = `i`（当前这根比它矮，让它被弹出，所以 `i` 是它右边第一根更矮的）
- 左边界 = 弹出 `top` 后的新栈顶（栈是递增的，新栈顶就是它左边第一根更矮的）

矩形横跨 `(左边界, 右边界)` 这个**开区间**内的柱子，个数 = `右边界 - 左边界 - 1 = i - stk.top() - 1`。

栈弹空时，说明 `top` 左边没有任何更矮柱子，左边界是虚拟的 `-1`（数组最左外），代入 `i - (-1) - 1 = i`，所以宽度直接是 `i`（下标 0 到 i-1，共 i 根）。

### Q3：为什么用单调**递增**栈？和 739 每日温度的**递减**栈方向为什么相反？

取决于**你要找什么**：

- 739 每日温度：对每个位置找「右边第一个**更大**的」。栈里存的是「还在等一个更高温度」的位置，新来的只要更高就能让栈顶出栈——所以栈里高度**递减**（从栈底到栈顶越来越矮，栈顶最急迫地等着）。
- 84 柱状图：对每个位置找「右边第一个**更小**的」。新来的只要**更矮**就能让栈顶出栈（封住右边界）——所以栈里高度**递增**。

一句话总结：**找更大用递减栈，找更小用递增栈**。两者都是「存下标、等触发、触发即结算」，只是弹栈方向（比较符号）反过来。

### Q4：哨兵为什么能省事？前后都加 0 有什么区别？

- **只在末尾加 0**（本文主解）：作用是**收尾**——遍历到这个 0 时，把栈里「右边一直没遇到更矮」的残留柱子全部弹出结算。省掉循环结束后再单独清栈的代码。
- **首尾都加 0**：首部那个 0 永远压在栈底（没有任何柱子比 0 还矮，弹不动它），所以栈**永远不会空**。这样 `stk.top()` 前不用判 `empty()`，宽度公式直接写 `i - stk.top() - 1`，连三元都省了。代价是要在数组前面 `insert`，或用「下标偏移」模拟。

两种写法等价，本文保留三元判断是为了把「左边界 -1」的逻辑写显式，便于理解。

### Q5：遇到**等高**柱子（`heights[i] == heights[stk.top()]`）怎么处理？

本文用严格 `<`（等高也弹）。等高柱子被提前弹出时，它算出的右边界是「小于等于」而非严格小于，看似不精确，但**最终答案不受影响**：因为等高的一串柱子里，**最右边那根**会等到真正更矮的柱子出现才被弹出，它能算对完整的左右边界，面积正确。官方题解对此有论证。如果改成 `<=`（等高不弹），也正确，只是栈里会堆积一串等高下标，没有好处。

## 复盘

- **核心套路（单调栈求「左右第一个更大/更小」确定区间）**：凡是要对每个元素找「左边/右边第一个比它大/小的位置」，进而确定一个区间的问题，单调栈几乎是标配模板。84 是这个模板最经典的难题。
- **解题三段式**：① 最大矩形的高 = 某根柱子高度（枚举高）；② 对每根柱子要找左右第一个更矮的（定宽）；③ 单调递增栈一次遍历同时敲定左右边界 + 哨兵收尾。
- **和 739 的对比（单调栈双壁）**：

  | | 739 每日温度 | 84 柱状图最大矩形 |
  |---|---|---|
  | 找什么 | 右边第一个**更大** | 右边第一个**更小** |
  | 栈方向 | 单调**递减**栈 | 单调**递增**栈 |
  | 弹栈条件 | 当前 > 栈顶 | 当前 < 栈顶 |
  | 结算时机 | 弹栈时记录「等待天数」 | 弹栈时算「高 × 宽」面积 |
  | 复杂度 | O(n) 时间 / O(n) 空间 | O(n) 时间 / O(n) 空间 |

- **可迁移**：
  - **85 最大矩形**：把每一行往上看作「柱状图的一行高度」，对每行套一次 84 的单调栈即可。84 是 85 的子程序。
  - **42 接雨水**的单调栈解法：同样是「存下标的单调栈 + 弹栈时结算」，但接雨水用**递减栈**（找左右更高来接水），方向恰好和 84 相反。三道题串起来练，单调栈就通透了。
- **STL 要点**：`stack<int>` 存下标；`top()`/`pop()` 前必判 `empty()`；用哨兵可以免除判空但会改输入数组。

### 解法二：官方方法一，两次单调栈求 left[]/right[]

官方题解的「方法一」更直观但常数稍大：**分别**从左往右、从右往左各跑一次单调栈，先求出每根柱子的 `left[i]`（左侧第一个更矮下标）和 `right[i]`（右侧第一个更矮下标），最后一遍扫算面积。适合用来理解「左右边界」的概念，主解的一次遍历正是对它的常数优化。

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        // vector<int> left(n), right(n)：两个长度 n 的整型数组，存每根柱子的左右边界下标。
        vector<int> left(n), right(n);

        // 第一次单调栈：从左往右，求 left[i] = i 左侧第一个更矮柱子的下标。
        stack<int> mono_stack;
        for (int i = 0; i < n; ++i) {
            // 栈内高度递增；把「高度 >= 当前」的栈顶弹出（它们被当前挡住，不再可能是别人的左边界）。
            while (!mono_stack.empty() && heights[mono_stack.top()] >= heights[i]) {
                mono_stack.pop();
            }
            // 栈空 → 左边没有更矮的，左边界视为虚拟的 -1。
            left[i] = (mono_stack.empty() ? -1 : mono_stack.top());
            mono_stack.push(i);
        }

        // 第二次单调栈：从右往左，求 right[i] = i 右侧第一个更矮柱子的下标。
        mono_stack = stack<int>();  // 清空栈：用一个全新的空 stack 赋值，等价于清空。
        for (int i = n - 1; i >= 0; --i) {
            while (!mono_stack.empty() && heights[mono_stack.top()] >= heights[i]) {
                mono_stack.pop();
            }
            right[i] = (mono_stack.empty() ? n : mono_stack.top());
            mono_stack.push(i);
        }

        // 第三遍：对每根柱子算「以其为高」的最大面积。
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            // 宽 = right[i] - left[i] - 1（左右边界开区间内的柱子数）。
            ans = max(ans, (right[i] - left[i] - 1) * heights[i]);
        }
        return ans;
    }
};
```

- **时间**：O(n)——三次线性扫描，每次每个元素进出栈各一次。
- **空间**：O(n)——两个边界数组 + 栈。
- **和主解的对比**：主解把「确定左边界（入栈时）」和「确定右边界（出栈时）」合到同一次遍历里，省掉了 `left[]`、`right[]` 数组和第二、三次扫描，常数更小，但理解门槛略高。先看懂解法二，再看主解的「一次遍历」会顺理成章。
