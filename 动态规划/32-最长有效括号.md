- 标签：栈、字符串、**动态规划**
- 力扣链接：https://leetcode.cn/problems/longest-valid-parentheses/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/longest-valid-parentheses/solution/zui-chang-you-xiao-gua-hao-by-leetcode-solution/)「最长有效括号」（slug：`zui-chang-you-xiao-gua-hao-by-leetcode-solution`）。正文主解是 **动态规划**——`dp[i]` 表示「以下标 i 结尾的最长有效括号长度」，根据 `s[i]` 是 `)` 还是 `(`、以及 `s[i-1]` 和 `dp[i-1]` 分情况转移，这和本目录主题「动态规划」最对应。官方同一篇文章还给了「栈」和「正向/反向两次扫描」两种解法，写法更短，放在「复盘」对比。

## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 `"(()())"`。

**示例 1：**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```
输入：s = ""
输出：0
```

**提示：**

- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

## 思路

> 本题主要参考力扣官方题解「方法一：动态规划」。

要求的是「最长有效括号子串的长度」，关键词是**最长**和**连续**。「最长」立刻让人想到动态规划或滑动窗口；而「有效括号」的判定又和「以某个位置结尾是否能闭合」强相关。把这两个角度合起来，就得到一个非常自然的 DP 状态定义。

### DP 三要素

#### ① 状态定义：`dp[i]` = 以下标 `i` 的字符**结尾**的最长有效括号子串长度

这是全题最关键的一步。注意口径是「**以下标 i 结尾**」，不是「前 i 个」——因为我们关心的是**连续**子串，一个子串必然有右端点，把右端点固定成 `i`，问题就变成「以 `i` 结尾的最长有效子串有多长」。

为什么按「结尾」定义而不是按「开头」？因为括号闭合的判断是从左括号往右找右括号，右括号出现时才能「结算」这一对的贡献——也就是说，信息是从**右端点**往左推的。以右端点为状态，转移方向自然。

最终答案 = `dp` 数组里的最大值 `max(dp[i])`（不是 `dp[n-1]`！因为最长子串不一定以最后一个字符结尾）。

#### ② 初始条件：`dp[i]` 全部初始化为 `0`

这点和别的 DP 不太一样——**所有位置默认 0**，不用单独算 `dp[0]`。原因是：

- 以 `(` 结尾的子串不可能有效（左括号没闭合，单独一个 `(` 谈不上有效），所以只要 `s[i] == '('`，`dp[i]` 就是 0，保持默认即可。
- 只有 `s[i] == ')'` 时才可能 `dp[i] > 0`，需要分类讨论去计算。

代码因此从 `i = 1` 开始遍历（`i = 0` 单个字符不可能有效，必为 0）。

#### ③ 状态转移方程：分两大情况（核心，最绕的地方）

遍历到 `s[i]`，先看它是 `(` 还是 `)`：

**情况 0：`s[i] == '('`** → `dp[i] = 0`。

以 `(` 结尾的子串不可能有效，直接保持默认值 0，什么都不做。

**情况 1：`s[i] == ')'`** → 再按 `s[i-1]` 是什么细分。目标是「把 `s[i]` 这个右括号也闭合进有效子串」，看能不能和前面的某个 `(` 配上对。

**子情况 1a：`s[i-1] == '('`，即结尾形如 `……()`。**

紧挨着的 `s[i-1]` 正好是个左括号，它和 `s[i]` 直接凑成一对 `"()"`。这一对贡献长度 2，再加上「这一对前面那段」如果是有效子串，就连起来：

```
dp[i] = dp[i-2] + 2
```

含义：`s[i-1..i]` 是 `"()"`（长度 2），它前面 `s[0..i-2]` 里以 `i-2` 结尾的最长有效子串长度是 `dp[i-2]`，两者拼起来还是连续有效的（因为前一段以 `)` 结尾，接上 `()` 不破坏结构）。

边界：当 `i == 1` 时不存在 `i-2`（越界），此时 `"()"` 前面没东西，`dp[i] = 0 + 2 = 2`。代码里写成 `(i >= 2 ? dp[i-2] : 0) + 2` 兜底。

**子情况 1b：`s[i-1] == ')'`，即结尾形如 `……))`。**

这最绕。`s[i]` 是右括号，但前一个 `s[i-1]` 也是右括号，它俩没法直接配。要给 `s[i]` 找配对的 `(`，必须**跳过 `s[i-1]` 已经匹配掉的那一大段**，去那段的前一个位置找。

关键推导：`dp[i-1]` 是「以 `i-1` 结尾的最长有效子串长度」，也就是 `s[i-dp[i-1] .. i-1]` 这一整段（长度 `dp[i-1]`）已经是一坨闭合好的有效括号。要想让 `s[i]` 也能闭合，它的配对 `(` 必须在这坨**之前**，即下标 `i - dp[i-1] - 1` 处。

```
位置:  ...  i-dp[i-1]-1  |  i-dp[i-1]  ...  i-1  |  i
字符:  ...      ?        |   <— dp[i-1] 长的有效段 —>  )
```

- 若 `s[i - dp[i-1] - 1] == '('`：配对成功！`s[i]` 和这个 `(` 把中间那一整坨有效段 `s[i-dp[i-1] .. i-1]` 「包」了起来。于是：

  ```
  dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]
  ```

  三部分：
  - `dp[i-1]`：被包在中间的有效段长度；
  - `2`：新配上的那一对 `(...)`；
  - `dp[i - dp[i-1] - 2]`：这对括号**前面**那一段如果也有效，就连起来（和子情况 1a 加 `dp[i-2]` 同理，只是这里下标变成了 `i - dp[i-1] - 2`）。

- 若 `s[i - dp[i-1] - 1] == ')'` 或该位置越界（不存在）：配对失败，`s[i]` 没法闭合，`dp[i] = 0`，保持默认。

代码里下标越界保护写成 `i - dp[i-1] > 0`（等价于 `i - dp[i-1] - 1 >= 0`，保证 `s[i - dp[i-1] - 1]` 合法且 `dp[i - dp[i-1] - 2]` 那一项也能取到值或用 0 兜底）。

### 手动推导 `s = "(()"`（应为 2）

下标 0,1,2；`dp` 初始全 0。

```
i=0  s[0]='('  → 情况0：dp[0]=0
i=1  s[1]='('  → 情况0：dp[1]=0
i=2  s[2]=')'  → 情况1。s[1]='(' → 子情况1a：
                dp[2] = (i>=2? dp[0] : 0) + 2 = dp[0]+2 = 0+2 = 2
maxans = max(0, 2) = 2 ✓   （有效子串是 s[1..2]="()"）
```

注意 `s[0]='('` 没配对上，所以总长不是 3。答案取 `dp` 最大值 2，不是 `dp[2]` 凑巧也是 2。

### 手动推导 `s = ")()())"`（应为 4）

下标 0~5；`dp` 初始全 0。

```
i=0  s[0]=')'  → 情况1。s[-1]不存在（i=0，循环从 i=1 开始，其实不会处理 i=0）
i=1  s[1]='('  → 情况0：dp[1]=0
i=2  s[2]=')'  → 情况1。s[1]='(' → 子情况1a：
                dp[2] = dp[0]+2 = 0+2 = 2
i=3  s[3]='('  → 情况0：dp[3]=0
i=4  s[4]=')'  → 情况1。s[3]='(' → 子情况1a：
                dp[4] = dp[2]+2 = 2+2 = 4      ← 前面 dp[2]=2 连上了
i=5  s[5]=')'  → 情况1。s[4]=')' → 子情况1b：
                跳过 dp[4]=4 长的有效段，看 s[i-dp[4]-1] = s[5-4-1] = s[0] = ')'
                不是 '('，配对失败 → dp[5]=0
maxans = max over dp = 4 ✓   （有效子串是 s[1..4]="()()"）
```

`i=5` 这个 `)` 想配对，跳过中间 `()()` 4 个字符后落在 `s[0]=')'`，是右括号配不上，所以 `dp[5]=0`——这正体现了「连续」：从 `s[1]` 开始的那段有效括号被 `s[0]` 这个孤立的 `)` 阻断，没法再往左延伸。

## 代码

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.size();
        // ans：记录遍历过程中的最长有效长度，对应官方代码里的 maxans。
        //   - 最终答案不是 dp[n-1]（最长子串不一定以末尾结尾），而是整个 dp 数组的最大值。
        //   - 所以每次更新 dp[i] 后立刻 ans = max(ans, dp[i])。
        int ans = 0;

        // vector<int> dp(n, 0)：构造长度为 n、元素全为 0 的动态数组。
        //   - dp[i] 含义：以下标 i 结尾的最长有效括号子串长度。
        //   - 全初始化 0：s[i]=='(' 时 dp[i] 必为 0（以 '(' 结尾不可能有效），默认值正好；
        //     只有 s[i]==')' 才可能改成正值，所以循环里只处理 ')'。
        //   - 访问 dp[i] 是 O(1)；整体占 O(n) 空间。
        //   - 特例：n==0 时 vector 长度为 0，下面的 for 循环不执行，直接返回 ans=0，无需特判。
        vector<int> dp(n, 0);

        // for 从 i=1 开始：i=0 单个字符不可能构成有效括号，dp[0] 必为 0，跳过。
        //   - 注意是 i < n（下标 0~n-1）。
        for (int i = 1; i < n; i++) {
            // 只处理 s[i]==')'；s[i]=='(' 时 dp[i] 保持 0（见 dp 初始化注释）。
            if (s[i] == ')') {

                // ===== 子情况 1a：s[i-1]=='('，结尾形如 ……() =====
                // s[i-1] 和 s[i] 直接凑成 "()"，贡献长度 2，
                // 再接上它前面以 i-2 结尾的有效段 dp[i-2]。
                if (s[i - 1] == '(') {
                    // 边界 i>=2：i==1 时没有 i-2（"()" 正好在开头，前面没东西），用 0 兜底。
                    //   - 三目 (i >= 2 ? dp[i - 2] : 0) + 2：下标合法才取 dp[i-2]，否则按 0 算。
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                }

                // ===== 子情况 1b：s[i-1]==')'，结尾形如 ……)) =====
                // s[i] 想配对的 '(' 必须跳过「以 i-1 结尾的那段有效括号」（长度 dp[i-1]），
                // 落在下标 i-dp[i-1]-1 处。若那里是 '('，配对成功。
                else if (i - dp[i - 1] > 0 && s[i - dp[i - 1] - 1] == '(') {
                    // 条件 i - dp[i-1] > 0 保证：
                    //   (1) s[i - dp[i-1] - 1] 不越界（等价于 i-dp[i-1]-1 >= 0）；
                    //   (2) 下面 dp[i - dp[i-1] - 2] 里的下标 i-dp[i-1]-2 >= -1，
                    //       配合三目 (i-dp[i-1])>=2 ? ... : 0 安全兜底。
                    //   - 为什么不是 >= 0 而是 > 0？因为这里要看的是「配对 '(' 的前一个位置」i-dp[i-1]-2，
                    //     若它为 -1 表示 '(' 在最开头、前面没东西，那项就按 0 算。
                    //
                    // 转移：dp[i] = dp[i-1]（被包在中间的有效段）
                    //              + 2（新配上的那一对括号）
                    //              + dp[i-dp[i-1]-2]（那对括号前面若也有效就连起来）
                    dp[i] = dp[i - 1] + ((i - dp[i - 1]) >= 2 ? dp[i - dp[i - 1] - 2] : 0) + 2;
                }
                // 注：若上面两条件都不满足，dp[i] 保持默认 0（s[i] 配不上对）。

                // 滚动更新答案：dp 数组的最大值就是结果。
                //   - max(a, b)：<algorithm> 的函数，返回较大者，O(1)。
                ans = max(ans, dp[i]);
            }
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n)，其中 n 是字符串 `s` 的长度。
  - 只遍历字符串一次，每个位置 `i` 做常数次判断和赋值（O(1)），共 O(n)。与官方题解一致。
- **空间**：O(n)
  - 开了一个长度为 n 的 `dp` 数组。（「复盘」里的栈法和两次扫描法能把空间压到 O(n)/O(1)。）

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：`dp[i-1]` 在子情况 1b 里到底是什么？为什么要「跳过」它？

`dp[i-1]` 是「以 `i-1` 结尾的最长有效子串长度」，也就是说 `s[i-dp[i-1] .. i-1]` 这一整段（共 `dp[i-1]` 个字符）已经是一坨**完全闭合**的有效括号。

`s[i]` 是个右括号，想给它找个配对的 `(`。但紧挨着它的 `s[i-1]` 是 `)`（子情况 1b 的前提），而且 `s[i-1]` 自己已经被它前面那段有效结构「消化」掉了。所以 `s[i]` 的配对 `(` 不可能在 `s[i-dp[i-1] .. i-1]` 这段里面（那段都是已配好的），必须去这段的**前一个位置** `s[i - dp[i-1] - 1]` 找。这就是「跳过 `dp[i-1]`」的来历——跳过的是「已经被 `s[i-1]` 占用的那坨有效括号」。

### Q2：为什么是 `i - dp[i-1] - 1` 这个下标？怎么推出来的？

从右往左数：当前位置 `i`，往前数「以 `i-1` 结尾的有效段」有 `dp[i-1]` 个字符，那么这段的左端点（含）是 `i - dp[i-1]`，它的**前一个**位置就是 `i - dp[i-1] - 1`。`s[i]` 的配对 `(` 只能在「这段的前一个」——再往左就更远，配 `s[i]` 就不连续了；在这段里面则和「已闭合」矛盾。

形象想：`... ( <— 这里是 i-dp[i-1]-1  [一坨 dp[i-1] 长的有效括号，结尾是 i-1] —> )  <- 这是 i`。只要那个 `( ` 存在，`(...)` 就把中间整坨包住了。

### Q3：为什么 `s[i] == '('` 时 `dp[i]` 一定是 0？

有效括号子串**一定以 `)` 结尾**——因为有效子串里左右括号成对，最后一个未闭合的必须是右括号才能「闭合」整个串。以 `(` 结尾意味着这个 `(` 还没等到它的 `)`，谈不上有效。所以 `s[i] == '('` 直接 `dp[i] = 0`，代码里干脆不进 `if`，保持初始默认值。

### Q4：怎么保证算出来的一定是「连续」子串？

`dp[i]` 的定义本身就绑死了「**以下标 i 结尾**」。转移时无论子情况 1a 还是 1b，都是在「以 `i-2` 或 `i-dp[i-1]-2` 结尾的有效段」**末尾紧接着**追加新的成对括号——下标是连续相邻的，没有跳跃拼接。只要某处断开（比如遇到配不上的 `)`），那个位置的 `dp[i]` 直接归 0，新的连续段从 0 重新开始累计。所以每个 `dp[i]` 对应的都是一段连续子串的长度，取 max 自然得到最长连续有效子串。

### Q5：边界 `i - dp[i-1] > 0` 为什么用严格大于，不是 `>= 0`？

这个条件管两件事：保证 `s[i-dp[i-1]-1]` 不越界（下标 ≥ 0），同时让后面 `dp[i-dp[i-1]-2]` 那一项也能安全处理。

- `i - dp[i-1] > 0` 等价于 `i - dp[i-1] - 1 >= 0`，即配对位置 `(` 下标合法。
- 若写成 `>= 0`，则 `i - dp[i-1] - 1 == -1` 时会越界访问 `s[-1]`，是未定义行为。
- 至于 `dp[i-dp[i-1]-2]` 这一项：当 `i - dp[i-1] - 2 == -1`（配对 `(` 在最开头 s[0]，前面没东西），代码里的三目 `(i-dp[i-1]) >= 2 ? ... : 0` 会走 `:0` 分支兜底，所以 `-1` 这种情况被三目接住了，不会真的去取 `dp[-1]`。

## 复盘

### 可迁移套路：「以 i 结尾的 DP + 跳过已匹配区间」

本题是**子串/子数组类 DP** 的一个范本，套路可迁移：

1. **状态按「以 i 结尾」定义**：凡问「最长连续子串/子数组」，第一反应是 `dp[i] = 以 i 结尾的最优值`，最后答案取 `max(dp)`。这比按「前 i 个」定义更贴合「连续」语义。类似的题有最大子数组和（53）、乘积最大子数组（152）。
2. **转移时「跳过已确定的子结构」**：子情况 1b 最核心的思想是——遇到嵌套/包裹结构时，用 `dp[i-1]` 把「已经处理好的内层」整段跳过去，直接定位到外层的配对点。这种「用 DP 值回推下标」的技巧在括号、字符串匹配题里反复出现，值得记牢。

### 栈法对比（官方方法二，写法更短）

DP 法虽然思路直，但转移方程要分情况、下标绕。栈法要短得多，思路是「栈里存**下标**，维护一个待匹配的左括号下标栈」：

- 栈底始终放一个「最后一个没配上的右括号下标」作为分隔符（初始 `-1`）。
- 遇 `(` 压入其下标；遇 `)` 先弹栈，若栈空了说明这个 `)` 没配上、把它作为新分隔符压入；若栈非空，则当前有效长度 = `i - stk.top()`。

官方代码（备查，详细注释略）：

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int maxans = 0;
        stack<int> stk;
        stk.push(-1);                       // 栈底分隔符：最后一个未匹配的右括号下标
        for (int i = 0; i < s.length(); i++) {
            if (s[i] == '(') {
                stk.push(i);                // 左括号：压入下标待配
            } else {
                stk.pop();                  // 右括号：弹掉栈顶（配对或弹出分隔符）
                if (stk.empty()) {
                    stk.push(i);            // 栈空 = 这个 ) 没配上，它成为新分隔符
                } else {
                    maxans = max(maxans, i - stk.top());  // 有效长度 = 当前位置 - 新栈顶
                }
            }
        }
        return maxans;
    }
};
```

- 时间 O(n)，空间 O(n)。和 DP 同复杂度，但**无需分情况推下标**，更不容易写错。
- 诀窍：栈里存**下标**而非字符，这样弹栈后能用 `i - stk.top()` 直接算出连续长度。

### 两次扫描法（官方方法三，O(1) 空间）

正向扫一遍记 `left/right` 计数，`left==right` 时更新答案，`right>left` 时清零；再反向扫一遍（处理 `(()` 这种左括号多的情况）。空间 O(1)，但需要两次遍历，且「为什么正向扫不够、要反向再扫一遍」这点比较反直觉——适合作为「极致优化」了解，不做主推。

### 三法横向对比

| 解法 | 时间 | 空间 | 思路难度 | 备注 |
|---|---|---|---|---|
| 动态规划（主解） | O(n) | O(n) | 中（下标绕） | 与目录主题对应，状态定义清晰 |
| 栈 | O(n) | O(n) | 低 | 写法最短，不易错，实战首选 |
| 两次扫描 | O(n) | O(1) | 中（要懂为何扫两遍） | 空间最优 |
