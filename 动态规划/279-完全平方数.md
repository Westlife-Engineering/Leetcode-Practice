# 279 完全平方数

- 难度：中等
- 标签：广度优先搜索、数学、**动态规划**
- 力扣链接：https://leetcode.cn/problems/perfect-squares/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[完全平方数](https://leetcode.cn/problems/perfect-squares/solution/wan-quan-ping-fang-shu-by-leetcode-solut-t99c/)」。正文主解是 **动态规划**，O(n√n) 时间 O(n) 空间——本质是把「完全平方数」当成可用无限次的「物品」，求凑成和 `n` 的**最少件数**，可看作 **完全背包求最少个数** 的变体。官方的**数学定理法**（基于拉格朗日四平方和定理，O(√n)）和 **BFS** 放在「复盘」作拓展。

## 题目描述

给你一个整数 `n` ，返回和为 `n` 的完全平方数的**最少数量**。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是**完全平方数**，而 `3` 和 `11` 不是。

**示例 1：**

```
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4 = 2² + 2² + 2²
```

**示例 2：**

```
输入：n = 13
输出：2
解释：13 = 4 + 9 = 2² + 3²
```

**提示：**

- `1 <= n <= 10^4`

> 一句话理解题意：「**完全平方数**」就是 `1, 4, 9, 16, 25 ...`（即 `1², 2², 3², 4², 5² ...`）。同一个完全平方数可以**重复使用**（如 `12 = 4+4+4` 用了 3 次 `4`）。问：**最少挑几个**这样的数相加等于 `n`。

## 思路

> 本题主要参考力扣官方题解「方法一：动态规划」。

要求的是「最少个数」——是求**最值**，不是求方案数。`n` 最大到 10^4，组合方案数爆炸，没法枚举每一种凑法。得找**递推关系**：能不能用「凑出更小的和」所需的最少个数，推出「凑出更大的和」的最少个数？

### DP 三要素（所有 DP 题的通用思考框架）

#### ① 状态定义：`dp[i]` = 和为 `i` 的完全平方数的最少个数

把「问题」用一个数组描述出来。这里「凑出和 `i` 至少要几个完全平方数」就是最自然的状态——`dp[n]` 就是答案。

> 为什么这么定义？因为「凑出和 `i`」是一个**子问题**，原问题「凑出和 `n`」就是 `i=n` 的特例。DP 的本质就是把大问题拆成结构相同的小问题。

#### ② 状态转移方程：`dp[i] = min(dp[i], dp[i - j*j] + 1)`（核心！）

**盯着「最后挑的那一个数」看**：凑出 `i` 的方案里，最后一个挑的完全平方数，必然是 `1, 4, 9, 16 ...` 中的某一个（因为只用完全平方数凑）。假设最后一个挑的是 `j*j`（`j` 是正整数），那么：

1. 这一个数贡献了 `1` 个（`+1` 的来源）；
2. 剩下的部分要凑出 `i - j*j`，而这恰好就是子问题 `dp[i - j*j]`！

由于我们不知道最后一个到底该挑哪个 `j*j` 才能让总数最少，所以**枚举所有可能的 `j`**（只要 `j*j <= i`），对每个 `j` 算出 `dp[i - j*j] + 1`，取它们之中的**最小值**：

```
dp[i] = min_{j: j*j <= i} ( dp[i - j*j] + 1 )
```

一句话总结：**「凑出和 `i` 的最少个数 =（最后一个挑的完全平方数是 `j*j`）时，凑出 `i-j*j` 的最少个数 + 1」，对所有合法的 `j` 取最小。** 这里的 `+1` 就是「最后挑的那个 `j*j` 占了 1 个名额」。

> **为什么 `j*j <= i`？** 因为最后一个数 `j*j` 必须「装得下」：它的值不能超过要凑的目标 `i`。比如凑 `i=12`，可以挑 `j=1`(1)、`j=2`(4)、`j=3`(9)，因为 `1,4,9 <= 12`；但 `j=4`(16) 就不行，`16 > 12` 没法用。所以内层循环条件是 `j*j <= i`。

#### ③ 初始条件：`dp[0] = 0`，其余 `dp[i] = INF`

转移方程要查 `dp[i - j*j]`，当 `i` 本身就是个完全平方数时（比如 `i=4`，挑 `j=2`），`i - j*j = 0`，所以要给 `dp[0]` 一个合理的值：

- `dp[0] = 0`：凑出和为 `0` 需要 `0` 个完全平方数（什么都不挑）。这是递推的「地基」——当 `i` 恰好等于某个 `j*j` 时，`dp[i] = dp[0] + 1 = 0 + 1 = 1`，即「自己一个完全平方数就够」，逻辑正确。
- 其余 `dp[i]` 初始化为一个**大数**（如 `INT_MAX`）：表示「还没算过、目前认为是无穷大」。这样后面 `min` 取较小值时，第一次比较就能把真实答案写进去。

> **为什么 `dp[0]` 一定要是 `0` 而不是别的？** 因为 `+1` 的语义是「多挑一个数」。凑出 `0` 本来就不需要挑任何数，所以基础值必须是 `0`，这样从 `dp[0]` 加 `1` 得到的 `dp[j*j] = 1` 才表示「挑一个 `j*j` 就凑出了 `j*j`」。如果 `dp[0]` 写成 `1` 或别的，所有答案都会系统性偏大。

### 手动推导 n = 12 和 n = 13

**n = 12**（答案 3，凑法 `4+4+4`）：

```
dp[0] = 0                              ← 初始
dp[1] = dp[1-1*1]+1     = dp[0]+1 = 1  ← 只能挑 1 (1²=1)
dp[2] = dp[2-1*1]+1     = dp[1]+1 = 2  ← 只能挑 1 (4>2, 9>2)
dp[3] = dp[3-1*1]+1     = dp[2]+1 = 3  ← 只能挑 1
dp[4] = min(dp[4-1]+1,  dp[4-4]+1)
      = min(dp[3]+1=4,   dp[0]+1=1) = 1   ← 挑 4 (=2²) 最优，1 个
dp[5] = min(dp[4]+1=2,  dp[1]+1=2) = 2   ← 4+1 或 1+1+1+1+1
...
dp[8] = min(dp[7]+1=4,  dp[4]+1=2) = 2   ← 4+4，2 个
dp[12]= min(dp[11]+1,   dp[8]+1=3,  dp[3]+1=4) = 3   ← 4+4+4，3 个
```

结果 `dp[12] = 3` ✓（对应 `12 = 4+4+4`，挑了 3 个 `2²`）。

**n = 13**（答案 2，凑法 `4+9`）：

```
dp[9] = min(dp[8]+1, dp[5]+1, dp[0]+1) = 1   ← 挑 9 (=3²) 最优，1 个
dp[13]= min(dp[12]+1=4,  dp[9]+1=2,  dp[4]+1=2) = 2   ← 9+4 或 4+9，2 个
```

结果 `dp[13] = 2` ✓（对应 `13 = 4+9`，挑了 `2²` 和 `3²` 各一个）。

### 和「322 零钱兑换」的关系（重要类比）

本题和 [322 零钱兑换](https://leetcode.cn/problems/coin-change/) 是**一对孪生题**，转移方程几乎一模一样：

| | 322 零钱兑换 | 279 完全平方数 |
|---|---|---|
| 「物品」 | 各种面值的硬币 | 各种完全平方数 `1,4,9,16...` |
| 物品列表 | 题目给的 `coins` 数组 | 自动生成 `j*j`（`j=1,2,3,...`） |
| 目标 | 凑出金额 `amount` | 凑出整数 `n` |
| 求什么 | 最少**硬币数** | 最少**完全平方数个数** |
| 转移方程 | `dp[i] = min(dp[i-c]+1)`，枚举硬币 `c` | `dp[i] = min(dp[i-j*j]+1)`，枚举 `j` |

两者本质都是 **完全背包求最少件数**：「物品」可重复用，「价值」都是 1（每件算 1 个），求凑满目标的最少件数。会做其中一道，另一道就是换个「物品列表」的事。本题甚至更省事——「物品」不用题目给，直接 `j*j` 现场枚举。

## 代码

```cpp
class Solution {
public:
    int numSquares(int n) {
        // vector<int> dp(n+1, INT_MAX)：开一个长度 n+1 的 int 数组，所有元素初始化为 INT_MAX。
        //   - vector 是 C++ 动态数组（顺序容器）；这里下标 0..n 共 n+1 个位置，dp[i] 表示「和为 i 的最少完全平方数个数」。
        //   - 第二个参数 INT_MAX 是「填充值」，把每个元素都填成「无穷大」，代表「还没算出、暂时认为凑不出来」。
        //   - 为什么用 INT_MAX？后面用 min 取较小值，第一次比较 dp[i-j*j]+1 必然 < INT_MAX，就能把真实答案写进去。
        //   - 注意 INT_MAX 需要 <climits>，力扣 C++ 模板默认已包含，不用手动 #include。
        //   - vector<int>(大小, 初值) 这种构造是「批量填充」，时间 O(n)，空间 O(n)。
        vector<int> dp(n + 1, INT_MAX);

        dp[0] = 0;  // ★ 初始条件：凑出和为 0 需要 0 个完全平方数（什么都不挑）。
                    //   这是整个递推的「地基」：当 i 本身就是某个 j*j 时，dp[i] = dp[0]+1 = 1，表示「自己一个就够」。
                    //   其余 dp[1..n] 保持 INT_MAX，等待下面循环填入真实最小值。

        // 外层循环：i 从 1 枚举到 n，依次算出每个 dp[i]。
        //   - 必须从小到大算：因为 dp[i] 要查 dp[i-j*j]，而 i-j*j < i，更小的 i 必须先算好。
        //   - 注意是 i <= n（含 n），循环结束时 dp[n] 就是答案。
        for (int i = 1; i <= n; i++) {

            // 内层循环：枚举「最后挑的那个完全平方数 j*j」。
            //   - j 从 1 开始，j*j 就是 1,4,9,16,... 这些完全平方数（物品）。
            //   - 条件 j*j <= i：物品值不能超过目标和 i（挑的数得「装得下」）。
            //     比如凑 i=5 时 j 只能是 1,2（j*j=1,4），j=3 时 9>5 越界，循环自动停。
            //   - 写成 j*j<=i 而不是 j<=sqrt(i)，避免浮点运算，更快也更安全。
            for (int j = 1; j * j <= i; j++) {

                // ★ 状态转移方程：dp[i] = min(dp[i], dp[i-j*j] + 1)
                //   - dp[i-j*j]：凑出「剩下那部分 i-j*j」所需的最少个数（更小的子问题，已算好）。
                //   - +1：最后挑的这个 j*j 占了 1 个名额。
                //   - min：枚举不同 j，取使得总数最少的那个。
                //   - 注意 i-j*j >= 0 一定成立（因为 j*j<=i），所以 dp[i-j*j] 不会越界访问。
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];  // 凑出和为 n 的最少完全平方数个数
    }
};
```

**用 n=12 走一遍**（每轮外层结束后 `dp[i]` 的值）：

```
dp[0]=0 (初始)
i=1:  j=1(1)  → dp[1]=min(INF, dp[0]+1)=1
i=2:  j=1(1)  → dp[2]=min(INF, dp[1]+1)=2
i=3:  j=1(1)  → dp[3]=min(INF, dp[2]+1)=3
i=4:  j=1(1)→dp[4]=dp[3]+1=4; j=2(4)→dp[4]=min(4, dp[0]+1)=1   → dp[4]=1
i=5:  j=1→dp[5]=dp[4]+1=2;     j=2→dp[5]=min(2, dp[1]+1)=2     → dp[5]=2
...
i=12: j=1→dp[12]=dp[11]+1=4; j=2→dp[12]=min(4, dp[8]+1=3)=3; j=3→dp[12]=min(3, dp[3]+1=4)=3
      → dp[12]=3   ✓  (4+4+4)
返回 3
```

## 复杂度

- **时间**：O(n√n)
  - 外层循环 `n` 次。内层循环次数取决于 `j*j <= i`，即 `j <= √i`，最多约 `√n` 次。
  - 总操作数约为 `∑_{i=1}^{n} √i ≈ n·√n` 量级。`n=10^4` 时约 `10^4 × 100 = 10^6`，远在时限内。
- **空间**：O(n)
  - 开了一个长度 `n+1` 的 `dp` 数组。本题转移只查 `dp[i-j*j]`（`j` 不定，跨度大），没法像爬楼梯那样压缩到 O(1)。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：为什么 `dp[0]` 要初始化为 `0`？

`dp[0]` 表示「凑出和为 0 需要的最少个数」。和为 0 意味着**什么都不挑**，自然就是 0 个。

它是整个递推的**地基**：当 `i` 恰好等于某个完全平方数 `j*j` 时（比如 `i=4`、`j=2`），转移会查 `dp[i-j*j] = dp[0]`，于是 `dp[4] = dp[0]+1 = 0+1 = 1`，含义是「挑一个 `4` 自己就凑出了 4」。如果 `dp[0]` 写成 1 或别的非零值，所有完全平方数位置的答案都会偏大（`dp[4]` 会变成 2），整个递推就全错了。

一句话：**`dp[0]=0` 是「凑 0 不花钱」这个物理事实的直接编码**，不是任意凑的数。

### Q2：内层循环 `j*j <= i` 怎么来的？为什么不是 `j <= i`？

`j` 是「底数」，真正挑进凑法的「物品」是 `j*j`（完全平方数）。约束是「挑的这个数不能比目标和 `i` 还大」——即 `j*j <= i`。

如果写成 `j <= i`，就会让 `j*j` 远超 `i`，此时 `i - j*j` 变成负数，访问 `dp[负数]` 会**数组越界**（未定义行为，可能崩）。所以必须用 `j*j <= i` 把 `j` 限制在 `j <= √i`。

为什么不用 `j <= sqrt(i)`？因为 `sqrt` 是**浮点函数**，有精度风险还慢；`j*j <= i` 全是整数运算，既快又没误差，是力扣上的标准写法。

### Q3：和 322 零钱兑换到底什么关系？为什么解法几乎一样？

两者本质都是 **完全背包求最少件数**：

- 「物品」可重复选（完全背包的「完全」二字来源）；
- 每件物品「价值」都是 1（每挑一个算 1 个）；
- 求凑满目标的「最少件数」（`min`）。

转移方程都是 `dp[i] = min(dp[i-物品]+1)`，枚举所有物品取最小。区别只在「物品列表怎么来」：322 是题目给的 `coins` 数组，279 是现场 `j*j` 生成。**背熟这套「完全背包求最少」模板**，322、279、518（零钱兑换 II 求方案数变体）一类题都是换皮。

### Q4：为什么用 `min`？什么时候 DP 用 `min` 什么时候用 `+`？

看题目**求什么**：

- 求**最值**（最少 / 最多 / 最长 / 最短）→ 用 `min` / `max`。本题求「最少个数」，所以在多种凑法里取最小。322 零钱兑换、64 最小路径和、300 最长递增子序列都是这类。
- 求**方案总数**（有多少种凑法 / 走法）→ 用 `+`（把各类不重叠的情况相加）。70 爬楼梯、518 零钱兑换 II（求方案数）、62 不同路径都是这类。

口诀：**「求最少/最多用 min/max，求数量用 +」**。看到「最少几个」「最多几种」「最长多长」就条件反射想到 `min`/`max`。

## 复盘

- **核心套路**：「**DP 求最少个数 = 完全背包变体**」是一大类题的通用模板。状态定义 `dp[i]` = 凑出目标 `i` 的最少件数，转移 `dp[i] = min(dp[i-w]+1)` 枚举所有物品 `w`，初始 `dp[0]=0` 其余 `INF`。本题的「物品」是 `1,4,9,...` 这些完全平方数，322 零钱兑换的「物品」是硬币面值，两者一模一样。
- **「盯着最后一步」找转移方程**：和爬楼梯「最后一步跨几阶」一脉相承。本题「最后挑的那个完全平方数是 `j*j`」，确定它后剩下来就是子问题 `dp[i-j*j]`。**分析最后一步→归类子问题→相加/取最值**，是推导所有 DP 转移方程的通用招数。
- **`dp[0]` 的语义**：求「凑 0」的答案永远是 0（不挑任何东西），它是所有「凑满」类 DP 的地基。记住「求最少件数 → `dp[0]=0`、其余 `INF`；求方案数 → `dp[0]=1`、其余 0」这套初始化口诀。
- **题目给的「物品列表」不是固定的就自己生成**：322 给了 `coins`，本题没给但能用 `j*j` 现场枚举。看到「完全平方数」「斐波那契数」「幂次」这类有规律的数列当物品，不用等题目给数组，直接 `for` 循环生成即可。

### 解法二：数学定理法（官方方法二，O(√n) 时间）

DP 是 O(n√n)，但本题有个基于数论的 **O(√n)** 解法，思路来自**拉格朗日四平方和定理**：**任何正整数都能表示为至多 4 个完全平方数之和**。所以答案只能是 `1, 2, 3, 4` 中的一个。再结合一个更精细的定理（勒让德三平方定理）可以进一步判定：

- 答案 = 1：`n` 本身就是完全平方数。
- 答案 = 4：`n` 能写成 `4^k × (8m+7)` 的形式（此时必定需要 4 个）。
- 答案 = 2：`n = a² + b²`（枚举 `a`，看 `n-a²` 是不是完全平方数）。
- 其余情况答案 = 3。

```cpp
class Solution {
public:
    // 判断 x 是否为完全平方数：取平方根 y=floor(sqrt(x))，看 y*y 是否还原回 x
    bool isPerfectSquare(int x) {
        int y = sqrt(x);          // sqrt 返回 double，赋给 int 自动向下取整
        return y * y == x;
    }

    // 判断 x 是否能写成 4^k*(8m+7)：不断除掉因子 4，看剩下的是否模 8 余 7
    bool checkAnswer4(int x) {
        while (x % 4 == 0) {      // 把 x 里的 4^k 因子全部除干净
            x /= 4;
        }
        return x % 8 == 7;        // 剩下的部分模 8 余 7 → 答案是 4
    }

    int numSquares(int n) {
        if (isPerfectSquare(n)) return 1;          // n 自己就是平方数 → 1 个
        if (checkAnswer4(n))   return 4;          // 形如 4^k*(8m+7) → 必须 4 个
        for (int i = 1; i * i <= n; i++) {         // 否则枚举：看能否拆成两平方数之和
            int j = n - i * i;
            if (isPerfectSquare(j)) return 2;      // n = i² + j² → 2 个
        }
        return 3;                                  // 剩下的情况 → 3 个
    }
};
```

- **时间**：O(√n)——枚举 `i` 最多到 `√n`，每次判断完全平方数 O(1)。
- **空间**：O(1)。
- **何时用**：追求极致性能或面试官明确要求数学解法时。缺点是要背定理、可读性差，DP 仍是首推的「通用解」。

### 解法三：BFS（把问题看成最短路径，O(n√n)）

把「凑出 `n`」看成图上找最短路：起点是 `0`，每次从当前和 `cur` 出发，加任意一个完全平方数 `j*j` 走一步，目标是到达 `n`，**问最少走几步**。BFS 天然求无权图最短路，第一次到达 `n` 的层数就是答案。

```cpp
class Solution {
public:
    int numSquares(int n) {
        queue<int> q;              // BFS 队列，存「当前凑出的和」
        vector<int> dist(n + 1, -1); // dist[i]=-1 表示和 i 还没访问过
        q.push(0);                 // 从 0 出发
        dist[0] = 0;
        while (!q.empty()) {
            int cur = q.front(); q.pop();
            if (cur == n) return dist[cur];   // 第一次到 n 就是最少步数
            for (int j = 1; cur + j * j <= n; j++) {  // 枚举下一步加哪个完全平方数
                int nxt = cur + j * j;
                if (dist[nxt] == -1) {         // 没访问过才入队（避免重复）
                    dist[nxt] = dist[cur] + 1;
                    q.push(nxt);
                }
            }
        }
        return n;  // 最坏情况全用 1，返回 n（实际到不了这）
    }
};
```

- **时间**：O(n√n)——每个和最多入队一次，每次展开最多 `√n` 个后继。
- **空间**：O(n)——`dist` 数组 + 队列。
- **对比**：和 DP 同量级，但思路更直观（「凑数 = 走图」）。BFS 的「第一次到达即最优」性质来自 BFS 的层序遍历——这点和「最小基因变化」「单词接龙」一类题完全一致，可迁移。
