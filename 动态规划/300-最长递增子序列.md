# 300 最长递增子序列

- 难度：中等
- 标签：数组、二分查找、**动态规划**
- 力扣链接：https://leetcode.cn/problems/longest-increasing-subsequence/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/solution/zui-chang-shang-sheng-zi-xu-lie-by-leetcode-soluti/)」。正文主解是 **动态规划（O(n²)）**——状态定义为「以 `nums[i]` 结尾的最长递增子序列长度」，转移时枚举所有可能的「前驱」`j`。这是最基础、最直观的子序列 DP 写法，和目录主题最对应。官方同一篇文章里还给了更优的 **贪心 + 二分查找（O(n log n)）**，放在「复盘」作对比。

## 题目描述

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

**示例 1：**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

**示例 2：**

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示：**

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

**进阶：** 你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

## 思路

> 本题主要参考力扣官方题解「方法一：动态规划」。

### 先把概念弄清：子序列 vs 子数组（本题最容易混的点）

这题叫「最长递增子序列」，关键词是**子序列**。它和 53 题那种「子数组」本质不同：

- **子数组（subarray）**：元素**必须连续**挨着，是数组里「一段」。如 `[10,9,2,5]` 是 `nums` 的子数组（下标 0~3 连着取）。
- **子序列（subsequence）**：元素**可以跳着选**，只要求**相对顺序不变**，不要求相邻。如 `[2,5,7,101]` 是 `nums=[10,9,2,5,3,7,101,18]` 的子序列（跳过了 `10,9,3,18`，但保留的 `2→5→7→101` 在原数组里的先后顺序没变）。

这个区别直接决定了 DP 的写法：
- 53 题（子数组）状态 `f(i)` 只用看 `f(i-1)`（前一段连不连），转移是 O(1)；
- 本题（子序列）状态 `dp[i]` 要**枚举所有 j < i 作为「前驱」**（`nums[j]` 可能是子序列里紧挨着 `nums[i]` 的前一个元素，但中间隔了多少个不重要），转移是 O(n)。

所以本题朴素 DP 是 **O(n²)**，比 53 题的 O(n) 慢一个量级——这是「子序列 vs 子数组」带来的固有代价。

### DP 三要素

#### ① 状态定义：`dp[i]` = 以 `nums[i]` 结尾的最长**严格递增**子序列的长度

两个关键限定，缺一不可：

1. **「以 `nums[i]` 结尾」**：这个子序列**必须包含 `nums[i]`**，且 `nums[i]` 是最后一个元素。这是状态能正确转移的前提（否则转移时无法判断「能不能接上」）。
2. **「严格递增」**：子序列里相邻两个元素必须满足前一个 < 后一个（不是 ≤）。所以示例 3 全是 `7` 时，答案只有 1（任何两个 7 都不严格递增）。

> **为什么按「以 `nums[i]` 结尾」定义，而不是「前 i 个元素里的最长递增子序列」？**
>
> 因为递增关系是看**尾巴**的——判断 `nums[i]` 能不能接在某个子序列后面，只看那个子序列的最后一个元素是不是 `< nums[i]`，前面的元素无所谓。把「结尾是谁」编码进状态，转移时才有判断依据。如果定义成「前 i 个里的最长长度」，就没法表达「结尾是几」，转移无从下手。
>
> 最终答案是 `max(dp[i])`（所有位置里最长的那个），不是 `dp[n-1]`——因为最长子序列不一定以最后一个元素结尾。

#### ② 状态转移：`dp[i] = max(dp[j] + 1)`，对所有 `j < i` 且 `nums[j] < nums[i]`

这是全题核心。盯着 `nums[i]` 这个「尾巴」看：它的前一个元素 `nums[j]`（`j < i`）可以是任何一个比它小的元素。每选一个合法的 `j`，就把 `nums[i]` 接在「以 `nums[j]` 结尾的最长子序列」后面，长度 +1：

```
dp[i] = max(dp[j] + 1)    对所有 j < i 且 nums[j] < nums[i]
```

如果**没有**任何 `j < i` 满足 `nums[j] < nums[i]`（即 `nums[i]` 前面没有比它小的元素），那 `nums[i]` 只能自己开一个子序列，长度 = 1。这就是为什么 `dp` 全部初始化为 1。

一句话总结：**「`nums[i]` 可以接在任何一个比它小且位置靠前的子序列后面，挑最长的那个接，再加 1」**。

#### ③ 初始条件：`dp[i] = 1`（对所有 i）

每个元素自身就是一个长度为 1 的子序列。这一条是转移方程的**兜底**——就算 `nums[i]` 前面没有任何比它小的元素，`dp[i]` 至少是 1，不会是 0（更不会是垃圾值）。

### 手动推导示例 1

`nums = [10,9,2,5,3,7,101,18]`（下标 0~7）。逐个算 `dp[i]`：

```
i=0  x=10   前面没有 j       dp[0]=1                     ans=1
i=1  x= 9   前面没有比9小的   dp[1]=1                     ans=1
i=2  x= 2   前面没有比2小的   dp[2]=1                     ans=1
i=3  x= 5   j=2(nums[2]=2<5) dp[3]=dp[2]+1=2             ans=2   ← [2,5]
i=4  x= 3   j=2(nums[2]=2<3) dp[4]=dp[2]+1=2             ans=2   ← [2,3]（j=3 的 5 不<3，跳过）
i=5  x= 7   j=2,3,4 都<7
             取最大 dp[j]: dp[3]=2 → dp[5]=dp[3]+1=3      ans=3   ← [2,5,7] 或 [2,3,7]
i=6  x=101  j=0~5 全 <101
             取最大 dp[j]: dp[5]=3 → dp[6]=dp[5]+1=4      ans=4   ← [2,5,7,101]
i=7  x= 18  j=0~5 都<18（j=6 的101不<18，跳过）
             取最大 dp[j]: dp[5]=3 → dp[7]=dp[5]+1=4      ans=4   ← [2,5,7,18]
返回 max(dp) = 4 ✓   （对应 [2,3,7,101] 或 [2,5,7,101] 等）
```

可以看到 `dp` 数组最终是 `[1,1,1,2,2,3,4,4]`，最大值 4 就是答案。

## 代码

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();

        // vector<int> dp(n, 1)：构造长度为 n、每个元素初始化为 1 的动态数组。
        //   - 签名 vector<类型>(元素个数, 初始值)。
        //   - 为什么初始化为 1？因为「每个元素自身就是一个长度为 1 的递增子序列」。
        //     这是转移方程的兜底：即便 nums[i] 前面没有任何比它小的元素，
        //     dp[i] 也至少是 1（不会是 0 或垃圾值）。
        //   - 访问 dp[i] 是 O(1)；整体占用 O(n) 空间。
        //   - 注意：官方代码写成 vector<int> dp(n,0) 然后循环里再 dp[i]=1，效果完全等价，
        //     这里直接用 1 初始化更简洁，少写一行。
        vector<int> dp(n, 1);

        // ans：全局答案 = 所有 dp[i] 的最大值。
        //   - 初始化为 0 没问题，因为每个 dp[i] >= 1，max 一定能被覆盖。
        //   - （对比 53 题「最大子数组和」时 ans 必须用 nums[0] 兜底，因为那里答案可能为负；
        //     本题求的是「长度」，恒为正整数，0 是安全的初值。）
        int ans = 0;

        // 外层：枚举每个 i 作为子序列的「结尾」。
        for (int i = 0; i < n; i++) {
            // 内层：枚举所有 j < i 作为 nums[i] 的「前驱」。
            //   - 只有 nums[j] < nums[i] 时，nums[i] 才能接在「以 nums[j] 结尾的子序列」后面，
            //     形成更长的严格递增子序列，长度 = dp[j] + 1。
            //   - 注意是「严格小于 <」，不是 <=：题目要求「严格递增」，相等的元素不能算。
            //     所以示例 3 全是 7 时，所有 nums[j] < nums[i] 都不成立，dp 全为 1，答案 1。
            //   - 这层循环是 O(n)，外层也是 O(n)，所以总时间 O(n²)。
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    // max(a, b)：<algorithm> 里的函数，返回 a、b 中较大者，O(1)。
                    //   - dp[i] 可能在多个合法 j 里被反复更新，每次取较大值，
                    //     等价于「在所有合法前驱里挑最长的 dp[j]，再加 1」。
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            // 用当前 dp[i] 更新全局最大值。
            //   - 最长子序列不一定以最后一个元素结尾（可能中间某个 i 的 dp[i] 最大），
            //     所以不能只 return dp[n-1]，要在循环里持续刷新 ans。
            ans = max(ans, dp[i]);
        }

        return ans;
    }
};
```

## 复杂度

- **时间**：O(n²)
  - 外层循环 n 次，内层循环平均 n/2 次（`j` 从 0 到 `i-1`），总体 n × (n/2) = O(n²)。
  - 数据范围 n ≤ 2500，n² ≈ 6.25 × 10^6，C++ 里轻松通过（力扣时间限制够用）。
- **空间**：O(n)
  - 开了一个长度为 n 的 `dp` 数组。`ans`、`i`、`j` 都是 O(1) 额外变量。
  - 不能像 53 题那样滚动压缩——因为 `dp[i]` 依赖**所有** `dp[j] (j < i)`，不是只依赖前一项，无法用一个变量滚动。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：子序列和子数组到底差在哪？为什么这题是 O(n²)、53 题是 O(n)？

**差在「元素能不能跳着选」**，这直接决定了状态转移要看几个前驱。

- **子数组（53 题）**：元素**连续**。`nums[i]` 要么接在前一段（`f(i-1)`）后面，要么自己起一段——只有这两种选择，转移 `f(i)=max(f(i-1)+x, x)` 是 O(1)，整体 O(n)。
- **子序列（本题）**：元素**不连续**。`nums[i]` 前面的**任何** `j < i`（只要 `nums[j] < nums[i]`）都可能是它的「前驱」，所以必须把所有 `j` 都试一遍取最大，转移是 O(n)，整体 O(n²)。

记忆口诀：**「子数组看 1 个前驱，子序列看所有前驱」**——前者 O(n)，后者 O(n²)，这就是连续 vs 离散的代价。

### Q2：`dp[i]` 为什么初始化成 1，而不是 0？

因为**每个元素自身就是一个长度为 1 的递增子序列**（单个元素天然递增）。`dp[i]` 表示「以 `nums[i]` 结尾的最长子序列长度」，这个子序列至少包含 `nums[i]` 自己，所以最小值是 1，绝不可能是 0。

如果初始化成 0，会发生什么？当 `nums[i]` 前面**没有**任何 `nums[j] < nums[i]` 时（比如它是前缀最小值），内层循环一次都不进 `if`，`dp[i]` 保持 0——这显然错了（应该是 1）。所以必须用 1 兜底。

官方代码的写法是 `vector<int> dp(n, 0)` 然后**循环里第一行 `dp[i] = 1;`**，等价于我们这里直接 `dp(n, 1)`，更简洁。

### Q3：为什么状态要按「以 `nums[i]` 结尾」定义？不能定义成「前 i 个元素里的最长递增子序列」吗？

**不能**，那样转移写不出来。原因是：判断 `nums[i]` 能不能接在某个子序列后面，**只看那个子序列的最后一个元素**是不是 `< nums[i]`。如果状态里不编码「结尾是谁」，转移时就不知道「这个子序列的尾巴是几」，没法判断能不能接上。

按「以 `nums[i]` 结尾」定义，就把「尾巴是 `nums[i]`」固化进了状态，转移时 `nums[i]` 能不能接在 `dp[j]` 后面，只需比较 `nums[j] < nums[i]`（`dp[j]` 的尾巴一定是 `nums[j]`），一目了然。

这种「**按结尾定义状态**」是子序列 DP 的通用套路，下面「复盘」会展开。

### Q4：能不能用「滑动窗口」做？

**不能**。滑动窗口要求窗口满足某种「**单调性**」（如窗口扩大时某个量单调增），才能用双指针 O(n) 伸缩。本题要找的是「严格递增」子序列，元素大小是任意的（有正有负、忽大忽小），扩大窗口不保证「递增」性质，没有任何单调性可利用，滑动窗口失效。

本题的正解是**动态规划**（O(n²)）或**贪心 + 二分**（O(n log n)，见复盘），都不属于滑动窗口那一类。

## 复盘

- **核心套路**：「**子序列 DP：按结尾定义状态 + 枚举所有前驱**」是本题的可迁移框架。看到「最长 / 最短 / 计数子序列」类问题，第一步就想：状态能不能定义成「以 `nums[i]` 结尾的 ...」，然后枚举所有 `j < i` 看能不能从 `dp[j]` 转移过来。这个框架覆盖了 300（最长递增子序列）、1143（最长公共子序列）、53 的「子数组版」（把枚举前驱退化成只看前一项）等一大类题。
- **子序列 vs 子数组的本质区别**：子数组转移 O(1)（只看前一项，保证连续），子序列转移 O(n)（要看所有前驱，允许跳跃）。看到「子序列」就要有 O(n²) 的心理预期，再用二分优化到 O(n log n)。
- **按结尾定义的妙处**：把「递增/匹配」这种**看尾巴**的约束编码进状态，转移时只需比较两个元素的大小/字符，无需关心子序列内部结构。这是「最长 X 子序列」类 DP 的标准姿势。

### 解法二：贪心 + 二分查找（官方方法二，O(n log n)）

进阶要求把复杂度降到 O(n log n)，靠的就是这招。核心思想：**想让递增子序列尽可能长，就要让「同长度的子序列」的结尾尽可能小**——结尾越小，后面能接上的元素越多。

维护一个数组 `d`，其中 `d[k]` 表示「长度为 k 的所有递增子序列中，结尾元素的最小值」。可以证明 `d` 是**严格递增**的（长度更长的子序列结尾不可能更小）。对每个 `nums[i]`：

- 若 `nums[i] > d[len]`（比当前最长子序列的结尾还大）：直接接上去，`d[++len] = nums[i]`，子序列变长。
- 否则：在 `d[1..len]` 里二分找**第一个 ≥ `nums[i]** 的位置 `pos`，用 `nums[i]` 替换 `d[pos]`（让某个长度的结尾变得更小，为将来接更多元素腾空间）。这一步**不改变 `len`**，只是「优化」已有长度。

最终 `len` 就是答案。注意 `d` 数组在过程中**不一定**是真正的最长子序列（中间被替换过），但它的**长度**始终正确。

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int len = 1, n = (int)nums.size();
        if (n == 0) return 0;

        // d[k]：长度为 k 的递增子序列中，结尾元素的最小值。d[1..len] 有效。
        //   - d 严格递增（长度越长结尾越大），所以可以用二分。
        //   - 开 n+1 是因为下标从 1 开始用（d[0] 不参与，避免长度 0 的歧义）。
        vector<int> d(n + 1, 0);
        d[len] = nums[0];

        for (int i = 1; i < n; ++i) {
            if (nums[i] > d[len]) {
                // 比当前最长子序列结尾还大 → 直接接上，子序列变长。
                d[++len] = nums[i];
            } else {
                // 二分找 d[1..len] 里第一个 >= nums[i] 的位置 pos。
                //   - 用「找最后一个 < nums[i] 的位置」的写法，pos+1 就是第一个 >= nums[i] 的位置。
                //   - 如果找不到（所有 d[k] 都 >= nums[i]），pos=0，替换 d[1]。
                int l = 1, r = len, pos = 0;
                while (l <= r) {
                    int mid = (l + r) >> 1;   // 位运算右移一位 = 除以 2
                    if (d[mid] < nums[i]) {
                        pos = mid;
                        l = mid + 1;
                    } else {
                        r = mid - 1;
                    }
                }
                d[pos + 1] = nums[i];         // 替换：让长度 pos+1 的结尾变小
            }
        }
        return len;
    }
};
```

- **时间**：O(n log n)——外层 n 次，每次内层二分 O(log n)。
- **空间**：O(n)——`d` 数组。
- **何时用**：当 n 很大（如 n > 10^5）时，O(n²) DP 会超时，必须用这招。本题 n ≤ 2500，两种解法都能过，DP 更易理解，二分更优更快。
- **STL 进阶写法**：二分那段可以用 `<algorithm>` 的 `lower_bound`：`int pos = lower_bound(d.begin() + 1, d.begin() + len + 1, nums[i]) - d.begin(); d[pos] = nums[i];`。`lower_bound(first, last, v)` 返回区间内**第一个 ≥ v** 的迭代器，区间已有序时是 O(log n)。这里官方手写二分是为了讲清原理，实际刷题用 `lower_bound` 更简洁。

### 可迁移套路：「按结尾定义 + 枚举前驱」是子序列 DP 的万能起手式

| 题目 | 状态定义 | 转移 |
|---|---|---|
| 300 最长递增子序列 | `dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长 | `dp[i] = max(dp[j]+1)`，`j<i` 且 `nums[j]<nums[i]` |
| 1143 最长公共子序列 | `dp[i][j]` = `s1[0..i]` 与 `s2[0..j]` 的 LCS 长 | 字符相等 `dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])` |
| 53 最大子数组和（子数组版） | `f(i)` = 以 `nums[i]` 结尾的最大和 | `max(f(i-1)+x, x)`（退化为只看前一项） |

记住这个表：**凡是「子序列 / 子数组 + 最值」的题，先想「按结尾定义状态」，再决定转移时看一个前驱还是所有前驱**。
