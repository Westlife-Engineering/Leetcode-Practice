# 118 杨辉三角

- 难度：简单
- 标签：**数组**、**动态规划**
- 力扣链接：https://leetcode.cn/problems/pascals-triangle/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[杨辉三角](https://leetcode.cn/problems/pascals-triangle/solution/yang-hui-san-jiao-by-leetcode-solution-lew9/)」（方法一：数学）。正文主解是 **动态规划（逐行构造）**：每行首尾是 1，中间每个数 = 上一行左上方 + 右上方，O(n²) 时间 O(n²) 空间。这是二维 DP 的入门题——当前行依赖上一行，递推即可。

## 题目描述

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1:**

```
输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2:**

```
输入: numRows = 1
输出: [[1]]
```

**提示:**

- `1 <= numRows <= 30`

## 思路

> 本题主要参考力扣官方题解「方法一：数学」。

题目已经把规则写在题面里了：**「每个数是它左上方和右上方的数的和」**。所以这是一道按规则构造的题，重点是把这条规则翻译成下标关系。

### 杨辉三角长什么样

把前 5 行左对齐写出来（行号从 0 开始，列号也从 0 开始）：

```
行号 i=0:     [1]
行号 i=1:    [1, 1]
行号 i=2:   [1, 2, 1]
行号 i=3:  [1, 3, 3, 1]
行号 i=4: [1, 4, 6, 4, 1]
```

观察其中的规律，可以总结出几条**核心性质**（官方题解列了一长串，最关键的是下面两条）：

1. **每行首尾两个数都是 1**。即 `triangle[i][0] = 1` 且 `triangle[i][i] = 1`（第 `i` 行有 `i+1` 个元素，下标 `0` 到 `i`）。
2. **中间每个数 = 上一行「左上方 + 右上方」**。第 `i` 行第 `j` 列（`1 <= j <= i-1`）：

   ```
   triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]
   ```

   - `triangle[i-1][j-1]` 是「左上方」（上一行、列号小一位）；
   - `triangle[i-1][j]` 是「右上方」（上一行、列号相同）。

   对应到组合数公式就是 $\mathcal{C}_n^m=\mathcal{C}_{n-1}^{m}+\mathcal{C}_{n-1}^{m-1}$，第 `i` 行第 `j` 个数恰好是组合数 $\binom{i}{j}$。

另外两条用得较少的性质（备忘）：每行左右对称；第 `n` 行有 `n+1` 项，前 `n` 行共 `n(n+1)/2` 个数。

### 为什么这是「动态规划」

DP 的三个要素本题都对得上：

- **状态**：`triangle[i][j]` 表示第 `i` 行第 `j` 列的值。
- **转移**：`triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]`（当前行依赖上一行）。
- **边界**：每行首尾为 1，第 0 行只有 `[1]`。

它和一维 DP（如 70 爬楼梯、53 最大子数组和）的区别在于：**状态是二维的（行、列）**，但「第 `i` 行」这一整行只依赖「第 `i-1` 行」，所以可以**逐行构造**——算完一行存进结果，再拿它算下一行，天然有递推顺序，不需要额外的状态压缩技巧。

### 手动推导 numRows = 5

```
i=0:  只有 1 个元素，首尾都是它 → [1]
i=1:  2 个元素，首尾都是 1      → [1, 1]
i=2:  先全填 1 得 [1,1,1]
      再算中间 j=1: triangle[1][0]+triangle[1][1] = 1+1 = 2
      → [1, 2, 1]
i=3:  先全填 1 得 [1,1,1,1]
      j=1: triangle[2][0]+triangle[2][1] = 1+2 = 3
      j=2: triangle[2][1]+triangle[2][2] = 2+1 = 3
      → [1, 3, 3, 1]
i=4:  先全填 1 得 [1,1,1,1,1]
      j=1: triangle[3][0]+triangle[3][1] = 1+3 = 4
      j=2: triangle[3][1]+triangle[3][2] = 3+3 = 6
      j=3: triangle[3][2]+triangle[3][3] = 3+1 = 4
      → [1, 4, 6, 4, 1]
最终输出 [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]] ✓
```

**实现小技巧**：与其逐个判断「是不是首尾」，不如先把整行**全部初始化为 1**（`vector<int>(i+1, 1)`），这样首尾的 1 天然就有了，循环里只需要处理中间下标 `1` 到 `i-1` 的元素去覆写，逻辑更干净。这是官方代码（用 `resize` 后单独设首尾）的等价写法。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        // vector<vector<int>> ans：二维动态数组（「向量的向量」）。
        //   - 外层 vector 的每个元素本身又是一个 vector<int>（一行）。
        //   - 这里只声明、不指定大小，后面用 push_back 一行一行追加进去。
        //   - 它就是要返回的「整个杨辉三角」，最终大小为 numRows 行。
        vector<vector<int>> ans;

        // 外层循环：逐行构造，i 是行号（0 到 numRows-1）。
        //   - 第 i 行共有 i+1 个元素。
        for (int i = 0; i < numRows; ++i) {
            // vector<int> row(i + 1, 1)：构造一个长度为 i+1、每个元素都初始化为 1 的一维 vector。
            //   - 第一个参数是「元素个数」，第二个是「初始值」。
            //   - 关键好处：首尾两个位置的 1 直接就有了（杨辉三角每行首尾都是 1），
            //     循环里只要处理「中间」的元素即可，不用单独特判边界。
            //   - 构造复杂度 O(i+1)（要逐个填初值）。
            vector<int> row(i + 1, 1);

            // 内层循环：只处理「中间」的下标 j = 1 到 i-1（首尾下标 0 和 i 保持为 1 不动）。
            //   - 当 i <= 1 时（第 0、1 行），1 <= j < i 不成立，循环体不执行，
            //     row 就是全 1，正好是 [1] 和 [1,1]，正确。
            for (int j = 1; j < i; ++j) {
                // 状态转移：当前格 = 上一行「左上方 + 右上方」。
                //   - ans[i-1]：上一行（因为 ans 里已经存好了前 i 行，下标 0 到 i-1）。
                //   - ans[i-1][j-1]：上一行、列号 j-1（左上方）。
                //   - ans[i-1][j]：  上一行、列号 j   （右上方）。
                //   - 注意 j 的范围是 [1, i-1]，所以 j-1 >= 0 且 j <= i-1 < i，
                //     两个下标都落在上一行合法范围内，不会越界。
                row[j] = ans[i - 1][j - 1] + ans[i - 1][j];
            }

            // ans.push_back(row)：把构造好的一行追加到 ans 末尾。
            //   - push_back 会把 row 复制一份存进 ans（之后 row 这个局部变量就被丢弃了）。
            //   - 这里行末还可以写 ans.emplace_back(row)（emplace_back 少一次移动，
            //     对 int 这类平凡类型差别不大），两种写法力扣都接受。
            ans.push_back(row);
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n²)，其中 `n = numRows`
  - 第 `i` 行有 `i+1` 个元素，需要构造 + 计算共 O(i)。总元素个数为 `1+2+...+n = n(n+1)/2`，即 O(n²)。
  - 这已经是理论下界——因为**输出本身**就有 O(n²) 个数，至少得花这么多时间把它们都写出来。
- **空间**：O(n²)
  - 即返回值 `ans` 占用的空间，共 `n(n+1)/2` 个 int。若不计返回值（官方题解的口径），额外空间为 O(1)（只有 `i`、`j`、`row` 几个变量）。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：为什么每行首尾两个数一定是 1？

这是杨辉三角的**定义性质**。可以从两个角度理解：

- **从构造规则看**：中间元素 = 左上方 + 右上方。但每行第一个数没有「左上方」（左边没元素），最后一个数没有「右上方」（右边没元素），没法套公式，于是规定它们就是 1。
- **从组合数看**：第 `i` 行第 `j` 个数是组合数 $\binom{i}{j}$。当 `j=0` 或 `j=i` 时 $\binom{i}{0}=\binom{i}{i}=1$（从 `i` 个里取 0 个或全取，都只有 1 种方案）。所以首尾恒为 1。

实现上，`vector<int>(i+1, 1)` 先把整行填成 1，正好把首尾搞定，循环里只动中间。

### Q2：中间元素 `triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]` 这个公式怎么来的？

题目原话「每个数是它**左上方和右上方**的数的和」。把这句话翻译成下标：

- 当前在第 `i` 行第 `j` 列。
- 「上方」= 上一行 = 第 `i-1` 行。
- 「左上方」= 上一行里、比当前列号小一位 = 第 `i-1` 行第 `j-1` 列。
- 「右上方」= 上一行里、和当前列号相同 = 第 `i-1` 行第 `j` 列。

两数相加即可。注意 `j` 的合法范围是 `[1, i-1]`：`j=0` 是首元素（没有左上方），`j=i` 是尾元素（没有右上方），都跳过。对应组合数递推 $\mathcal{C}_n^m=\mathcal{C}_{n-1}^{m}+\mathcal{C}_{n-1}^{m-1}$。

### Q3：为什么时间复杂度是 O(n²)？看起来只是两层 for。

外层 `i` 从 0 跑到 `numRows-1`，内层 `j` 从 1 跑到 `i-1`，内层执行次数是 `0+0+1+2+...+(n-2)`，总和约 `n²/2`，也就是 O(n²)。直观地说：**输出的三角形一共约 n²/2 个格子**，每个格子（除了每行首尾的 1）都要算一次加法，所以总工作量正比于格子数。这已经是该问题的最优——不可能比 O(n²) 更快，因为光是把结果填出来就要访问每个格子。

### Q4：`vector<int>(i + 1, 1)` 这个写法是什么意思？为什么不是先 `resize` 再循环赋值？

`vector<int>(count, value)` 是 vector 的**构造函数**，意思是「造一个长度为 `count` 的 vector，每个元素都初始化为 `value`」。所以 `vector<int>(i+1, 1)` 就是「长度 `i+1`、全为 1」的一行。

官方代码用的是另一种等价写法：

```cpp
ret[i].resize(i + 1);        // 先把第 i 行扩到 i+1 个元素（默认填 0）
ret[i][0] = ret[i][i] = 1;   // 再单独把首尾设成 1
```

两种写法效果一样，但 `vector<int>(i+1, 1)` 把「首尾是 1」这件事一步到位地表达出来了，更贴合杨辉三角的性质、也更易读。代价是中间那些位置被先填了 1 再被覆写（多了一次无意义的写入），但常数极小、可忽略。

## 复盘

- **核心套路**：**「逐行递推构造」**——当每一行的值只依赖上一行时，按行从上到下算、把每行存进结果数组即可。这是一类非常通用的二维 DP 模式（当前层只看上一层），和「滚动数组」是同源思想；只是本题的输出就是整张表，不必压缩空间。
- **性质 → 公式的翻译**：题目用自然语言给规则（「左上方 + 右上方」），写代码前要把它**翻成下标关系**（`[i-1][j-1] + [i-1][j]`），并想清楚下标合法范围。这套「文字 → 下标」的翻译能力是所有数组/矩阵题的基本功。
- **初始化技巧**：先把整行填成「边界值」（这里是 1）、再覆写中间，能避免在循环里反复 `if` 特判边界。这种「先填默认值再改中间」的写法在网格 DP 里很常见（比如矩阵路径、旋转矩阵）。
- **杨辉三角的应用**：第 `n` 行第 `k` 个数 = 组合数 $\binom{n}{k}$，所以本题也等价于「打印 $\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$」。反过来，求单个组合数时也可以用这个递推（帕斯卡公式）避免阶乘溢出——`C(n,k)` 类题目（如 62 不同路径）背后就是同一套递推。
