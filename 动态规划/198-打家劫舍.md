# 198 打家劫舍

- 难度：中等
- 标签：数组、**动态规划**
- 力扣链接：https://leetcode.cn/problems/house-robber/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[打家劫舍](https://leetcode.cn/problems/house-robber/solution/da-jia-jie-she-by-leetcode-solution/)」。正文主解是 **动态规划（滚动变量）**，O(n) 时间 O(1) 空间——这是 **DP「偷 / 不偷两种决策取最优」** 的经典入门题。官方同一篇文章里先用 `dp` 数组讲清转移方程（写法更直观），再用滚动变量把空间压到 O(1)，这里正文直接给最终的滚动变量版本；数组版本放「复盘」对照。

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

**示例 1：**

```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**

```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 思路

> 本题主要参考力扣官方题解「方法一：动态规划」。

要求的是「能偷到的**最高金额**」。约束只有一条：**相邻两家不能同时偷**。也就是说，对每一间房，只有两种选择——偷，或不偷。这天然就是一个**决策问题**，适合用动态规划把「前 i 家的最优结果」一点点推出来。

### DP 三要素（所有 DP 题的通用思考框架）

做任何动态规划题，先把这三件事想清楚，代码自然就出来了。

#### ① 状态定义：`dp[i]` = 前 `i` 家（`nums[0..i-1]`）能偷到的最高金额

把「问题」用一个数组（或变量）描述出来。这里「前 i 家能偷到的最高金额」就是最自然的状态——`dp[n]`（n 是房屋总数）就是答案。

> 为什么这么定义？因为「前 i 家的最高金额」是一个**子问题**，且原问题「前 n 家的最高金额」就是子问题 `i=n` 的特例。DP 的本质就是把大问题拆成结构相同的子问题。
>
> 注意这里的下标口径：`dp[i]` 表示的是**前 i 家**（不是「第 i 家」）。对应到数组下标，「第 i 家」是 `nums[i-1]`。下文转移方程里出现的 `nums[i]` 指的是**下标为 i 的那一家**，请留意这个口径差异（官方代码用 `size = nums.size()` 直接按下标处理，所以转移写成 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，这里的 `i` 是**数组下标**）。

#### ② 状态转移方程：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`（核心！）

这是全题最关键的观察。**盯着「第 i 家（下标 i）要不要偷」看**——只有两种可能：

1. **不偷第 i 家**：那前 i 家能偷到的最高金额，就等于前 `i-1` 家的最高金额（第 i 家没贡献，原样继承），即 `dp[i-1]`；
2. **偷第 i 家**：那第 `i-1` 家**绝对不能偷**（相邻会触发警报），所以前 i 家的最高金额 = 前 `i-2` 家的最高金额 + 第 i 家的金额，即 `dp[i-2] + nums[i]`。

这两种情况**互斥**（对第 i 家只有偷或不偷）、**完备**（没有第三种可能）。所以两者取较大值：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

一句话总结：**「考虑下标 i 这家时，要么不偷（沿用 dp[i-1]），要么偷（dp[i-2] + nums[i]），两者取大」**。为什么偷第 i 家时是 `dp[i-2]` 而不是 `dp[i-1]`？因为一旦偷了第 i 家，第 `i-1` 家就被「锁死」不能偷了，能自由安排的只剩前 `i-2` 家，所以加上的是 `dp[i-2]`。

#### ③ 初始条件：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`

转移方程依赖「前两项」，所以最小的两项必须**手动给定**（否则没法启动递推）：

- `dp[0]`：只有一家（下标 0），只能偷它，最高金额 = `nums[0]`。
- `dp[1]`：有两家（下标 0 和 1），相邻只能偷一家，挑金额高的，最高金额 = `max(nums[0], nums[1])`。

> 注意 `dp[1]` 不能直接写成 `nums[1]`！因为前两家里可能第 0 家金额更高（比如 `nums=[5,1]`，应该偷第 0 家得 5，而不是偷第 1 家得 1）。这是和爬楼梯（`dp[2] = dp[1]+dp[0]`）不同的地方——本题是**取最值**，不是求和，所以初始值要先比一下。

### 手动推导两个示例

**示例 1：`nums = [1,2,3,1]`**（下标 0~3，n=4）

```
dp[0] = nums[0]                    = 1
dp[1] = max(nums[0], nums[1])      = max(1, 2)  = 2
dp[2] = max(dp[1], dp[0]+nums[2])  = max(2, 1+3)= 4   ← 不偷下标2得2，偷下标2得1+3=4，取4
dp[3] = max(dp[2], dp[1]+nums[3])  = max(4, 2+1)= 4   ← 偷下标3得2+1=3 < 不偷得4，取4
返回 dp[3] = 4 ✓   （偷下标 0 和 2：1+3=4）
```

**示例 2：`nums = [2,7,9,3,1]`**（下标 0~4，n=5）

```
dp[0] = nums[0]                    = 2
dp[1] = max(nums[0], nums[1])      = max(2, 7)  = 7
dp[2] = max(dp[1], dp[0]+nums[2])  = max(7, 2+9)= 11  ← 偷下标2：2+9=11 > 7
dp[3] = max(dp[2], dp[1]+nums[3])  = max(11,7+3)= 11  ← 偷下标3得7+3=10 < 11
dp[4] = max(dp[3], dp[2]+nums[4])  = max(11,11+1)=12  ← 偷下标4：dp[2]+1=11+1=12
返回 dp[4] = 12 ✓  （偷下标 0、2、4：2+9+1=12）
```

### 用滚动变量把空间压到 O(1)

朴素 DP 要开一个长度 n 的 `dp` 数组，空间 O(n)。但观察转移方程：**`dp[i]` 只依赖它前面的两项 `dp[i-1]` 和 `dp[i-2]`**，再往前的 `dp[i-3]`、`dp[i-4]`……一旦用完就再也没用了。

所以不用存整个数组，**只用 2 个变量轮流滚动**就够了——这就是「滚动变量」（也叫滚动数组思想的一维退化版）。官方代码用 `first`、`second` 两个变量，分别对应 `dp[i-2]`、`dp[i-1]`，每轮循环算出新的 `dp[i]` 后整体右移一位。

## 代码

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        // 特判空数组（本题约束 n>=1，写上是防御性编程的好习惯，照搬官方不丢分）。
        if (nums.empty()) {
            return 0;
        }
        int size = nums.size();
        // 只有一家：只能偷它，直接返回 nums[0]。
        //   必须特判！否则下面 second = max(nums[0], nums[1]) 在 size==1 时
        //   会越界访问 nums[1]（数组只有下标 0），导致未定义行为。
        if (size == 1) {
            return nums[0];
        }

        // first / second 是两个「滚动变量」，含义（在每轮循环「开始时」）：
        //   first  = dp[i-2]   （前 i-2 家能偷的最高金额）
        //   second = dp[i-1]   （前 i-1 家能偷的最高金额，也是当前已知的「最新最优值」）
        //   ——本轮目标是算出 dp[i] = max(second, first + nums[i])，
        //     算完后两个变量整体「往右滚动一位」（详见循环内注释）。
        //
        // 初始化（i=2 时开始用转移方程，所以先填好 dp[0]、dp[1]）：
        //   first  = nums[0]                  = dp[0]
        //   second = max(nums[0], nums[1])    = dp[1]   ← 前两家相邻只能偷一家，挑金额高的
        int first = nums[0], second = max(nums[0], nums[1]);

        // i 从 2 到 size-1：第 i 轮算出 dp[i]。
        //   - 从 2 开始，因为 dp[0]、dp[1] 已经初始化好了，转移方程最早用到的是 dp[2]。
        //   - 注意是 < size（下标 0~size-1），共循环 size-2 次；结束时 second 里就是 dp[size-1]。
        for (int i = 2; i < size; i++) {
            // ★ 滚动三步——顺序不能乱！
            //   1) 先用 temp 把「旧 second」(=dp[i-1]) 存起来，因为下一步 second 就要被覆盖了。
            int temp = second;
            //   2) 算出 dp[i] 赋给 second：max(不偷第i家=dp[i-1], 偷第i家=dp[i-2]+nums[i])
            //      = max(旧 second, first + nums[i])。这是本轮真正的计算。
            //      <algorithm> 的 max(a, b)：返回 a、b 中较大者，O(1)。
            second = max(first + nums[i], second);
            //   3) 把刚存的「旧 second」(=dp[i-1]) 赋给 first，于是 first 变成 dp[i-1]，
            //      正好是「下一轮 i+1」所需要的 dp[(i+1)-2] = dp[i-1]。
            //      ——到这里两个变量都已更新完毕：新 first = dp[i-1]、新 second = dp[i]。
            first = temp;
            // 顺序命门：必须先存 temp 再覆盖 second，最后才动 first。
            //   如果先写 second=... 就会把旧 second（dp[i-1]）冲掉，
            //   后面 first = temp 拿不到旧 second，递推就崩了。
            //   （first、second、temp 在 C++ 里就是普通 int，赋值即覆盖，没有副本。）
        }
        return second;   // 循环结束时 second = dp[size-1]，即前 n 家能偷的最高金额
    }
};
```

**用示例 2 `nums = [2,7,9,3,1]` 走一遍**（每轮循环**结束后**的 first、second）：

```
初始:                      first=2, second=7
i=2: temp=7, second=max(2+9, 7)=11, first=7   →  first=7,  second=11  (=dp[2])
i=3: temp=11, second=max(7+3, 11)=11, first=11 →  first=11, second=11  (=dp[3])
i=4: temp=11, second=max(11+1, 11)=12, first=11 → first=11, second=12  (=dp[4])
返回 12 ✓
```

## 复杂度

- **时间**：O(n)
  - 循环从下标 2 跑到 `size-1`，每轮做 1 次 `max`（O(1)），共 n-2 轮，整体 O(n)。
- **空间**：O(1)
  - 只用了 `first`、`second`、`temp` 三个 int 变量，没有开数组。对比朴素 `dp` 数组的 O(n)，省了一大块。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：转移方程怎么来的？为什么偷第 i 家用的是 `dp[i-2]` 而不是 `dp[i-1]`？

这是全题最容易卡的地方。关键在于**「偷第 i 家」这个决策会连累第 `i-1` 家**。

- 如果**偷**第 i 家（拿到 `nums[i]`），那因为「相邻不能同时偷」，第 `i-1` 家就被锁死不能偷了。既然第 `i-1` 家没贡献，那「前 i 家的最优」就退化成「前 `i-2` 家的最优 + 第 i 家金额」= `dp[i-2] + nums[i]`。
- 如果**不偷**第 i 家，那第 i 家没贡献，第 `i-1` 家爱偷不偷（自由安排），所以「前 i 家的最优」=「前 `i-1` 家的最优」= `dp[i-1]`。

两者取大就是 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。所以 `dp[i-2]` 里的 `-2` 是被「偷了第 i 家就不能偷第 i-1 家」这条规则逼出来的。

### Q2：为什么不偷第 i 家用 `dp[i-1]`、偷第 i 家用 `dp[i-2]`？感觉两种决策在「看不同的家」。

没在「看不同的家」，两种决策**都在考虑「前 i 家」这个整体**，只是对「第 i 家」的处理方式不同：

- 「不偷第 i 家」时，相当于把问题**甩给前 `i-1` 家**（让它们自己最优）。
- 「偷第 i 家」时，第 i 家已经固定要偷了，剩下能自由安排的是前 `i-2` 家（第 `i-1` 家被锁死）。

两种决策最后都要回答同一个问题：「前 i 家的最高金额是多少？」——所以是同一个状态 `dp[i]` 的两个候选值，取大即可。

### Q3：能不能偷三家、四家不相邻的？方程只看了「相邻两家」。

方程**没有限制偷几家**，只限制「相邻不能同时偷」。`dp[i-2]` 里可能本身就含多个被偷的房子（比如 `dp[4]` 对应偷了下标 0、2、4 三家，互不相邻）。所以方程天然支持「偷任意多家不相邻的房子」，递推过程会自动把最优组合挑出来。

如果想还原出具体偷了哪些家（而不只是金额），就得保留整个 `dp` 数组、从 `dp[n]` 回溯——但本题只要金额，滚动变量足够。

### Q4：滚动变量 `first`/`second` 到底怎么工作？为什么需要 `temp`？

记住一句话：**每轮循环把 `(first, second)` 整体往右「挪」一位，腾出来的最右格填新算的 `dp[i]`**。

循环开始时两者的角色（对第 `i` 轮）：

```
first = dp[i-2]   second = dp[i-1]     ← 这是「旧的」一对
```

本轮目标是算 `dp[i] = max(second, first + nums[i])`，并让下一轮（`i+1`）开始时两者变成 `dp[i-1]`、`dp[i]`。所以：

```
temp   = second;                         // 备份旧 second（=dp[i-1]），因为下一步要覆盖它
second = max(first + nums[i], second);   // 算出新 dp[i]，赋给 second
first  = temp;                           // 把旧 second（=dp[i-1]）赋给 first
```

**`temp` 的唯一作用**就是保住「旧 second」——因为 `second = ...` 会把它冲掉，但下一轮的 `first` 又恰好需要它（新 first = dp[i-1]）。所以必须先存后覆盖。如果不用 `temp`，三步写成两步，必然会丢失 `dp[i-1]`，递推就崩了。

## 复盘

- **核心套路**：「**DP「偷 / 不偷两种决策取最优」**」是打家劫舍系列的总框架。看到「每个位置有选或不选两种决策、不能连续选、要求最值」时，第一步就是问自己：状态怎么定义？偷和不偷分别怎么转移？最小边界是多少？把这三件事写下来，代码就完成了一大半。
- **「盯着第 i 家做决策」找转移方程**：本题是「第 i 家偷还是不偷」；这个思考方式可迁移到一大类 DP——比如「选不选、选哪个、能不能连选」。**分析当前位置的决策→分类→取最值**，是推导转移方程的通用招数。
- **滚动变量压缩**：当 `dp[i]` 只依赖**有限的前几项**（本题只依赖前 2 项）时，不用数组、用几个变量滚动即可，空间从 O(n) 降到 O(1)。判断「能不能压」就看转移方程回头看几步——只看前 2 步用 2 个变量（+1 个 temp 辅助）。这和爬楼梯的滚动变量思想完全一致。
- **取最值 vs 求和的初始条件差异**：爬楼梯是「方法数求和」，`dp[1]`、`dp[2]` 直接数；打家劫舍是「金额取最值」，`dp[1]` 必须先 `max` 比较两家（不能直接给 `nums[1]`）。看到 `max` 就要警觉初始值可能要先比一下。

### 系列迁移：213 环形打家劫舍、337 打家劫舍 III

本题（198）是打家劫舍系列的入门，转移方程 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 是后续两题的基石：

- **213 打家劫舍 II（环形）**：房子排成**环**（首尾相邻）。破环技巧：分别考虑「偷下标 0，不偷最后一家」和「不偷下标 0，可偷最后一家」两种情况，各跑一遍 198 的 rob，取较大值。本质还是 198 的转移方程，只是把环拆成两条链。
- **337 打家劫舍 III（树形）**：房子排成**二叉树**，相邻父子不能同时偷。把 `dp[i] = max(dp[i-1], dp[i-2]+nums[i])` 推广成「每个节点返回两个值：偷该节点的最大值、不偷该节点的最大值」，在树上后序遍历递推。思想内核还是「偷 / 不偷两种决策取最优」。

### 解法二：`dp` 数组版（官方写法一，对照用）

思路完全一样，区别是不压缩空间——直接开 `dp` 数组把每一步存下来，转移方程一目了然，**调试 / 推导时更直观**。生产代码里两种等价，滚动变量版省内存。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        if (nums.empty()) return 0;
        int size = nums.size();
        if (size == 1) return nums[0];

        // vector<int>(size, 0)：构造长度为 size、元素全为 0 的动态数组。
        //   - 写法上 vector<int> dp = vector<int>(size, 0); 和 vector<int> dp(size, 0); 等价。
        //   - 访问 dp[i] 是 O(1)；整体占用 O(size) 空间。
        vector<int> dp = vector<int>(size, 0);
        dp[0] = nums[0];                         // 前一家：只能偷它
        dp[1] = max(nums[0], nums[1]);           // 前两家：相邻只能偷一家，挑金额高的
        for (int i = 2; i < size; i++) {
            // 转移方程：不偷第 i 家(dp[i-1]) vs 偷第 i 家(dp[i-2]+nums[i])，取大。
            dp[i] = max(dp[i - 2] + nums[i], dp[i - 1]);
        }
        return dp[size - 1];
    }
};
```

- **时间**：O(n)
- **空间**：O(n)——比滚动变量版多开一个长度 n 的数组。
- **何时用**：调试 / 理解转移过程时更清晰；正式提交建议用滚动变量版。
