# 53 最大子数组和

- 难度：中等
- 标签：**数组**、分治、动态规划
- 力扣链接：https://leetcode.cn/problems/maximum-subarray/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考力扣官方题解「[最大子序和](https://leetcode.cn/problems/maximum-subarray/solution/zui-da-zi-xu-he-by-leetcode-solution/)」。正文主解是 **动态规划（Kadane 算法，滚动变量）**，O(n) 时间 O(1) 空间；官方的**分治法**（O(n) 时间 O(log n) 空间）放在「复盘」作对比。

## 题目描述

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组** 是数组中的一个连续部分。

**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**示例 2：**

```
输入：nums = [1]
输出：1
```

**示例 3：**

```
输入：nums = [5,4,-1,7,8]
输出：23
```

**提示：**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**进阶：** 如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 **分治法** 求解。

## 思路

> 本题主要参考力扣官方题解「方法一：动态规划」。

要求的是「**连续**子数组的最大和」。注意「连续」二字——子数组的元素必须挨在一起，不能跳着挑。这把它和「最长递增子序列」那种可以不连续的题区分开。

### 暴力想法：枚举所有子数组 O(n²)

最直接的思路：两层循环，外层定起点 `i`，内层定终点 `j`，把 `nums[i..j]` 的和算出来取最大。固定 `i` 后，`j` 从 `i` 往右扩展时可以**累加**着求和（不用每次重新算），所以内层是 O(n)，整体 O(n²)。

数据范围 n ≤ 10^5 时，O(n²) = 10^10 量级，**会超时**。需要更快的做法。

### 前缀和的想法（也是 O(n²)，但启发了 O(n) 解法）

记前缀和 `S[k] = nums[0]+...+nums[k-1]`（`S[0]=0`），则 `nums[i..j]` 的和 = `S[j+1] - S[i]`。要让「以 `j` 结尾的子数组和最大」，就是要找一个**最小的 `S[i]`（i ≤ j）**。

这其实已经能看到 O(n) 的影子了：边扫边维护「已经扫过的前缀和最小值」`minS`，对每个 `j` 用 `S[j+1] - minS` 更新答案。这就是前缀和视角下的 O(n) 解法，本质和下面的 Kadane 等价。

### 官方主解：动态规划（Kadane 算法）

**核心定义**：令 `f(i)` 表示**以第 `i` 个数结尾**的「连续子数组的最大和」。那么最终答案就是：

```
max { f(i) }, 0 ≤ i ≤ n-1
```

为什么按「以 `i` 结尾」来定义状态？因为这样有**无后效性**——一旦固定了「必须以 `nums[i]` 结尾」，前面的选择只归结成一个问题：接不接上 `f(i-1)` 那一段。

**状态转移**——这是全题最关键的观察：

对 `nums[i]` 来说，以它结尾的最大和子数组只有两种可能：

1. **接在前面那段后面**：和 = `f(i-1) + nums[i]`；
2. **从 `nums[i]` 自己重新开始**：和 = `nums[i]`。

两者取大：

```
f(i) = max( f(i-1) + nums[i], nums[i] )
```

一句话总结这个决策：**「前面的累积和对我有帮助就接上，没帮助（是负的）就丢掉、从自己重开」**。因为如果 `f(i-1) < 0`，那 `f(i-1) + nums[i] < nums[i]`，接上去只会拖后腿，不如从 `nums[i]` 起一段新的。

**压成 O(1) 空间**：`f(i)` 只依赖 `f(i-1)`，不需要开整个 `f` 数组，用一个变量 `pre` 滚动保存「上一个位置的 f 值」即可。这就是「滚动数组/滚动变量」思想。

### 用示例走一遍

`nums = [-2,1,-3,4,-1,2,1,-5,4]`（`pre` = 以当前元素结尾的最大和，`maxAns` = 全局最大）：

```
i=0  x=-2  pre=max(0-2,-2)=-2   maxAns=max(-2,-2)=-2
i=1  x= 1  pre=max(-2+1, 1)= 1   maxAns=max(-2, 1)= 1   ← 前面-2是负的，丢掉，从1重开
i=2  x=-3  pre=max( 1-3,-3)=-2   maxAns=max( 1,-2)= 1
i=3  x= 4  pre=max(-2+4, 4)= 4   maxAns=max( 1, 4)= 4   ← 又重开
i=4  x=-1  pre=max( 4-1,-1)= 3   maxAns=max( 4, 3)= 4
i=5  x= 2  pre=max( 3+2, 2)= 5   maxAns=max( 4, 5)= 5
i=6  x= 1  pre=max( 5+1, 1)= 6   maxAns=max( 5, 6)= 6   ← 峰值，对应子段 [4,-1,2,1]
i=7  x=-5  pre=max( 6-5,-5)= 1   maxAns=max( 6, 1)= 6
i=8  x= 4  pre=max( 1+4, 4)= 5   maxAns=max( 6, 5)= 6
返回 6 ✓
```

## 代码

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        // pre：滚动变量，保存「以当前元素 x 结尾的连续子数组的最大和」f(i)。
        //   - 初始化为 0，因为转移写成 max(pre + x, x)，
        //     第一个元素时 pre+x = 0+x = x，等价于「从自己开始」，不会出错。
        //   - 每轮循环用新值覆盖（只依赖上一轮），所以一个变量即可，无需 f 数组。
        int pre = 0;
        // maxAns：全局答案，所有 f(i) 的最大值。
        //   - 必须初始化成 nums[0]（或某个真实元素），不能初始化成 0！
        //     因为数组可能全为负数（如 [-1] 或 [-2,-1]），此时最大和是负数，
        //     若初值给 0，会被错误地当成答案返回（0 比任何负数大）。
        int maxAns = nums[0];

        // 范围 for 循环：const auto &x 逐个只读引用 nums 的元素，避免拷贝。
        //   - const：不修改元素；auto：让编译器推导类型（这里是 int）；
        //     &：引用，对 int 没什么性能差别，但养成对大对象用引用的习惯。
        for (const auto &x : nums) {
            // max(a, b)：<algorithm> 里的函数，返回 a、b 中较大者，O(1)。
            //   核心决策：x 要么接在 pre 后面（pre + x），要么自己另起一段（x）。
            //   - 当 pre < 0 时，pre + x < x，max 自动选 x，相当于「丢掉前面的负贡献」。
            pre = max(pre + x, x);
            // 用当前 f(i) 更新全局最大值。
            maxAns = max(maxAns, pre);
        }
        return maxAns;
    }
};
```

## 复杂度

- **时间**：O(n)
  - 只遍历一遍数组，每个元素做两次 `max`（O(1)），共 O(n)。
- **空间**：O(1)
  - 只用了 `pre`、`maxAns` 两个变量，没有开额外数组。

## 疑惑 / 卡点

> 这块记录做题时和 AI 的问答，方便以后回顾。随做题提问持续更新。

### Q1：`maxAns` 为什么初始化成 `nums[0]` 而不是 `0`？

**因为数组可能全是负数。** 题目要求「子数组最少包含一个元素」，所以答案至少得选一个元素，**绝不能是 0**（0 对应「空子数组」，题目不允许）。

举例 `nums = [-2,-1]`：正确答案是 `-1`（选 `[-1]` 这一段）。如果 `maxAns` 初值给 `0`，循环里 `pre` 始终为负，`max(0, pre)` 永远是 `0`，最后返回 `0`——这是**空子数组的和**，不符合题意，错。

`pre` 初值给 `0` 是可以的，因为第一个元素时 `max(0 + x, x) = x`，自动归位；但 `maxAns` 必须用数组里的真实元素兜底。

### Q2：全是负数的情况下，这套转移还成立吗？

成立。走一遍 `nums = [-3,-2,-1]`：

```
pre=0 maxAns=-3
x=-3: pre=max(0-3,-3)=-3  maxAns=max(-3,-3)=-3
x=-2: pre=max(-3-2,-2)=-2 maxAns=max(-3,-2)=-2
x=-1: pre=max(-2-1,-1)=-1 maxAns=max(-2,-1)=-1
返回 -1 ✓（选 [-1] 这一段）
```

因为每步都 `max(pre+x, x)`，而 `x` 自己也是一个候选，所以 `pre` 永远不会小于「当前 x」。答案就是「最大的那个单元素」，符合「全负数时取最大负数」的预期。

### Q3：`pre = max(pre + x, x)` 里的 `pre` 到底是什么？为什么一个变量就够？

`pre` 在每轮循环开始时代表 `f(i-1)`（以上一个元素结尾的最大和），算完 `max(pre+x, x)` 后它就变成了 `f(i)`（以当前元素结尾的最大和），供下一轮用。

能压成一个变量的原因是**无后效性 + 只依赖前一个状态**：`f(i)` 只用 `f(i-1)`，不需要 `f(i-2)`、`f(i-3)` 等更早的值。一旦算完 `f(i)`，`f(i-1)` 就再没用了，直接覆盖。这是所有「一维、只看前一项」DP 的通用压缩手段（滚动数组）。

如果想保留每个位置的 `f(i)`（比如还要还原出是哪段子数组），就得开 `f` 数组——但本题只要最大值，所以一个变量足矣。

### Q4：为什么不能用「滑动窗口」做？

滑动窗口适用于「窗口内满足某条件时如何伸缩」的问题（如和恰好/至多为 K 的最长子数组），它的前提往往是**元素都非负**（这样窗口扩大和单调增、收缩和单调减，才能用单调性双指针）。

本题元素有正有负，扩大窗口**不一定**让和变大（加个负数反而变小），不满足单调性，滑动窗口失效。本质工具是**动态规划 / 前缀和**，而不是双指针。

## 复盘

- **核心套路**：「**最大/最小的连续子段和**」→ 想到 **Kadane 算法**，状态定义为「以 `i` 结尾的最大和」，转移 `f(i)=max(f(i-1)+nums[i], nums[i])`。一句话：「**前面的累积是正贡献就接上，否则从自己重开**」。
- **状态定义的技巧**：用「**以某个位置结尾**」来定义状态，天然保证子段连续，且把「选不选前面」压缩成一个二选一决策——这是连续子数组类 DP 的通用姿势（如 152 乘积最大子数组、918 环形子数组的最大和都沿用此模式，只是把 `max/和` 换成 `max/积` 或额外处理环）。
- **滚动变量压缩**：当 `f(i)` 只依赖 `f(i-1)` 时，无需数组，一个变量滚动即可，空间从 O(n) 降到 O(1)。判断「能否压缩」就看转移方程里回头看几步——只看一步就能压。
- **初始化陷阱**：求「最大值」且结果可能为负时，答案变量**必须用真实元素初始化**，不能给 `0`；这点在「全负数组」下会直接 WA。

### 解法二：分治（官方方法二，O(n) 时间 O(log n) 空间）

题目「进阶」提到的分治法。和动态规划时间同为 O(n)，但空间是 O(log n)（递归栈）、常数更大，**单次查询不如 Kadane**。它的价值在于：把区间信息组织成一棵树后，可以扩展成**线段树**，支持 O(log n) 查询/修改**任意区间**的最大子段和（多次询问场景才有优势）。

**思路**：对区间 `[l, r]` 取中点 `m` 分治。每个区间维护四个量：

- `lSum`：以 `l` 为左端点的最大子段和；
- `rSum`：以 `r` 为右端点的最大子段和；
- `mSum`：区间内的最大子段和（即所求）；
- `iSum`：区间总和。

合并左右子区间时：`iSum` 直接相加；`lSum` 是「左子 `lSum`」或「左子 `iSum` + 右子 `lSum`」取大；`rSum` 对称；`mSum` 是「左子 `mSum`、右子 `mSum`、左子 `rSum` + 右子 `lSum`」三者取大（最后一种对应跨中点的子段）。

```cpp
class Solution {
public:
    struct Status {
        int lSum, rSum, mSum, iSum;
    };

    // pushUp：把左右两个子区间的 Status 合并成父区间的 Status。
    Status pushUp(Status l, Status r) {
        int iSum = l.iSum + r.iSum;                          // 总和 = 左和 + 右和
        int lSum = max(l.lSum, l.iSum + r.lSum);             // 以 l 开头：要么只在左半，要么跨到右半
        int rSum = max(r.rSum, r.iSum + l.rSum);             // 以 r 结尾：对称
        int mSum = max(max(l.mSum, r.mSum), l.rSum + r.lSum);// 最大子段和：不跨中点 or 跨中点
        return (Status){lSum, rSum, mSum, iSum};
    }

    // get：查询 a[l..r] 区间的 Status。
    Status get(vector<int> &a, int l, int r) {
        if (l == r) {
            // 长度 1 的区间：四个量都等于该唯一元素。
            return (Status){a[l], a[l], a[l], a[l]};
        }
        int m = (l + r) >> 1;           // 位运算右移一位 = 除以 2（向下取整），比 /2 快一点点
        Status lSub = get(a, l, m);     // 分治左半
        Status rSub = get(a, m + 1, r); // 分治右半
        return pushUp(lSub, rSub);      // 合并
    }

    int maxSubArray(vector<int>& nums) {
        return get(nums, 0, (int)nums.size() - 1).mSum;
    }
};
```

- **时间**：O(n)——递归树每层合计处理 n 个元素，共 O(log n) 层。
- **空间**：O(log n)——递归栈深度。
- **何时用分治**：只有「**多次查询任意区间**的最大子段和」时才值得（建线段树）；单次求全局最大和，Kadane 更优。
