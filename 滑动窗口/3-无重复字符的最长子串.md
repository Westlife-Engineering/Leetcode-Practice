# 3 无重复字符的最长子串

- 难度：中等
- 标签：哈希表、字符串、**滑动窗口**
- 力扣链接：https://leetcode.cn/problems/longest-substring-without-repeating-characters/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解 / 阅读文章](https://leetcode.cn/articles/longest-substring-without-repeating-characters/)的滑动窗口做法。正文主解是 **HashSet + 滑动窗口**；「优化版（记录下标直接跳）」见文末「复盘」。

## 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的最长子串的长度。

**示例 1：**

```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2：**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3：**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。
```

**数据范围：**

- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

## 思路

> 本题参考力扣官方「滑动窗口」做法。

### 暴力想法（O(n³)，会超时）

枚举所有子串 `[i, j)`，再检查该子串里有没有重复字符。检查一次最坏 O(n)，总复杂度约 O(n³)。n ≤ 5×10⁴ 不可行。

### 关键观察：滑动窗口

暴力会反复检查「某个子串是否无重复」，但其实没必要：

- 如果 `s[i..j-1]` **已经**确认无重复，那么扩展到 `j` 时，**只需判断 `s[j]` 是否已在当前窗口里**。
- 一旦发现重复，以 `i` 开头的无重复子串就已经推到了极限，可以让左边界右移，继续找更长的。

这就是**滑动窗口**：维护一个当前无重复的区间 `[i, rk]`（官方写法里右端点叫 `rk`），用哈希集合记录窗口里出现过的字符。

### 算法（HashSet + 滑动窗口）

1. 用 `unordered_set<char> occ` 存当前窗口里的字符。
2. 右指针 `rk` 初始为 `-1`（还没吃进任何字符）。
3. 枚举左指针 `i = 0 .. n-1`：
   - 若 `i != 0`，说明左边界右移了一格，把 `s[i-1]` 从集合里删掉。
   - 不断尝试右移 `rk`：只要 `rk+1` 没越界，且 `s[rk+1]` **不在**集合里，就把它塞进集合并 `++rk`。
   - 此时 `[i, rk]` 就是「以 `i` 开头的最长无重复子串」，用 `rk - i + 1` 更新答案。

**为什么对？** 右指针只向右走、不回退；左指针也只向右走。每个下标进出集合各至多一次，整体线性。

示意（`s = "abcabcbb"`）：

```
i=0: 窗口尽量往右扩 → "abc"，长度 3
i=1: 丢掉 'a'，再扩 → "bca"，长度 3
i=2: 丢掉 'b'，再扩 → "cab"，长度 3
...
```

## 代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // unordered_set<char>：哈希集合，元素无序、不可重复，查找/插入/删除均摊 O(1)。
        //   - 本题用来记录「当前滑动窗口里已经出现过的字符」。
        //   - 和 unordered_map 一样基于哈希；这里只关心「有没有」，不需要映射到别的值，
        //     所以用 set 比 map 更合适。
        unordered_set<char> occ;

        int n = (int)s.size();
        int ans = 0;

        // rk：右指针（right）。官方题解命名。
        //   - 初始为 -1：表示窗口还是空的，右端点在左边界左侧。
        //   - 循环中始终维护：区间 [i, rk] 内无重复字符（若 rk < i 则窗口为空）。
        int rk = -1;

        // 枚举左指针 i：每次固定左端点，把右端点尽量往右推。
        for (int i = 0; i < n; ++i) {
            if (i != 0) {
                // 左指针从 i-1 移到 i：窗口丢掉最左边那个字符。
                // erase(key)：从集合中删除值为 key 的元素；不存在则什么都不做，均摊 O(1)。
                occ.erase(s[i - 1]);
            }

            // 尽量扩展右边界：下一个字符还不在窗口里，就可以吃进来。
            // count(x)：返回集合中等于 x 的元素个数（对 set 只能是 0 或 1）。
            //   - 常用写法：if (occ.count(x)) 表示「x 已在集合中」。
            //   - 比 find(x) != end() 更直观；均摊 O(1)。
            while (rk + 1 < n && !occ.count(s[rk + 1])) {
                // insert(x)：插入元素；若已存在则集合不变。均摊 O(1)。
                occ.insert(s[rk + 1]);
                ++rk;
            }

            // 此时 [i, rk] 是以 i 开头的最长无重复子串。
            // max(a, b)：返回两者较大值；力扣环境默认可用。
            ans = max(ans, rk - i + 1);
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(n)
  - 左指针 `i`、右指针 `rk` 都只向右移动，各自最多走 n 步；每个字符进出 `occ` 各至多一次。官方写作 O(2n) = O(n)。
- **空间**：O(min(n, m))
  - `occ` 里最多存窗口大小个字符；窗口大小 ≤ n，也 ≤ 字符集大小 m（本题字符含字母、数字、符号、空格，m 可看成常数级的 ASCII 范围）。

## 复盘

- **核心套路**：维护「当前无重复」的滑动窗口；右扩遇到重复就左缩（或左端点枚举时丢掉旧字符）。哈希集合负责 O(1) 判断「字符在不在窗口里」。
- **子串 vs 子序列**：子串必须连续（`"wke"`），子序列可以不连续（`"pwke"`）。本题要的是子串长度。
- **和双指针目录题的区别**：这里两指针同向滑动（都从左往右），形成窗口；`11` / `42` 是左右端点对向收拢。

### 解法二：优化的滑动窗口（记录上次出现下标）

官方方法三：不用集合逐步删左边，而是用「字符 → 上次出现下标」的映射。当 `s[j]` 在窗口内重复时，**左指针直接跳到**上次出现位置的下一位，省掉逐步 `erase`。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // unordered_map<char, int>：哈希表，key 是字符，value 是该字符最近一次出现的下标。
        //   - 查找/写入均摊 O(1)。
        //   - mp[c]：若 c 不存在会插入默认值 0；本题用 count / find 判断更安全，
        //     或写成「先查再更新」，避免把「没出现过」和「出现在下标 0」搞混。
        unordered_map<char, int> last;
        int n = (int)s.size();
        int ans = 0;
        int i = 0;  // 左指针：窗口 [i, j]

        for (int j = 0; j < n; ++j) {
            // 若 s[j] 曾出现，且上次位置仍在当前窗口内，则左边界直接跳过那个重复位置。
            if (last.count(s[j]) && last[s[j]] >= i) {
                i = last[s[j]] + 1;
            }
            last[s[j]] = j;                 // 更新该字符最近出现位置
            ans = max(ans, j - i + 1);
        }
        return ans;
    }
};
```

- **时间**：O(n)——右指针只走一遍，左指针只向右跳。
- **空间**：O(min(n, m))——哈希表大小受字符集限制。
- **小优化**：若确认是 ASCII，可用 `int last[128]`（初值填 -1）代替 `unordered_map`，常数更小。
