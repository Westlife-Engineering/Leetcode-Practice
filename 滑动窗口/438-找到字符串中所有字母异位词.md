# 438 找到字符串中所有字母异位词

- 难度：中等
- 标签：哈希表、字符串、**滑动窗口**
- 力扣链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked

> 说明：本题参考[力扣官方题解](https://leetcode.cn/problems/find-all-anagrams-in-a-string/solutions/1123971/zhao-dao-zi-fu-chuan-zhong-suo-you-zi-mu-xzin/)的滑动窗口做法。正文主解是 **定长滑动窗口 + 两个计数数组**；「用 differ 优化比较」见文末「复盘」。

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1：**

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

**示例 2：**

```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

**数据范围：**

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母

## 思路

> 本题参考力扣官方「滑动窗口」做法。

### 关键观察

异位词 = 字母种类和出现次数完全相同、顺序可以不同。

因此：`p` 的异位词子串，**长度一定等于 `p.size()`**。问题变成：

> 在 `s` 里检查每一个长度为 `n = p.size()` 的窗口，看它的字符计数是否与 `p` 相同。

### 暴力想法（会超时）

枚举每个起点 `i`，取出 `s.substr(i, n)`，排序后和排序后的 `p` 比较。窗口有 O(m) 个，每次排序 O(n log n)，太大。

### 定长滑动窗口 + 计数数组

窗口长度固定为 `n`，每右移一格：

- 右边新字符进窗口（计数 +1）
- 左边旧字符出窗口（计数 -1）

用两个长度为 26 的数组：

- `pCount`：`p` 里每个字母出现几次
- `sCount`：当前窗口里每个字母出现几次

二者相等 ⟺ 当前窗口是异位词。

示意（`s = "cbaebabacd"`, `p = "abc"`，窗口长 3）：

```
[cba]ebabacd  → 计数 == p → 记下 0
c[bae]babacd  → 不相等
...
cbaeba[bac]d  → 计数 == p → 记下 6
```

## 代码

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int m = (int)s.size();
        int n = (int)p.size();

        // s 比 p 还短：不可能有异位词子串。
        // vector<int>()：空的整型动态数组，作为空答案返回。
        if (m < n) {
            return vector<int>();
        }

        // vector<int> ans：存放所有合法起始下标。
        vector<int> ans;

        // vector<int> sCount(26)：长度为 26 的整型数组，初始全 0。
        //   - 构造签名：vector(size_type count) → 创建 count 个默认值（int 为 0）元素。
        //   - 下标 0..25 对应字母 'a'..'z'；只用数组不用 unordered_map，
        //     因为字符集固定 26，数组更快、比较也方便（可直接 ==）。
        vector<int> sCount(26);
        vector<int> pCount(26);

        // 先统计 p，以及 s 的第一个窗口 s[0..n-1]。
        for (int i = 0; i < n; ++i) {
            // c - 'a'：把小写字母映射到 0..25。
            ++sCount[s[i] - 'a'];
            ++pCount[p[i] - 'a'];
        }

        // vector 支持 operator==：逐元素比较是否全等，O(26)=O(1)。
        // 第一个窗口合法 → 起点是 0。
        // emplace_back(x)：在末尾就地构造元素；比 push_back 少一次临时对象。
        if (sCount == pCount) {
            ans.emplace_back(0);
        }

        // 窗口右移：每次丢掉 s[i]，纳入 s[i+n]，新窗口起点是 i+1。
        // i 从 0 走到 m-n-1，共 m-n 次滑动。
        for (int i = 0; i < m - n; ++i) {
            --sCount[s[i] - 'a'];           // 左端字符出窗口
            ++sCount[s[i + n] - 'a'];       // 右端新字符进窗口

            if (sCount == pCount) {
                ans.emplace_back(i + 1);    // 当前窗口起点
            }
        }
        return ans;
    }
};
```

## 复杂度

- **时间**：O(m + |Σ|)
  - 建初始窗口 O(n)，之后滑动 O(m - n) 次；每次比较两个长度 26 的数组是 O(|Σ|)，|Σ|=26 视为常数，整体 O(m)。
- **空间**：O(|Σ|)
  - 两个计数数组，各 26 个格子；答案数组不算额外算法空间时也可说 O(1)（相对输入规模）。

## 复盘

- **核心套路**：**定长滑动窗口**——异位词长度已知，窗口大小钉死，滑动时只更新进出的两个字符。
- **和 [3 无重复字符的最长子串](./3-无重复字符的最长子串.md) 的区别**：第 3 题窗口长度可变（遇重复就缩）；本题窗口长度固定为 `|p|`。
- **和 [49 字母异位词分组](../哈希/49-字母异位词分组.md)**：49 是「按异位词归类」；本题是「在长串里找所有异位词窗口」。

### 解法二：用 differ 优化「整表比较」

官方方法二：不维护两个数组再 `==`，而是用一个 `count[26]` 表示「窗口相对 p 的差值」，再用变量 `differ` 记录「有多少个字母的计数目前 ≠ 0」。滑动时只根据进出字符局部更新 `differ`，当 `differ == 0` 就是异位词。

思路要点：

- 初始：窗口里每个字母 +1，`p` 里每个字母 -1，再数有多少个位置非 0 → `differ`。
- 左端字符出窗：该位从「相同变不同」或「不同变相同」时改 `differ`，再把计数 -1。
- 右端字符进窗：对称更新。

- **时间**：仍是 O(m)，但每步比较从扫 26 格变成 O(1) 维护 `differ`。
- **空间**：O(|Σ|)。
